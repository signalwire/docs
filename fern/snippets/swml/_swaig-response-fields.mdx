<ParamField path="response" type="string | object" toc={true}>
  The result the agent reads next. A string becomes the tool message as written. For `ai` agents, an object splits the result into `tool_result`, the data the agent reads, and `tool_prompt`, an instruction added right after it. When omitted, the agent gets a default result.
</ParamField>

<ParamField path="action" type="object | object[]" toc={true}>
  An action, or a list of actions, for the platform to perform on the call.
</ParamField>

<ParamField path="post_process" type="boolean" default="false" toc={true}>
  If `true`, the actions run after the agent has spoken its reply rather than immediately. Read only by `ai` agents.
</ParamField>
