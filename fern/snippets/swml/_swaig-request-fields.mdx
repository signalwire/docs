[SWML Function properties]: /docs/swml/reference/ai/swaig/functions#properties

These fields are always present:

<ParamField path="function" type="string" toc={true}>
  Name of the function that was invoked.
</ParamField>

<ParamField path="description" type="string" toc={true}>
  The description of the function being invoked. The value is the `functions.description` value you
  provided in the [SWML Function properties].
</ParamField>

<ParamField path="argument" type="object" toc={true}>
  The argument the AI agent is providing to the function. The object contains the three following fields.
</ParamField>

<Indent>
<ParamField path="argument.parsed" type="object[]" toc={true}>
  Each JSON object detected within the argument, parsed. Usually a single-element array.
</ParamField>

<ParamField path="argument.raw" type="string" toc={true}>
  The raw argument provided by the AI agent.
</ParamField>

<ParamField path="argument.substituted" type="string" toc={true}>
  The argument provided by the AI agent, excluding any JSON.
</ParamField>
</Indent>

<ParamField path="argument_desc" type="object" toc={true}>
  The parameter definition for the function, as you declared it in `parameters` in the
  [SWML Function properties]. Omitted when the function was declared with the legacy string `argument`
  form instead.
</ParamField>

<ParamField path="call_id" type="string" toc={true}>
  The unique identifier for the current call.
</ParamField>

<ParamField path="ai_session_id" type="string" toc={true}>
  The unique identifier for the AI session.
</ParamField>

<ParamField path="app_name" type="string" toc={true}>
  Name of the application that originated the request.
</ParamField>

<ParamField path="content_type" type="string" toc={true}>
  Type of content. The value will be `text/swaig`.
</ParamField>

<ParamField path="content_disposition" type="string" toc={true}>
  Content disposition identifier. The value will be `SWAIG Function`.
</ParamField>

<ParamField path="version" type="string" toc={true}>
  The SWAIG version, for example `2.0`.
</ParamField>

<ParamField path="channel_active" type="boolean" toc={true}>
  Whether the channel is currently active.
</ParamField>

<ParamField path="channel_offhook" type="boolean" toc={true}>
  Whether the channel is off-hook.
</ParamField>

<ParamField path="channel_ready" type="boolean" toc={true}>
  Whether the channel is ready.
</ParamField>

These fields depend on the call, on the function's configuration, or on what you enabled:

<ParamField path="project_id" type="string" toc={true}>
  The project ID associated with the call, when available.
</ParamField>

<ParamField path="space_id" type="string" toc={true}>
  The Space ID associated with the call, when available.
</ParamField>

<ParamField path="caller_id_name" type="string" toc={true}>
  Name of the caller, when available.
</ParamField>

<ParamField path="caller_id_num" type="string" toc={true}>
  Number of the caller, when available.
</ParamField>

<ParamField path="conversation_id" type="string" toc={true}>
  The conversation ID, when the AI session has one.
</ParamField>

<ParamField path="global_data" type="object" toc={true}>
  Global data set via the `set_global_data` action, as a key-value map. Included when the session has any.
</ParamField>

<ParamField path="meta_data_token" type="string" toc={true}>
  The token that scopes `meta_data`. Included when the function defines one, or defaults to the
  function's `web_hook_url`.
</ParamField>

<ParamField path="meta_data" type="object" toc={true}>
  The metadata scoped to `meta_data_token`, as a key-value map. Included alongside `meta_data_token`.
</ParamField>

<ParamField path="SWMLVars" type="object" toc={true}>
  A collection of variables related to SWML. Included when you enable `swaig_post_swml_vars`.
</ParamField>

<ParamField path="SWMLCall" type="object" toc={true}>
  The SWML `call` object for the call. Included when you enable `swaig_post_swml_vars`.
</ParamField>

<ParamField path="call_log" type="object[]" toc={true}>
  The conversation so far. Redacted when `redact_prompt` is set. Included when you enable
  `swaig_post_conversation`.
</ParamField>

<ParamField path="raw_call_log" type="object[]" toc={true}>
  The full conversation so far, before redaction. Included when you enable `swaig_post_conversation`.
</ParamField>

<ParamField path="fatal_error" type="boolean" toc={true}>
  `true` when the AI session has hit an unrecoverable error. Included only in that case.
</ParamField>

<ParamField path="error_reason" type="string" toc={true}>
  A description of the error. Included only alongside `fatal_error`.
</ParamField>
