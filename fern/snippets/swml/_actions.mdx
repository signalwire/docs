<ParamField path="action[].SWML" type="object" toc={true}>
  A SWML object to be executed.
</ParamField>

<ParamField path="action[].say" type="string" toc={true}>
  Text for the agent to speak. The caller can interrupt it, as they can a reply.

  The model receives the text as the agent's own words, right after the result of the function call it came from: in full when it played, cut where the caller stopped hearing it when it was interrupted, and as `…` alone when it never played. The function's `response` doesn't need to repeat it. Words the caller said before the `say` began are placed before it, and words said while or after it played come after it. On realtime models, the model speaks the text itself.
</ParamField>

<ParamField path="action[].stop" type="boolean" toc={true}>
  Whether to stop the conversation.
</ParamField>

<ParamField path="action[].hangup" type="boolean" toc={true}>
  Whether to hang up the call. When set to `true`, the call will be terminated after the AI agent finishes speaking.
</ParamField>

<ParamField path="action[].hold" type="integer | string | object" toc={true}>
  Places the caller on hold while playing hold music (configured via the [`params.hold_music`](/docs/swml/reference/calling/ai/params#paramshold_music) parameter).
  During hold, speech detection is paused and the AI agent will not respond to the caller.

  The value is the hold timeout. Can be:
  - A number of seconds, such as `120`
  - A [duration string](/docs/swml/reference/calling/ai/params#duration-values), such as `"5m"` for 5 minutes
  - An object with `timeout`, and optionally `step` and `timeout_step`

  Default timeout is `300` seconds (5 minutes). A timeout outside `0` to `900` seconds (15 minutes) falls back to `300` seconds.

  <Note title="Unholding a call">
  There is no `unhold` SWAIG action because the AI agent is inactive during hold and cannot process actions.
  To take a caller off hold, either:
  - Let the hold timeout expire (the AI will automatically resume with a default message), or
  - Use the [Calling API `ai_unhold` command](/docs/apis/rest/calls/call-commands) to programmatically unhold the call with a custom prompt.
  </Note>
</ParamField>

<Indent>
<ParamField path="hold.timeout" type="integer | string" default="300" toc={true}>
  How long to hold the caller: a number of seconds, or a [duration string](/docs/swml/reference/calling/ai/params#duration-values) such as `"5m"`. A value outside `0` to `900` seconds falls back to `300`.
</ParamField>

<ParamField path="hold.step" type="string" toc={true}>
  The step to move to when the caller is taken off hold. When omitted, the conversation stays on the current step. Applies only if the hold starts.
</ParamField>

<ParamField path="hold.timeout_step" type="string" toc={true}>
  The step to move to when the hold times out without the caller being taken off hold. When omitted, the conversation stays on the current step. Applies only if the hold starts.
</ParamField>
</Indent>

<ParamField path="action[].change_context" type="string" toc={true}>
  The name of the context to switch to. The context must be defined in the AI's `prompt.contexts` configuration.
  This action triggers an immediate context switch during the execution of a SWAIG function.

  Visit the [`contexts`][contexts] documentation for details on defining contexts.
</ParamField>

<ParamField path="action[].change_step" type="string" toc={true}>
  The name of the step to switch to. The step must be defined in `prompt.contexts.{context_name}.steps` for the current context; it doesn't need to be in the current step's `valid_steps`.
  This action triggers an immediate step transition during the execution of a SWAIG function.

  Naming the step the agent is already in starts that step over. Its text is rebuilt from the current variables, so a `set_global_data` in the same result is reflected whatever the order of the actions. Its `history` mode applies again, and its functions are set again. Use this for a confirm step whose proposal the caller revised.

  Visit the [`steps`][steps] documentation for details on defining steps.
</ParamField>

<ParamField path="action[].toggle_functions" type="object[]" toc={true}>
  An array of objects to toggle SWAIG functions on or off during the conversation.
  Each object identifies a function by name and sets its active state.
  A function can only toggle functions that have the same `meta_data_token` as itself.

  See [`toggle_functions`][toggle_functions] for additional details.
</ParamField>

<Indent>
<ParamField path="toggle_functions[].function" type="string" required={true} toc={true}>
  The name of the SWAIG function to toggle. One name per object; to toggle several functions, add an object for each.
</ParamField>

<ParamField path="toggle_functions[].active" type="boolean" default="true" toc={true}>
  Whether to activate or deactivate the function.
</ParamField>
</Indent>

<ParamField path="action[].set_global_data" type="object" toc={true}>
  A JSON object containing any global data, as a key-value map. This action sets the data in the [`global_data`][properties] to be globally referenced.
</ParamField>

<ParamField path="action[].set_meta_data" type="object" toc={true}>
  A JSON object containing any metadata, as a key-value map. This action sets the data in the [`meta_data`][properties] to be referenced locally in the function.

  See [`set_meta_data`][set_meta_data] for additional details.
</ParamField>

<ParamField path="action[].unset_global_data" type="string | string[]" toc={true}>
  The key to remove from [`global_data`](/docs/swml/reference/calling/ai#aiglobal_data), or an array of keys to remove.
</ParamField>

<ParamField path="action[].unset_meta_data" type="string | string[]" toc={true}>
  The key to remove from the function's [`meta_data`](/docs/swml/reference/calling/ai/swaig/functions#functionsmeta_data), or an array of keys to remove.
</ParamField>

<ParamField path="action[].playback_bg" type="object" toc={true}>
  A JSON object containing the audio file to play.
</ParamField>

<Indent>
<ParamField path="playback_bg.file" type="string" toc={true}>
  URL or filepath of the audio file to play. Authentication can also be set in the url in the format of `username:password@url`.
</ParamField>

<ParamField path="playback_bg.wait" type="boolean" default="false" toc={true}>
  Whether to wait for the audio file to finish playing before continuing.
</ParamField>
</Indent>

<ParamField path="action[].stop_playback_bg" type="boolean" toc={true}>
  Stops the background audio file. The action runs whenever the key is present, whatever its value, so `false` also stops playback. Leave the key out to keep playing.
</ParamField>

<ParamField path="action[].user_input" type="string" toc={true}>
  Adds text to the conversation as the caller's turn, as if the caller had said it, and the agent answers it. Works on realtime models too.
</ParamField>

<ParamField path="action[].context_switch" type="object" toc={true}>
  Replaces the agent's instructions mid-conversation. You can use [variables](/docs/swml/reference/variables) in `system_prompt`, `user_prompt`, `system_pom`, and `user_pom`. In a `data_map` function they're expanded along with the rest of the output; in a reply from your `web_hook_url`, they're expanded when the action runs. Either way they're expanded only once, so a value that itself contains `${...}` is left as it is.

  See [`context_switch`][context_switch] for additional details.
</ParamField>

<Indent>
<ParamField path="context_switch.system_prompt" type="string" toc={true}>
  The new instructions for the agent. Set this or `system_pom`.
</ParamField>

<ParamField path="context_switch.system_pom" type="object" toc={true}>
  The new instructions as an object with `text` or `pom`, the same shape as a prompt. Used instead of `system_prompt` when both are set.
</ParamField>

<ParamField path="context_switch.consolidate" type="boolean" default="false" toc={true}>
  If `true`, the conversation so far is summarized and the summary is carried into the new context. When the caller hasn't spoken yet there's nothing to summarize, so `full_reset` is ignored.
</ParamField>

<ParamField path="context_switch.full_reset" type="boolean" default="false" toc={true}>
  If `true`, the new instructions replace the agent's original prompt. Otherwise the conversation is cleared and the new instructions are added.
</ParamField>

<ParamField path="context_switch.user_prompt" type="string" toc={true}>
  A string serving as simulated user input for the AI Agent. During a `context_switch` in the AI's prompt, the `user_prompt` offers the AI pre-established context or guidance.
</ParamField>

<ParamField path="context_switch.user_pom" type="object" toc={true}>
  The simulated user input as an object with `text` or `pom`. Used instead of `user_prompt` when both are set.
</ParamField>
</Indent>

<ParamField path="action[].settings" type="object" toc={true}>
  Changes the AI model's settings for the rest of the call, as a key-value map such as `{"temperature": 0.3}`. Only the keys you name change; every other setting, including one set on `prompt`, keeps its current value. A key the model doesn't accept is ignored. The change lasts across steps. Requires [`params.swaig_allow_settings`](/docs/swml/reference/calling/ai/params#paramsswaig_allow_settings), which is on by default.
</ParamField>

<ParamField path="action[].user_event" type="object" toc={true}>
  Sends a custom event to the client connected to the call, with this object as its payload, like the [`user_event`](/docs/swml/reference/calling/user-event) method.
</ParamField>

<ParamField path="action[].transfer" type="boolean | string | object" toc={true}>
  Transfer the call to a new destination. Accepts two forms depending on whether it accompanies a sibling `action[].SWML` payload:

  - **Boolean** — use alongside a sibling `action[].SWML` payload in the same action object. When `true`, ends the AI session and hard-transfers the call to that SWML. When omitted or `false`, the SWML executes inline and the AI session continues afterward.
  - **Object or string** — use on its own, without `SWML`, to end the AI session and transfer the call to the destination configured with the fields below. A string is shorthand for `transfer.dest`.
</ParamField>

<Indent>
<ParamField path="transfer.dest" type="string" required={true} toc={true}>
  The destination to transfer to: the name of a section in the current SWML document, or a URL that returns SWML to execute.
</ParamField>

<ParamField path="transfer.summarize" type="boolean" default="false" toc={true}>
  Whether to include a conversation summary when transferring.
</ParamField>
</Indent>

<ParamField path="action[].no_barge_next_response" type="boolean | string" toc={true}>
  Makes the agent's next spoken reply play in full, such as a read-back the caller should hear completely before answering. Set it to `true` or a true string; a number such as `1` is ignored.

  - It holds from the start of the next model request until a reply that speaks has played, so the caller's words neither cut the reply nor cancel its request. A reply that only calls a function leaves it for the next reply.
  - The caller's words during the reply, short acknowledgements such as "okay" included, are held and delivered after it. `interrupt_on_noise` doesn't cut the reply; DTMF still does.
  - It holds for at most 30 seconds from the request's start while the agent isn't speaking. A reply still playing then is held to its end.
  - [Semantic gates](/docs/swml/reference/calling/ai/swaig/functions/gates) see the reply as cut where the caller's words began.

  Not on realtime models, where barge-in is the model's own.
</ParamField>

<ParamField path="action[].semantic_gate_mark" type="string" toc={true}>
  Sets a named mark that a semantic gate's [`since`](/docs/swml/reference/calling/ai/swaig/functions/gates#gatessince) judges the conversation from: 1 to 64 letters, digits, or underscores. The mark is set as of the start of the result's action list, so a `say` anywhere in the same list comes after it. Setting a mark again moves it. Marks last for the whole call, and step and context changes don't clear them. A call keeps up to 16 mark names, dropping the oldest past that. An invalid name sets nothing.
</ParamField>

<ParamField path="action[].back_to_back_functions" type="boolean | string" toc={true}>
  Whether the model may call another function right after a function result, without answering the caller in words first. The setting lasts for the rest of the call.

  - `"forever"` (the default): the model may chain function calls freely.
  - `false`: the model must answer in words after a function result.
  - `true`: while chaining is off, allows one more chained call. It doesn't change `"forever"`.

  Any other value is ignored. The post-prompt and a `summarize_conversation` summary always run with `"forever"`. Not on realtime models.
</ParamField>

<ParamField path="action[].extensive_data" type="boolean" toc={true}>
  How long the model keeps this function's result. Without this action, a result over 1024 bytes is available to the model for the rest of its turn, including the function calls and retries after it. Once the caller speaks after a reply that played out, the model sees `The appropriate answer was provided.` in its place. A smaller result stays for the whole call.

  - `true`: the result is available for its turn only, whatever its size.
  - `false`: the result stays for the whole call, whatever its size.

  Also works from a `post_process` response. Not on realtime models.
</ParamField>

<ParamField path="action[].change_voice" type="string | string[] | object" toc={true}>
  Changes the current language's voice for the rest of the call. Takes a voice string such as `elevenlabs.adam`, an array of up to 8 voice strings, or an object with `voice` set to either. In an array, the first voice speaks and the rest become its fallbacks, replacing the language's own; with one voice, the language keeps its fallbacks. Either way the fallbacks start over from the first. See [`languages[].voice`](/docs/swml/reference/calling/ai/languages#languagesvoice) for voice strings and how fallbacks are tried.
</ParamField>

<ParamField path="action[].add_dynamic_hints" type="(string | object)[]" toc={true}>
  Adds speech recognition hints during the call, in the same forms as the `ai` method's [`hints`](/docs/swml/reference/calling/ai#aihints): strings, or objects with `hint`, or `pattern` and `replace`. Where the speech recognizer accepts hints during a call, the new list (the agent's hints, then the dynamic ones) is applied between turns without restarting recognition. Otherwise recognition restarts with the new list. Not on realtime models.
</ParamField>

<ParamField path="action[].clear_dynamic_hints" type="object" toc={true}>
  Removes every hint added with `add_dynamic_hints`. Set it to an empty object, `{}`. The new list is applied the same way as for `add_dynamic_hints`. Not on realtime models.
</ParamField>

<ParamField path="action[].end_of_speech_timeout" type="integer | string" toc={true}>
  Changes the agent's [`end_of_speech_timeout`](/docs/swml/reference/calling/ai/params#paramsend_of_speech_timeout). A number is milliseconds; a string can be a [duration](/docs/swml/reference/calling/ai/params#duration-values) such as `"1.5s"`. The value must be above `0`.
</ParamField>

<ParamField path="action[].speech_event_timeout" type="integer | string" toc={true}>
  Changes the agent's [`speech_event_timeout`](/docs/swml/reference/calling/ai/params#paramsspeech_event_timeout). A number is milliseconds; a string can be a [duration](/docs/swml/reference/calling/ai/params#duration-values) such as `"500ms"`. The value must be above `0`.
</ParamField>

<ParamField path="action[].wait_for_user" type="boolean" toc={true}>
  Whether the agent waits for the caller to speak before it takes its turn. Set after the caller has spoken, the agent waits up to [`attention_timeout`](/docs/swml/reference/calling/ai/params#paramsattention_timeout), and when that runs out it takes its turn as after any silence. Set before the caller's first words, it waits up to [`outbound_attention_timeout`](/docs/swml/reference/calling/ai/params#paramsoutbound_attention_timeout) and ends the call when that runs out.
</ParamField>
