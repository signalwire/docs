These fields are always present:

<ParamField path="function" type="string" toc={true}>
  Name of the function that was invoked.
</ParamField>

<ParamField path="argument" type="object" toc={true}>
  The argument the agent is providing to the function. The object contains the two following fields.
</ParamField>

<Indent>
<ParamField path="argument.parsed" type="object[]" toc={true}>
  The arguments parsed into objects. Usually a single-element array.
</ParamField>

<ParamField path="argument.raw" type="string" toc={true}>
  The raw argument string, exactly as the agent produced it.
</ParamField>
</Indent>

<ParamField path="call_id" type="string" toc={true}>
  The unique identifier for the current call.
</ParamField>

<ParamField path="ai_session_id" type="string" toc={true}>
  The unique identifier for the AI session. Matches `call_id` for Bedrock agents.
</ParamField>

<ParamField path="app_name" type="string" default="bedrock" toc={true}>
  Name of the application that originated the request.
</ParamField>

<ParamField path="caller_id" type="string" toc={true}>
  Number of the caller. An empty string when the call has none.
</ParamField>

<ParamField path="global_data" type="object" toc={true}>
  Global data as a key-value map. An empty object when you seeded none.
</ParamField>

<ParamField path="content_type" type="string" toc={true}>
  Type of content. The value will be `text/json`.
</ParamField>

<ParamField path="content_disposition" type="string" toc={true}>
  Content disposition identifier. The value will be `agent.function` for a function call.
</ParamField>

<ParamField path="conversation_type" type="string" toc={true}>
  The kind of conversation the agent is running. The value will be `voice`.
</ParamField>

<ParamField path="action" type="string" toc={true}>
  What the request is asking of you. The value will be `fetch_conversation` for a function call.
  The end-of-call conversation report sends `post_conversation` instead.
</ParamField>

<ParamField path="meta_data_token" type="string" toc={true}>
  The token that scopes `meta_data`. This is the `meta_data_token` you set on the function, or an
  MD5 of the function's name when you did not set one.
</ParamField>

<ParamField path="meta_data" type="object" toc={true}>
  The metadata scoped to `meta_data_token`, as a key-value map. An empty object when the function has
  none yet.
</ParamField>

These fields depend on the call or on the call's SWML state:

<ParamField path="project_id" type="string" toc={true}>
  The project ID associated with the call, when available.
</ParamField>

<ParamField path="space_id" type="string" toc={true}>
  The Space ID associated with the call, when available.
</ParamField>

<ParamField path="conversation_id" type="string" toc={true}>
  The conversation ID, when the agent was configured with one.
</ParamField>

<ParamField path="caller_id_name" type="string" toc={true}>
  Name of the caller, when available.
</ParamField>

<ParamField path="caller_id_number" type="string" toc={true}>
  Number of the caller, when available.
</ParamField>

<ParamField path="call_start_date" type="integer" toc={true}>
  When the call was created, as a Unix timestamp in microseconds.
</ParamField>

<ParamField path="call_answer_date" type="integer" toc={true}>
  When the call was answered, as a Unix timestamp in microseconds. `0` when it never was.
</ParamField>

<ParamField path="call_end_date" type="integer" toc={true}>
  When the call ended, as a Unix timestamp in microseconds. `0` while the call is still up.
</ParamField>

<ParamField path="ai_start_date" type="integer" toc={true}>
  When the agent started, as a Unix timestamp in microseconds.
</ParamField>

<ParamField path="ai_end_date" type="integer" toc={true}>
  When the agent stopped, as a Unix timestamp in microseconds. Omitted while it is still running.
</ParamField>

<ParamField path="times" type="object[]" toc={true}>
  Per-response performance metrics for the session so far. Included once the agent has any.
</ParamField>

<ParamField path="SWMLVars" type="object" toc={true}>
  A collection of variables related to SWML. Included when the call carries SWML state.
</ParamField>

<ParamField path="SWMLCall" type="object" toc={true}>
  The SWML `call` object for the call. Included when the call carries SWML state.
</ParamField>
