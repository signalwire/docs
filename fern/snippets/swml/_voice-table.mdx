### Supported voices and languages

To learn more about the supported voices and languages, please visit the [Supported Voices and Languages Documentation](/docs/platform/voice/tts).

### Supported ring tones

| Parameter   |                                                                                                                                                                                                                                                                                                                                                                                                                                  |
|:------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `urls.ring` | Available values are the following two-letter country identifiers: **at**, **au**, **be**, **bg**, **br**, **ca**, **ch**, **cl**, **cn**, **cy**, **cz**, **de**, **dk**, **dz**, **ee**, **eg**, **es**, **fi**, **fr**, **gr**, **hu**, **il**, **in**, **it**, **jp**, **ko**, **lt**, **mx**, **my**, **nl**, **no**, **nz**, **ph**, **pk**, **pl**, **pt**, **ro**, **rs**, **ru**, **sa**, **se**, **sg**, **th**, **tr**, **tw**, **uk**, **us**, **ve**, **za**. The named tone **bong** is also available. |
