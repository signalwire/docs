{/* Shared component: Resource Contexts */}

`Contexts` define the operational environment or 'scenario' under which
[Resources](/docs/platform/call-fabric/resources) operate.
They determine how resources are routed and interact with each other.

Every Project starts with two contexts, and you can add named contexts of either access type from the Dashboard's Contexts page:

- The `public` context exposes the Resource to anyone.
- The `private` context exposes the Resource to [Subscribers](/docs/platform/subscribers).

Use Contexts to structure and secure your communication flows
with granular control over how different Resources interact and are exposed.
