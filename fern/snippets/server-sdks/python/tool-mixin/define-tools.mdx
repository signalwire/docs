Returns the list of SWAIG functions registered on this {{noun}}: every tool added via
[`define_tool()`](/docs/server-sdks/reference/python/agents/{{base}}/define-tool),
the [`@tool` decorator](/docs/server-sdks/reference/python/agents/{{base}}#tool), or
[`register_swaig_function()`](/docs/server-sdks/reference/python/agents/{{base}}/register-swaig-function).

This method is available on [`SWMLService`](/docs/server-sdks/reference/python/agents/swml-service) and inherited by
[`AgentBase`](/docs/server-sdks/reference/python/agents/agent-base).

<Note>
Use this method to inspect the registered tools. The SDK doesn't call it when it
builds SWML or dispatches a tool call, so overriding it doesn't change which tools
the AI can use. Register tools with [`define_tool()`](/docs/server-sdks/reference/python/agents/{{base}}/define-tool) or the
[`@tool` decorator](/docs/server-sdks/reference/python/agents/{{base}}#tool) instead.
</Note>

## Parameters

None.

## Returns

`list[SWAIGFunction | dict[str, Any]]` -- A [`SWAIGFunction`](/docs/server-sdks/reference/python/agents/swaig-function)
object for each tool with a Python handler, and a raw dictionary for each function
added with `register_swaig_function()`, such as a DataMap tool.
