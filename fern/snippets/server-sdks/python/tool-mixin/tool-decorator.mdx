When parameters are not explicitly provided, the decorator automatically infers the
JSON Schema from Python type hints on the function signature.

#### Parameters

<ParamField path="name" type="str | None" default="None" toc={true}>
  Function name exposed to the AI. Defaults to the decorated function's `__name__`.
</ParamField>

<ParamField path="description" type="str | None" default="None" toc={true}>
  What the function does. The AI reads this to decide when to call it. Defaults to the
  function's docstring, or `"Function {name}"` as a fallback.
</ParamField>

<ParamField path="parameters" type="dict[str, Any] | None" default="None" toc={true}>
  Explicit JSON Schema for function parameters. If omitted, the schema is
  automatically inferred from Python type hints on the decorated function.
</ParamField>

<ParamField path="secure" type="bool" default="True" toc={true}>
  Require token validation on tool calls. Only `AgentBase` issues and checks tool
  tokens; a standalone `SWMLService` doesn't validate them.
</ParamField>

<ParamField path="fillers" type="dict[str, list[str]] | None" default="None" toc={true}>
  Filler phrases by language code, spoken while the function runs.
</ParamField>

<ParamField path="webhook_url" type="str | None" default="None" toc={true}>
  External webhook URL. If set, SignalWire calls this URL instead of executing locally.
</ParamField>

<ParamField path="required" type="list[str] | None" default="None" toc={true}>
  Required parameter names. Auto-inferred from type hints when not specified.
</ParamField>

<ParamField path="gates" type="Sequence[SemanticGate | dict[str, Any]] | None" default="None" toc={true}>
  1 to 8 [semantic gates](/docs/server-sdks/reference/python/agents/semantic-gate)
  that must pass before the function runs. Raises `ValueError` for gates the
  platform would refuse.
</ParamField>

<ParamField path="gate_fillers" type="dict[str, list[str | list[str]]] | None" default="None" toc={true}>
  What the AI says while the gates are checked, shaped like `fillers`. Raises
  `ValueError` without `gates`.
</ParamField>

<ParamField path="**swaig_fields" type="Any" toc={true}>
  Additional SWAIG fields (e.g., `wait_file`, `meta_data`, or
  `fillers_at_gates=False` on a gated function).
</ParamField>
