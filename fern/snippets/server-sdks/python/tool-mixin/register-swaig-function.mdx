Register a raw SWAIG function definition dictionary. This is the primary way to
register server-side functions created by
[`DataMap`](/docs/server-sdks/reference/python/agents/data-map), which generates complete
SWAIG function definitions including URL mappings, expressions, and output templates.

Unlike [`define_tool()`](/docs/server-sdks/reference/python/agents/{{base}}/define-tool),
this method does not take a Python handler -- the function executes on the SignalWire
server (for DataMap functions) or at an external webhook URL.

This method is available on [`SWMLService`](/docs/server-sdks/reference/python/agents/swml-service) and inherited by
[`AgentBase`](/docs/server-sdks/reference/python/agents/agent-base).

## Parameters

<ParamField path="function_dict" type="dict[str, Any]" required={true} toc={true}>
  Complete SWAIG function definition dictionary. Must follow the SWAIG function
  schema, typically generated by `DataMap.to_swaig_function()`. A definition with
  `gates` or `gate_fillers` is checked like one from `define_tool()`: raises
  `ValueError` for gates the platform would refuse, for `gates: None`, or for a
  gated definition without a description. The dictionary is updated in place:
  its gates are replaced with plain dicts.
</ParamField>
