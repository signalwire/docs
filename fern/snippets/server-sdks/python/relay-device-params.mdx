<ParamField path="devices[][].params.to_number" type="str" toc={true}>
  Destination phone number in E.164 format. Required for `"phone"`.
</ParamField>

<ParamField path="devices[][].params.from_number" type="str" toc={true}>
  Caller ID phone number in E.164 format. Required for `"phone"`. Use a number
  you bought in this project or a verified caller ID. When connecting an
  existing call, its own `from` or `to` number also works.
</ParamField>

<ParamField path="devices[][].params.to" type="str" toc={true}>
  Destination. Required for `"sip"`, where it's a SIP URI starting with `sip:`
  or `sips:`, and for `"fabric"`, where it's a resource address.
</ParamField>

<ParamField path="devices[][].params.from" type="str" toc={true}>
  Caller ID. Required for `"sip"` and `"fabric"`. Use a SIP URI, or a phone
  number you bought in this project or a verified caller ID.
</ParamField>

<ParamField path="devices[][].params.from_name" type="str" toc={true}>
  Caller ID name shown to the person you're calling, for `"sip"`. Use 1 to 70
  characters: letters, digits, spaces, and `_`, `.`, `-`, `+`, or `,`.
</ParamField>

<ParamField path="devices[][].params.timeout" type="int" default="60" toc={true}>
  How long to ring this device, in seconds, before giving up on it.
</ParamField>

<ParamField path="devices[][].params.headers" type="list[dict[str, str]]" toc={true}>
  Custom SIP headers to add to the INVITE, for `"sip"`. Each header is a dict
  with a `"name"` and a non-empty `"value"`. A name must start with `X-` or be
  `Privacy`, `P-Asserted-Identity`, or `User-to-User`. Names starting with
  `SignalWire`, `X-SignalWire`, or `X-CID` are reserved and rejected.
</ParamField>

<ParamField path="devices[][].params.session_timeout" type="int" toc={true}>
  Value of the SIP `Session-Expires` header, in seconds, for `"sip"`. Values
  from 1 to 15000 take effect; anything else is ignored and the default is used.
</ParamField>

<ParamField path="devices[][].params.call_state_url" type="str" toc={true}>
  HTTP or HTTPS URL that receives a webhook when this device's call changes
  state. When omitted, the device uses the state URL of the call it's connected
  to, if that call has one.
</ParamField>

<ParamField path="devices[][].params.call_state_events" type="list[str]" toc={true}>
  Which states send a webhook to `call_state_url`. Valid values: `"created"`,
  `"ringing"`, `"answered"`, `"ended"`. When omitted, the device uses the
  events of the call it's connected to, or only `"ended"` when there are none.
</ParamField>

<ParamField path="devices[][].params.confirm" type="str | list[dict]" toc={true}>
  SWML to run on this device's call after it answers and before it's
  connected, for example to have the callee press a key to accept. Either an HTTP or HTTPS URL
  that returns a SWML document, or a list of SWML methods to run inline. The
  same methods are allowed as in the SWML [`connect.confirm`](/docs/swml/reference/calling/connect#connectconfirm)
  parameter.
</ParamField>

<ParamField path="devices[][].params.confirm_timeout" type="int" toc={true}>
  How long `confirm` can run, in seconds. Defaults to the device's `timeout`.
</ParamField>
