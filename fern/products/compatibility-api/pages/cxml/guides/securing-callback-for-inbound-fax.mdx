## Overview

The SignalWire Fax API allows you to have full event monitoring through the usage of status callbacks.
The below example will demonstrate how to configure your SignalWire phone number with a cXML Script to receive a fax and alert your own server of fax events that are occurring in your SignalWire Space.

How To Run the Application
--------------------------

### Configuring Your Number

To create a cXML Script, select **My Resources** in the left sidebar of your [SignalWire Dashboard](https://my.signalwire.com), select **+ Add**, choose **Script**, and then choose **cXML Script**.

Paste the following XML content in your new cXML Script, replacing the `action` URL with the URL of your server.
The below code is taken from the [Receive a Fax in Compatibility XML example](/docs/compatibility-api/cxml/reference/fax/receive#examples).

```xml
<?xml version="1.0" encoding="UTF-8"?>
<Response>
  <Receive action="https://YOUR_URL_EXPECTING_A_CALLBACK."/>
</Response>
```

Lastly, assign the cXML Script to the phone number that receives the faxes:

<Markdown src="/snippets/common/dashboard/_assign-resource-to-number.mdx" />

The `<Receive>` verb answers the call and receives the fax, so the number needs no fax-specific setting.

### Testing your Configured Fax Number

Congratulations, your phone number is now configured!
It is time to test your phone number by [Sending a Fax](/docs/compatibility-api/rest/faxes/send-fax) to your fax-receiving phone number.

Once your fax has been received, you should receive a payload to your actionURL that looks similar to the one below.
Feel free to read up more on [Request Parameters](/docs/compatibility-api/cxml/reference/fax#request-parameters)
and [Additional Callback Parameters](/docs/compatibility-api/cxml/reference/fax/receive#action-callback)
for more information on the data being sent.

Additional Information on Callback Authentication
-------------------------------------------------

When using SignalWire for Inbound Fax, the callback can be made secure.
Unfortunately, there is no set list of IP addresses that SignalWire can provide as they change frequently.
That being said, there are a couple of ways to work around this.

As an alternative method, callbacks support basic authentication as well, for example, `https://user:pass@callback-url.com`.
You can also [view and allow SignalWire IPs in real-time by running a specific script](/docs/platform/allow-signalwire-ips-through-your-firewall).
However, as stated before, they change frequently, so keep your eye on them.

Wrap Up
-------

This mini-guide walked through how you can configure your SignalWire phone number to receive incoming faxes, and also opened the door to a variety of other monitoring methods through status callbacks.
Each significant event that occurs will be relayed back to your actionURL so that you can keep an eye on your traffic without having to keep an eye on your SignalWire Dashboard.
