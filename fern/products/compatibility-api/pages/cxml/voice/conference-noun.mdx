[`<Dial>`](/docs/compatibility-api/cxml/reference/voice/dial) verb's `<Conference>` noun allows the connection to a named conference room.
For example:

<CodeBlocks>
```xml
<?xml version="1.0" encoding="UTF-8"?>
<Response>
  <Dial>
    <Conference>Room 1234</Conference>
  </Dial>
</Response>
```

```javascript title="Node.js"
const { RestClient } = require("@signalwire/compatibility-api");
const response = new RestClient.LaML.VoiceResponse();

dial = response.dial();
dial.conference("Room 1234");
console.log(response.toString());
```

```csharp
using Twilio.TwiML;
using Twilio.TwiML.Voice;
using System;

class Example
{
    static void Main()
    {
        var response = new VoiceResponse();
        var dial = new Dial();
        dial.Conference("Room 1234");

        response.Append(dial);
        Console.WriteLine(response.ToString());;
    }
}
```

```python
from signalwire.voice_response import VoiceResponse, Dial, Conference

response = VoiceResponse()
dial = Dial()
dial.conference('Room 1234')
response.append(dial)

print(response)
```

```ruby
require 'signalwire/sdk'

response = Signalwire::Sdk::VoiceResponse.new do |response|
  response.dial do |dial|
    dial.conference('Room 1234')
  end
end

puts response.to_s
```
</CodeBlocks>

## Noun attributes

<ParamField path="beep" type="string" default="true" toc={true}>
  Whether or not a sound is played when callers leave or enter a conference. See [below](#conference_beep) for all possible values.
</ParamField>

<ParamField path="coach" type="string" toc={true}>
  Coach accepts a call [SID](/docs/platform/what-is-a-sid) of a call that is currently connected to an in-progress conference. Specifying a call SID that does not exist or is no longer connected to the conference will result in the call failing to the action URL and throwing a 13240 error.
</ParamField>

<ParamField path="emitCallQuality" type="boolean" default="false" toc={true}>
  When **true**, a `participant-call-quality` request with this participant's audio statistics is sent to `statusCallback` when the participant leaves, if statistics are available. To receive it, include `leave` in `statusCallbackEvent`. See [below](#conference_statusCallback) for request parameters.
</ParamField>

<ParamField path="endConferenceOnExit" type="boolean" default="false" toc={true}>
  If a participant with `endConferenceOnExit` set to **true** leaves a conference, the conference terminates and all participants drop out of the call.
</ParamField>

<ParamField path="eventCallbackUrl" type="string" toc={true}>
  A URL for conference recording status requests, used only when `recordingStatusCallback` is not set. Requests to it are always `POST`. Takes effect only when `record` is `record-from-start`.
</ParamField>

<ParamField path="maxParticipants" type="integer" toc={true}>
  The maximum number of participants allowed in a named conference room.
</ParamField>

<ParamField path="muted" type="boolean" default="false" toc={true}>
  Whether or not a caller can speak in a conference.
</ParamField>

<ParamField path="record" type="string" default="do-not-record" toc={true}>
  Can be used to record an entire `<Conference>`. `record-from-start` will begin recording the conference call once the first two participants join in on the call. Wait music is not recorded.
</ParamField>

<ParamField path="recordingStatusCallback" type="string" toc={true}>
  The `recordingStatusCallback` attribute takes in an absolute URL. SignalWire will make a `GET` or `POST` request to this URL when recording is accessible. See [below](#conference_recordingStatusCallback) for request parameters.
</ParamField>

<ParamField path="recordingStatusCallbackEvent" type="string" default="completed" toc={true}>
  The recording status that triggers a request to `recordingStatusCallback`. Set a single value; a list of values, or any value not listed [below](#conference_recordingStatusCallbackEvent), is treated as `completed`.
</ParamField>

<ParamField path="recordingStatusCallbackMethod" type="string" default="POST" toc={true}>
  The type of HTTP request to use when requesting a `recordingStatusCallback`.
</ParamField>

<ParamField path="startConferenceOnEnter" type="boolean" default="true" toc={true}>
  The conference begins once a specific caller enters into the conference room, unless it has already started. If a participant joins and `startConferenceOnEnter` is **false**, that participant will hear background music and stay muted until a participant with `startConferenceOnEnter` set to **true** joins the call.
</ParamField>

<ParamField path="statusCallback" type="string" toc={true}>
  The URL to make requests to for each `statusCallbackEvent` event. The URL is set by the first participant to enter a conference. All other information provided by other participants will be ignored. See [below](#conference_statusCallback) for request parameters.
</ParamField>

<ParamField path="statusCallbackEvent" type="string" toc={true}>
  Which conference state changes will trigger a webhook to the URL provided in `statusCallback`. Specifies conference state changes. The first participant to join the named conference is able to manipulate and set events. All other changes made by other participants will be ignored. See [below](#conference_statusCallbackEvent) for all possible events. To specify multiple events, separate them with a space.
</ParamField>

<ParamField path="statusCallbackMethod" type="string" default="POST" toc={true}>
  The type of HTTP request to use when requesting a `statusCallback`.
</ParamField>

<ParamField path="trim" type="string" default="trim-silence" toc={true}>
  Whether or not silence in the beginning and end of recordings are removed.
</ParamField>

<ParamField path="waitMethod" type="string" default="POST" toc={true}>
  Specifies whether the request to `waitUrl` is a `GET` or a `POST`.
</ParamField>

<ParamField path="waitUrl" type="string" toc={true}>
  URL for the music to play in the background while participants are waiting to enter a conference room. Only supports `<Play>`, `<Pause>`, and `<Redirect>`. If no `waitUrl` is provided, SignalWire will use its hold music.
</ParamField>




#### Values for the `beep` attribute  [#conference_beep]

The `beep` attribute has the following values:

| Value | Description |
|:------|:------------|
| `true` | Plays a beep when a caller leaves or enters a conference. The **default value** for `beep`. |
| `false` | Disables the beep when callers leave and enter conferences. |
| `onEnter` | Only plays a beep when a caller enters a conference. |
| `onExit` | Only plays a beep when a caller leaves a conference. |




#### Events for the `statusCallbackEvent` attribute  [#conference_statusCallbackEvent]

The `statusCallbackEvent` attribute has the following events. Each one sends the `StatusCallbackEvent` values listed beside it. If you set `statusCallback` without `statusCallbackEvent`, no callbacks are sent.

| Event | Description | `StatusCallbackEvent` values sent |
|:------|:------------|:------------|
| `start` | The conference has started as long as there are at least two people in the conference room and one of the participant's `startConferenceOnEnter` is set to **true**. | `conference-start` |
| `end` | The conference ends when the last participant in the call or a participant with `endConferenceOnExit` set to **true** leaves the call. | `conference-end` |
| `join` | When a participant joins a conference. | `participant-join` |
| `leave` | When a participant leaves a conference. | `participant-leave`, plus `participant-call-quality` for a participant who joined with `emitCallQuality` set to **true** |
| `mute` | When a participant has been muted or un-muted. | `participant-mute`, `participant-unmute` |
| `hold` | When a participant has been put on hold or put out of hold. | `participant-hold`, `participant-unhold` |
| `speaker` | When a participant has begun or stopped speaking. | `participant-speech-start`, `participant-speech-stop` |




#### Request parameters for the `statusCallback` URL  [#conference_statusCallback]

SignalWire sends the parameters below to your `statusCallback` URL, as a form-encoded `POST` body or, when `statusCallbackMethod` is `GET`, as query parameters. Every value is a string, so boolean parameters arrive as `true` or `false`. The full schema, with an example payload, is on the [Conference status callback reference](/docs/compatibility-api/rest/conferences/webhooks/conference-status-callback).

Which parameters are sent depends on the event:

| Parameter | `conference-start`, `conference-end` | `participant-join`, `-leave`, `-mute`, `-unmute`, `-hold`, `-unhold` | `participant-speech-start`, `-speech-stop` | `participant-call-quality` |
|:------|:------|:------|:------|:------|
| `AccountSid`, `ConferenceSid`, `StatusCallbackEvent`, `Timestamp` | Yes | Yes | Yes | Yes |
| `CallSid` | Sent with no value | Yes | Yes | Yes |
| `FriendlyName` | Yes | Yes | No | No |
| `Muted`, `Hold` | Sent with no value | Yes | Yes | No |
| `EndConferenceOnExit`, `StartConferenceOnEnter`, `Coaching`, `CallSidToCoach` | No | Yes | Yes | No |
| `ReasonConferenceEnded`, `CallSidEndingConference` | `conference-end` only | No | No | No |
| `AudioRttAvg`, `AudioRttMin`, `AudioRttMax`, `AudioOutJitterAvg`, `AudioOutJitterMin`, `AudioOutJitterMax`, `AudioOutLost` | No | No | No | Each one when measured |

<ParamField path="AccountSid" type="string" toc={true}>
  The unique ID of the project the conference belongs to.
</ParamField>

<ParamField path="ConferenceSid" type="string" toc={true}>
  The unique identifier for the conference.
</ParamField>

<ParamField path="FriendlyName" type="string" toc={true}>
  The name of the conference. Not sent on `participant-speech-start`, `participant-speech-stop`, or `participant-call-quality`.
</ParamField>

<ParamField path="StatusCallbackEvent" type="string" toc={true}>
  The event that triggered the request: `conference-start`, `conference-end`, `participant-join`, `participant-leave`, `participant-mute`, `participant-unmute`, `participant-hold`, `participant-unhold`, `participant-speech-start`, `participant-speech-stop`, or `participant-call-quality`. `participant-call-quality` reports the audio statistics of a participant who joined with `emitCallQuality` set to **true**, and is sent when that participant leaves.
</ParamField>

<ParamField path="Timestamp" type="string" toc={true}>
  The timestamp, in RFC 2822 format, of when SignalWire processed the event.
</ParamField>

<ParamField path="CallSid" type="string" toc={true}>
  The unique identifier of the participant's call. Has no value on `conference-start` and `conference-end`.
</ParamField>

<ParamField path="Muted" type="string" toc={true}>
  Whether the participant is muted: `true` or `false`. Has no value on `conference-start` and `conference-end`, and is not sent on `participant-call-quality`.
</ParamField>

<ParamField path="Hold" type="string" toc={true}>
  Whether the participant is on hold: `true` or `false`. Has no value on `conference-start` and `conference-end`, and is not sent on `participant-call-quality`.
</ParamField>

<ParamField path="EndConferenceOnExit" type="string" toc={true}>
  Whether the conference ends when this participant leaves: `true` or `false`. Sent on participant events except `participant-call-quality`.
</ParamField>

<ParamField path="StartConferenceOnEnter" type="string" toc={true}>
  Whether the conference starts when this participant joins: `true` or `false`. Sent on participant events except `participant-call-quality`.
</ParamField>

<ParamField path="Coaching" type="string" toc={true}>
  Whether the participant is coaching another call: `true` or `false`. Sent on every participant event except `participant-call-quality`, whether or not the participant joined with the `coach` attribute.
</ParamField>

<ParamField path="CallSidToCoach" type="string" toc={true}>
  The unique identifier of the call this participant is coaching. Sent on every participant event except `participant-call-quality`; has no value when the participant is not coaching.
</ParamField>

<ParamField path="ReasonConferenceEnded" type="string" toc={true}>
  Why the conference ended. Sent on `conference-end` only, and can be empty when no reason was recorded.

  | Value | Meaning |
  |:------|:------------|
  | `last-participant-left` | The last participant left. |
  | `last-participant-kicked` | The last participant was removed from the conference. |
  | `participant-with-end-conference-on-exit-left` | A participant with `endConferenceOnExit` set to **true** left. |
  | `participant-with-end-conference-on-exit-kicked` | A participant with `endConferenceOnExit` set to **true** was removed from the conference. |
  | `conference-ended-via-api` | The conference was ended through the REST API, by [updating the conference](/docs/compatibility-api/rest/conferences/update-conference) with `Status` set to `completed`. |
  | `down` | SignalWire ended the conference after a service interruption. |
  | `stale` | SignalWire closed a conference that was still open but no longer active. |
</ParamField>

<ParamField path="CallSidEndingConference" type="string" toc={true}>
  The unique identifier of the call whose departure ended the conference. Sent on `conference-end` only; has no value when the conference did not end because a participant left or was removed.
</ParamField>

<ParamField path="AudioRttAvg" type="number" toc={true}>
  The participant's average audio round-trip time, in seconds. Sent on `participant-call-quality` only, when measured.
</ParamField>

<ParamField path="AudioRttMin" type="number" toc={true}>
  The participant's minimum audio round-trip time, in seconds. Sent on `participant-call-quality` only, when measured.
</ParamField>

<ParamField path="AudioRttMax" type="number" toc={true}>
  The participant's maximum audio round-trip time, in seconds. Sent on `participant-call-quality` only, when measured.
</ParamField>

<ParamField path="AudioOutJitterAvg" type="integer" toc={true}>
  The average jitter of the audio stream SignalWire sends to the participant. Measured in RTP timestamp units, not milliseconds: divide by the codec's samples per millisecond (8 for PCMU and PCMA, 48 for Opus) to convert. Sent on `participant-call-quality` only, when measured.
</ParamField>

<ParamField path="AudioOutJitterMin" type="integer" toc={true}>
  The minimum jitter of the audio stream SignalWire sends to the participant. Measured in RTP timestamp units, not milliseconds: divide by the codec's samples per millisecond (8 for PCMU and PCMA, 48 for Opus) to convert. Sent on `participant-call-quality` only, when measured.
</ParamField>

<ParamField path="AudioOutJitterMax" type="integer" toc={true}>
  The maximum jitter of the audio stream SignalWire sends to the participant. Measured in RTP timestamp units, not milliseconds: divide by the codec's samples per millisecond (8 for PCMU and PCMA, 48 for Opus) to convert. Sent on `participant-call-quality` only, when measured.
</ParamField>

<ParamField path="AudioOutLost" type="integer" toc={true}>
  The number of audio RTP packets SignalWire sent to the participant that were reported lost. Sent on `participant-call-quality` only, when measured.
</ParamField>

#### Status values for the `recordingStatusCallbackEvent` attribute  [#conference_recordingStatusCallbackEvent]

The `recordingStatusCallbackEvent` attribute takes one of the following values. Each value sends only its own request, so `in-progress` alone sends no request when the recording completes.

| Value | Description |
|:------|:------------|
| `in-progress` | A request is sent when the recording begins. |
| `completed` | A request is sent when the recording has completed and is accessible. The **default value**. If the recording captured no audio, no request is sent. |
| `absent` | A request is sent only when SignalWire closes a recording that produced no file, such as after a service interruption. A recording that ends normally with no audio sends no request. |

### A simple conference call

<CodeBlocks>


The first participant would join the conference "Room 1234" and listen to wait music in the background until a second participant joins the conference. Once participants have joined the conference, the wait music comes to an end, a beep is played, and the conference call begins.

You can set the `startConferenceOnEnter` to **false** so that a group of participants can join in the conference room but the conference cannot begin until the moderator has entered the call. As the participants wait for the conference to begin, hold music will be playing in the background.

### Start a moderated conference call

<CodeBlocks>
```xml

```

Now, since the moderator has joined in on the conference call, `startConferenceOnEnter` is set to **true** which means the conference can begin. All the participants that were waiting on hold will now be connected to the conference room; the hold music will come to an end and a beep notification will play indicating conference entrance. Once the moderator leaves the call, the conference will come to an end and all participants will be disconnected from the call.

## Notes on usage

- You can freely name the conference room to fit your preference. However, only callers within a project can join in on a named conference room. Callers from separate projects will not be able to connect to that same conference room.
- You can customize the background music as callers are waiting to join a conference call
- Conferences will not begin unless there are 2 or more parties present.
