The SignalWire AI Gateway Interface. Allows you to create user-defined functions that can be executed during the dialogue.

## **Properties**

<ParamField path="amazon_bedrock.SWAIG" type="object" toc={true}>
  An object that accepts the following properties.
</ParamField>

<Indent>

<ParamField path="SWAIG.defaults" type="object" toc={true}>
  Default settings for all SWAIG functions. If `defaults` is not set, settings may be set in each function object. Default is not set.
</ParamField>

<Indent>
<ParamField path="defaults.web_hook_url" type="string" toc={true}>
  The default URL to send status callbacks and reports to for all SWAIG functions. If `defaults` is not set, `web_hook_url` may be set in each [SWAIG function](/docs/swml/reference/calling/amazon-bedrock/swaig/functions) object. Authentication can also be set in the url in the format of `username:password@url`.

  For what this URL receives and what it should return, see the
  [tool webhook](/docs/swml/reference/calling/amazon-bedrock/swaig/functions#tool-webhook).
</ParamField>
</Indent>


<ParamField path="SWAIG.functions" type="object[]" toc={true}>
  An array of JSON objects to define functions that can be executed during the interaction with the AI. Default is not set. The fields of this object are the six following.

  See [`functions`](/docs/swml/reference/calling/amazon-bedrock/swaig/functions) for additional details.
</ParamField>


</Indent>
