Parameters for AI that can be passed in `amazon_bedrock.params` at the top level of the [`amazon_bedrock` Method][amazon_bedrock].

## **Properties**

<ParamField path="amazon_bedrock.params" type="object" toc={true}>
  An object that accepts the following properties.
</ParamField>

<Indent>

<ParamField path="params.attention_timeout" type="integer" default="5000 ms" toc={true}>
  Amount of time, in ms, to wait for the caller to respond before the agent is prompted to get their attention.
  Allowed values: `0` (to disable) or `1,000`-`60,000`.
</ParamField>

<ParamField path="params.inactivity_timeout" type="integer" default="600000 ms" toc={true}>
  Amount of time, in ms, to wait for the caller to respond after the agent finishes speaking. When it passes, the agent is
  prompted to check whether the caller is still there; the session does not end. Allowed values: `0` (to disable) or
  `10,000`-`3,600,000`.
</ParamField>

<ParamField path="params.hard_stop_time" type="string" toc={true}>
  The maximum time the agent stays active. When it has passed, the agent receives `hard_stop_prompt` as a final
  instruction and the conversation is scheduled to end. The agent's reply to that instruction is not guaranteed to
  finish before the conversation ends.

  **Time format:** `HH:MM:SS`, `MM:SS`, or a whole number of seconds, greater than zero. For example, `30:00` and
  `1800` are both 30 minutes. In the colon forms, minutes and seconds go up to `59`.
</ParamField>

<ParamField path="params.hard_stop_prompt" type="string" default="The time limit for this call has been reached. Please wrap up the conversation." toc={true}>
  The final instruction the agent receives when `hard_stop_time` is reached, before the conversation ends. Used only
  when `hard_stop_time` is set, and the default applies only then.
</ParamField>

<ParamField path="params.video_talking_file" type="string" toc={true}>
  URL of a video file to play while the agent is talking. Only works for calls that support video, and only together
  with `video_idle_file`: the agent's video plays only when both are set.
</ParamField>

<ParamField path="params.video_idle_file" type="string" toc={true}>
  URL of a video file to play while the agent is idle. Only works for calls that support video, and only together with
  `video_talking_file`: the agent's video plays only when both are set.
</ParamField>

<ParamField path="params.video_listening_file" type="string" toc={true}>
  URL of a video file to play while the caller is speaking. Used only when `video_talking_file` and `video_idle_file`
  are both set; when omitted, `video_idle_file` plays while the caller speaks.
</ParamField>

</Indent>
