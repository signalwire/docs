Send digit presses as DTMF tones. For a live inbound call that hasn't been answered yet, the method first attempts to answer it.

<ParamField path="send_digits" type="object" required={true} toc={true}>
  An object that accepts the following properties.
</ParamField>


## **Properties**

<ParamField path="send_digits.digits" type="string" required={true} toc={true}>
  The digits to send. Valid values are `0123456789*#ABCDWw`; `A`, `B`, `C`, and `D` can also be lowercase. Character `W` is a 1 second delay, and `w` is a 500 ms delay.

  After variable expansion, the value must contain at least one valid character and at most 99 characters, counting `W` and `w`. A longer sequence isn't sent, and `send_digits_result` is still `success`, so keep each sequence within the limit or split it across several `send_digits` steps.
</ParamField>


## **Variables**

Set by the method:

- **send_digits_result:** (out) `success` | `failed`. `success` means the send command completed without a reported error; it doesn't confirm that the tones were transmitted or received. `failed` means the command reported an error or the digits were missing after variable expansion.

## **Examples**

### Send digits

<CodeBlocks>
<CodeBlock title="YAML">
```yaml
version: 1.0.0
sections:
  main:
    - answer: {}
    - send_digits:
        digits: '012345'
    - play:
        url: 'say: ${send_digits_result}'
```
</CodeBlock>
<CodeBlock title="JSON">
