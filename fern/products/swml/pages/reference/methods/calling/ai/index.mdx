Creates an AI agent that conducts voice conversations using automatic speech recognition (ASR),
large language models (LLMs), and text-to-speech (TTS) synthesis.
The agent processes caller speech in real-time, generates contextually appropriate responses,
and can execute custom functions to interact with external systems and databases through [SignalWire AI Gateway (SWAIG)][SWAIG].

Since the [prompt] configuration is central to AI agent behavior,
it is recommended to read the [prompt engineering][prompt-engineering] guide.

## **Properties**

<ParamField path="ai" type="object" required={true} toc={true}>
  An object that defines an AI agent for conducting voice conversations. Accepts the following properties to configure the agent's prompt, behavior, functions, language support, and other settings.
</ParamField>

<Indent>

<ParamField path="ai.prompt" type="object" toc={true}>
  Defines the AI agent's personality, goals, behaviors, and instructions for handling conversations.
  The prompt establishes how the agent should interact with callers, what information it should gather,
  and how it should respond to various scenarios. Required unless you set `ai.agent` instead.

  It is recommended to write [prompts][prompt] using [markdown formatting][markdown-guide] as LLMs better understand structured content.
  It is also recommended to read the [prompt engineering][prompt-engineering] guide.
</ParamField>


<ParamField path="ai.agent" type="string" toc={true}>
  The ID of an AI agent saved in your SignalWire Space, such as the `agent_id` of an AI agent created with the
  [REST API][ai-agents-api]. Use it instead of an inline configuration: the agent runs with its saved settings.

  Set `agent` on its own. Other `ai` properties placed next to it are ignored. Don't
  combine `agent` with `prompt`: if both are present, the inline configuration runs and `agent` is ignored.
</ParamField>


<ParamField path="ai.global_data" type="object" toc={true}>
  A key-value object for storing data that persists throughout the AI session.
  Can be set initially in the SWML script or modified during the conversation using the [`set_global_data`][set_global_data action] action.

  The `global_data` object is accessible everywhere in the AI session: prompts, AI parameters,
  and SWML returned from SWAIG functions.
  Access properties using template strings (e.g `${global_data.property_name}`)
</ParamField>


<ParamField path="ai.hints" type="string[] | object[]" toc={true}>
  An array of strings and objects that help the agent understand what the caller says.
  Hints don't change how the agent speaks; to change pronunciation, use [`ai.pronounce`](#aipronounce).

  **Hints as strings:** Each string is passed to speech recognition as a hint, making that word or phrase
  more likely to be recognized. Recognition isn't guaranteed.

  **Hints as objects:** Each object is a recognition hint (`hint`), a rewrite rule applied to the text the agent hears
  before the AI reads it (`pattern` with `replace`), or both.

  One hint list covers every language the agent uses; there are no per-language hints. When speech recognition
  runs in code-switching mode, because [`ai.multilingual`][multilingual] is set or a [`languages`][languages] entry's
  `code` is `multi`, recognition hints are not used. That covers string entries and `hint` values, and no error
  is returned. Rewrite rules still apply to the transcript in every mode.
</ParamField>

<Indent>

<ParamField path="hints[].hint" type="string" toc={true}>
  A word or phrase passed to speech recognition as a hint, the same as a string entry. Required when `pattern` and `replace` are not set.
</ParamField>

<ParamField path="hints[].pattern" type="string" toc={true}>
  A regular expression matched against the text the agent hears. Set it together with `replace`; each match is replaced with `replace` before the AI reads the text.
</ParamField>

<ParamField path="hints[].replace" type="string" toc={true}>
  The text that replaces each match of `pattern`. Set it together with `pattern`.
</ParamField>

<ParamField path="hints[].ignore_case" type="boolean" default="false" toc={true}>
  If `true`, `pattern` is matched case-insensitively.
</ParamField>

</Indent>


<ParamField path="ai.languages" type="object[]" toc={true}>
  An array of JSON objects defining supported languages in the conversation.
  Mutually exclusive with `ai.multilingual`.

  See [languages] for more details.
</ParamField>


<ParamField path="ai.multilingual" type="object" toc={true}>
  Configures a single agent to detect the caller's language and answer in it, switching as the caller switches.
  Mutually exclusive with `ai.languages`: if both are set, `ai.multilingual` is used and `ai.languages` is ignored.

  See [multilingual] for more details.
</ParamField>


<ParamField path="ai.params" type="object" toc={true}>
  A JSON object containing parameters as key-value pairs.

  See [params] for more details.
</ParamField>


<ParamField path="ai.post_prompt" type="object" toc={true}>
  The final set of instructions and configuration settings to send to the agent.
  Set either `text` or `pom` for the instructions, the same way as in [`prompt`][prompt].
</ParamField>

<Indent>

<ParamField path="post_prompt.text" type="string" toc={true}>
  The instructions to send to the agent, as a single block of text. Required unless `pom` is set.
</ParamField>

<ParamField path="post_prompt.pom" type="object[]" toc={true}>
  The instructions to send to the agent, as a Prompt Object Model (POM): an array of sections that SignalWire
  renders into a markdown document. Required unless `text` is set. Sections take the same properties as
  [`prompt.pom`](/docs/swml/reference/calling/ai/prompt#promptpom).
</ParamField>

<ParamField path="post_prompt.model" type="string" toc={true}>
  The AI model that writes the summary. When omitted, the agent's model is used. If the model you name isn't
  available, a default model is used instead; if no default model is available either, the agent doesn't start.
</ParamField>

<ParamField path="post_prompt.max_tokens" type="integer" toc={true}>
  Limits the number of tokens the AI model may generate for the summary.
</ParamField>

<ParamField path="post_prompt.temperature" type="number" default="1.0" toc={true}>
  Randomness setting. Float value between 0.0 and 1.5. Closer to 0 will make the output less random.
</ParamField>

<ParamField path="post_prompt.top_p" type="number" default="1.0" toc={true}>
  Randomness setting. Alternative to `temperature`. Float value between 0.0 and 1.0. Closer to 0 will make the output less random.
</ParamField>

<ParamField path="post_prompt.confidence" type="number" deprecated={true} toc={true}>
  Has no effect and can be omitted.
</ParamField>

<ParamField path="post_prompt.presence_penalty" type="number" default="0" toc={true}>
  Aversion to staying on topic. Float value between -2.0 and 2.0. Positive values increase the model's likelihood to talk about new topics.
</ParamField>

<ParamField path="post_prompt.frequency_penalty" type="number" default="0" toc={true}>
  Aversion to repeating lines. Float value between -2.0 and 2.0. Positive values decrease the model's likelihood to repeat the same line verbatim.
</ParamField>

</Indent>


<ParamField path="ai.post_prompt_url" type="string" toc={true}>
  The URL to which to send status callbacks and reports. Authentication can also be set in the url in the format of `username:password@url`.
  See [post_prompt_url callback](#post_prompt_url-callback) below.
</ParamField>


<ParamField path="ai.post_prompt_auth_user" type="string" toc={true}>
  The username for basic authentication on `post_prompt_url`. A username embedded in the URL takes precedence.
</ParamField>


<ParamField path="ai.post_prompt_auth_password" type="string" toc={true}>
  The password for basic authentication on `post_prompt_url`. A password embedded in the URL takes precedence.
</ParamField>


<ParamField path="ai.pronounce" type="object[]" toc={true}>
  An array of objects to clarify the AI's pronunciation of certain words or expressions.
</ParamField>

<Indent>

<ParamField path="pronounce[].replace" type="string" required={true} toc={true}>
  The expression to replace.
</ParamField>

<ParamField path="pronounce[].with" type="string" required={true} toc={true}>
  The phonetic spelling of the expression.
</ParamField>

<ParamField path="pronounce[].ignore_case" type="boolean" default="false" toc={true}>
  Whether the pronunciation replacement should ignore case. Only the boolean `true` turns it on.
</ParamField>

</Indent>


<ParamField path="ai.SWAIG" type="object" toc={true}>
  An object that configures the functions the agent can call during the dialogue: user-defined `functions`,
  shared `defaults`, `includes`, `native_functions`, `mcp_servers`, and `internal_fillers`.

  See [SWAIG] for more details.
</ParamField>


<ParamField path="ai.voice" type="string" toc={true}>
  The voice the agent speaks with when neither `ai.languages` nor `ai.multilingual` is set.
  Format: `<engine id>.<voice id>`, with an optional `:<model id>` suffix for engines that offer a choice of model,
  the same as [`languages[].voice`][voice-strings]. When `ai.languages` or `ai.multilingual` is set, the voices
  configured there are used instead.
</ParamField>

</Indent>

## Variables

- **ai_result:** (out) `success` | `failed`. Whether the agent ran. `failed` also covers an `agent` value that isn't a valid ID.
  When `agent` runs a saved agent, this method doesn't set `ai_result` itself.

## post_prompt_url callback

SignalWire sends the report to your `post_prompt_url` as an HTTP `POST`.

<llms-ignore>

<WebhookPayloadSnippet webhook="aiPostPromptCallback" />

</llms-ignore>

See the [AI post-prompt callback](/docs/apis/rest/webhooks/ai-post-prompt-callback) webhook
page for the full field reference. To use the report for debugging and analysis, such as replaying
the conversation, inspecting each SWAIG function call, or measuring latency, see
[Conversation analytics](/docs/platform/ai/analytics).

### Responding to post prompt requests

Answer the end-of-call report with any 2xx status. The body is not read, so `{"response": "ok"}` is
as good as an empty one.

The one request that does read your response is the conversation fetch, which arrives at the same
URL with `"action": "fetch_conversation"` when the agent starts with a
[`conversation_id`](/docs/swml/reference/calling/ai/params#paramsconversation_id) and
[`save_conversation`](/docs/swml/reference/calling/ai/params#paramssave_conversation) enabled.
Return the summary you stored for that `conversation_id` under a `conversation_summary` key, and the
agent resumes with it:

```json
{
  "conversation_summary": "Caller booked a ride from 123 Main St to the airport for 6pm."
}
```


## Examples

### Minimal AI agent

<CodeBlocks>
<CodeBlock title="YAML">
```yaml
version: 1.0.0
sections:
  main:
    - answer: {}
    - ai:
        prompt:
          text: "You are a customer service agent. Answer questions about account status and billing."
```
</CodeBlock>
<CodeBlock title="JSON">
```json
{
  "version": "1.0.0",
  "sections": {
    "main": [
      {
        "answer": {}
      },
      {
        "ai": {
          "prompt": {
            "text": "You are a customer service agent. Answer questions about account status and billing."
          }
        }
      }
    ]
  }
}
```
</CodeBlock>
</CodeBlocks>

### Hints

<CodeBlocks>
<CodeBlock title="YAML">
```yaml
ai:
  hints:
  - Tony
  - hint: swimmel
    pattern: swimmel
    replace: SWML
```
</CodeBlock>
<CodeBlock title="JSON">
```json
{
  "ai": {
    "hints": [
      "Tony",
      {
        "hint": "swimmel",
        "pattern": "swimmel",
        "replace": "SWML"
      }
    ]
  }
}
```
</CodeBlock>
</CodeBlocks>


### Pronounce

<CodeBlocks>
<CodeBlock title="YAML">
```yaml
version: 1.0.0
sections:
  main:
    - ai:
        prompt:
          text: |
            You are an expert in the GIF file format. Tell the user whatever they'd like to know in this
            field.
        pronounce:
          - replace: GIF
            with: jif
```
</CodeBlock>
<CodeBlock title="JSON">
```json
{
  "version": "1.0.0",
  "sections": {
    "main": [
      {
        "ai": {
          "prompt": {
            "text": "You are an expert in the GIF file format. Tell the user whatever they'd like to know in this\nfield.\n"
          },
          "pronounce": [
            {
              "replace": "GIF",
              "with": "jif"
            }
          ]
        }
      }
    ]
  }
}
```
</CodeBlock>
</CodeBlocks>
