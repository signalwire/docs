Use `ai.languages` to configure the spoken language of your AI Agent, as well as the TTS engine, voice, and fillers.

Use [`ai.multilingual`][multilingual] instead when a single call may move between languages and you
want the agent to follow the caller. If your agent only ever speaks one language, set the voice on a
single entry, or leave `languages` out and set the voice directly.

<Warning>
`languages` and [`multilingual`][multilingual] are mutually exclusive. If both are set, SignalWire
uses `multilingual` and ignores `languages` entirely. To use `languages`, remove the `multilingual`
key rather than emptying it.
</Warning>

## **Properties**

<ParamField path="ai.languages" type="object[]" toc={true}>
  An array of objects that accept the following properties.
</ParamField>

<Indent>

<ParamField path="languages[].name" type="string" required={true} toc={true}>
  Name of the language ("French", "English", etc). This value is used in the system prompt to instruct the LLM what language is being spoken.
</ParamField>

<ParamField path="languages[].code" type="string | string[]" required={true} toc={true}>
  Set the language code for ASR (Automatic Speech Recognition) (STT (Speech-to-text)) purposes.
  By default, SignalWire uses Deepgram's Nova-3 STT engine, so this value should match a code from Deepgram's [Nova-3 language codes table][deepgram-codes].

  Supply an array to have this voice listen for up to three codes at once.

  Set it to `multi` to have the engine transcribe whichever of its supported languages the caller speaks, rather than one fixed language. The agent still answers in this entry's single `voice`. To answer in the caller's language as well, use [`ai.multilingual`][multilingual] instead, which builds on the same code-switching mode and adds a voice per language.
<Info> If a different STT model was selected using the [`openai_asr_engine` parameter][openai-asr-engine], you must select a code supported by that engine.</Info>
</ParamField>

<ParamField path="languages[].voice" type="string" required={true} toc={true}>
  String format: `<engine id>.<voice id>`, with an optional `:<model id>` suffix for engines that offer a choice of model.
Select engine from `gcloud`, `polly`, `amazon`, `azure`, `openai`, `elevenlabs`, `deepgram`, `cartesia`, `rime`, `inworld`, `minimax`, `groq-tts`, `mistral`, `grok`, `smallest`, `fish`, or `speechify`. Select voice from [TTS provider reference][tts-providers].
For example, `"gcloud.fr-FR-Neural2-B"` or `"elevenlabs.rachel:eleven_flash_v2_5"`.
Always name the engine: a bare voice id resolves against a default engine that can change.
See [`voice` usage](#use-voice-strings) for more details.
</ParamField>

<ParamField path="languages[].auto_emotion" type="boolean" default="false" toc={true}>
  Lets the AI vary its emotion as it speaks. A global emotion, or specific emotions for certain topics, can be set within the prompt of the AI.
<Warning>Only works with the `Cartesia` and `MiniMax` TTS engines. For a fixed MiniMax emotion, use [`params.emotion`](#paramsemotion) instead.</Warning>
</ParamField>

<ParamField path="languages[].auto_speed" type="boolean" default="false" toc={true}>
  Lets the AI vary its speaking speed during the conversation. The speed behavior can be defined in the prompt of the AI.
<Warning>Only works with the `Cartesia`, `ElevenLabs`, `MiniMax`, `Rime`, `Inworld`, `Smallest`, and `Fish` TTS engines.</Warning>
</ParamField>

<ParamField path="languages[].function_fillers" type="string[]" default="None" toc={true}>
  An array of strings to be used as fillers in the conversation when the agent is calling a [`SWAIG function`][swaig-functions]. The filler is played asynchronously during the function call.
</ParamField>

<ParamField path="languages[].listen_language" type="string | string[]" default="None" toc={true}>
  An alias for `code`, read only when `code` is absent. Prefer `code`.
</ParamField>

<ParamField path="languages[].model" type="string" default="None" toc={true}>
  The model to use for the specified TTS engine (e.g. `coda`). Set this only if the `voice` string does not already carry a `:<model id>` suffix. Check the [TTS provider reference][tts-providers] for the available models.
</ParamField>

<ParamField path="languages[].speech_fillers" type="string[]" default="None" toc={true}>
  An array of strings to be used as fillers in the conversation. This helps the AI break silence between responses.

<Note>`speech_fillers` are used between every 'turn' taken by the LLM, including at the beginning of the call. For more targed fillers, consider using `function_fillers`.</Note>
</ParamField>

<ParamField path="languages[].turn_fillers" type="string[]" default="None" toc={true}>
  Short backchannels played while the caller still has the floor and the agent is deliberately waiting, as when they spell a name or read out a number, to signal it is still listening. Which waits earn one is set by [`params.turn_filler_sources`][turn-filler-sources].

<Note>Unlike the language-keyed map on [`ai.multilingual`][multilingual], this is a plain array, because the entry already fixes the language.</Note>
</ParamField>

<ParamField path="languages[].params" type="object" default="None" toc={true}>
  TTS engine-specific parameters for this language.
</ParamField>

<Indent>
  <ParamField path="params.similarity" type="number" default="0.75" toc={true}>
    The similarity slider dictates how closely the AI should adhere to the original voice when attempting to replicate it.
    The higher the similarity, the closer the AI will sound to the original voice.
    Valid values range from `0.0` to `1.0`.
    <Info>
  Only works with the ElevenLabs TTS engine.
  </Info>
  </ParamField>

  <ParamField path="params.stability" type="number" default="0.50" toc={true}>
    The stability slider determines how stable the voice is and the randomness between each generation.
    Lowering this slider introduces a broader emotional range for the voice.
    Valid values range from `0.0` to `1.0`.
    <Info>
  Only works with the ElevenLabs TTS engine.
  </Info>
  </ParamField>

  <ParamField path="params.speakingRate" type="number" default="1.0" toc={true}>
    Adjusts how quickly the voice speaks.
    Values below `1.0` slow the voice down; values above `1.0` speed it up.
    Valid values range from `0.5` to `1.5`.
    <Info>
  Only works with the Inworld TTS engine.
  </Info>
  </ParamField>

  <ParamField path="params.temperature" type="number" default="1.0" toc={true}>
    Controls the randomness and expressiveness of the generated speech.
    Lower values produce a more consistent, predictable delivery; higher values introduce more variation.
    Valid values range from `0.0` to `2.0`.
    <Info>
  Only works with the Inworld TTS engine.
  </Info>
  </ParamField>

  <ParamField path="params.speed" type="number" default="1.0" toc={true}>
    How quickly the voice speaks.
    Values below `1.0` slow the voice down; values above `1.0` speed it up.
    Valid values range from `0.5` to `2.0`.
    <Info>
  Only works with the MiniMax TTS engine.
  </Info>
  </ParamField>

  <ParamField path="params.vol" type="number" default="1.0" toc={true}>
    The speaking volume. Lower values are quieter.
    Valid values range from `0.1` to `1.0`.
    <Info>
  Only works with the MiniMax TTS engine.
  </Info>
  </ParamField>

  <ParamField path="params.pitch" type="integer" default="0" toc={true}>
    The pitch shift in semitones. Negative values lower the pitch; positive values raise it.
    Valid values range from `-12` to `12`.
    <Info>
  Only works with the MiniMax TTS engine.
  </Info>
  </ParamField>

  <ParamField path="params.emotion" type="string" toc={true}>
    A fixed emotional tone for the generated speech.
    Valid values are `happy`, `sad`, `angry`, `fearful`, `disgusted`, `surprised`, and `neutral`.
    To vary the emotion automatically during a conversation, use [`languages[].auto_emotion`](#languagesauto_emotion) instead.
    <Info>
  Only works with the MiniMax TTS engine.
  </Info>
  </ParamField>
</Indent>

<ParamField path="languages[].pronounce" type="object[]" default="None" toc={true}>
  Pronunciation replacements applied only while this language is active. Each entry takes the same `replace`, `with`, and `ignore_case` properties as [`ai.pronounce`][ai-pronounce], which applies to the whole call instead.
</ParamField>

<ParamField path="languages[].fillers" type="string[]" deprecated={true} default="None" toc={true}>
  A deprecated spelling of `function_fillers`, and never used for speech fillers. An explicit `function_fillers` on the same entry takes precedence over it. **Deprecated**: Use `function_fillers` instead.
</ParamField>

<ParamField path="languages[].engine" type="string" deprecated={true} toc={true}>
  The engine to use for the language. For example, `"elevenlabs"`. **Deprecated.** Set the engine with the [`voice`](#use-voice-strings) parameter.
</ParamField>

</Indent>


## Use `voice` strings

Compose the `voice` string using the `<engine id>.<voice id>` syntax, optionally followed by `:<model id>`.

First, select your engine using the `gcloud`, `polly`, `amazon`, `azure`, `openai`, `elevenlabs`, `deepgram`, `cartesia`, `rime`, `inworld`, `minimax`, `groq-tts`, `mistral`, `grok`, `smallest`, `fish`, or `speechify` identifier. 
Append a period (`.`), and then the specific voice ID from the TTS provider, giving `gcloud.en-US-Casual-K`. 
Where an engine offers more than one model, append a colon (`:`) and the model ID, as in `elevenlabs.rachel:eleven_flash_v2_5`.
Refer to SignalWire's [Supported Voices and Languages][tts-providers]
for guides on configuring voice ID strings for each provider.

<Warning>
Always include the engine. A voice ID on its own — `en-US-Casual-K` rather than `gcloud.en-US-Casual-K` —
is resolved against a default engine, and that default can change. A voice string that names its
engine keeps working regardless.
</Warning>

SignalWire's cloud platform integrates with leading text-to-speech providers.

## **Examples**

### Set a single language

SWML will automatically assign the language (and other required parameters) to the defaults in the above table if left unset.
This example uses `ai.language` to configure a specific English-speaking voice from ElevenLabs.

<CodeBlocks>
<CodeBlock title="YAML">
```yaml
languages:
  - name: English
    code: en-US
    voice: elevenlabs.rachel
    speech_fillers:
      - one moment please,
      - hmm...
      - let's see,
```
</CodeBlock>
<CodeBlock title="JSON">
```json
{
  "languages": [
    {
      "name": "English",
      "code": "en-US",
      "voice": "elevenlabs.rachel",
      "speech_fillers": [
        "one moment please,",
        "hmm...",
        "let's see,"
      ]
    }
  ]
}
```
</CodeBlock>
</CodeBlocks>

### Set multiple languages

SWML will automatically assign the language (and other required parameters) to the defaults in the above table if left unset.
This example uses `ai.language` to configure multiple languages using different TTS engines.

<CodeBlocks>
<CodeBlock title="YAML">
```yaml
languages:
  - name: Mandarin
    code: cmn-TW
    voice: gcloud.cmn-TW-Standard-A
  - name: English
    code: en-US
    voice: elevenlabs.rachel
```
</CodeBlock>
<CodeBlock title="JSON">
```json
{
  "languages": [
    {
      "name": "Mandarin",
      "code": "cmn-TW",
      "voice": "gcloud.cmn-TW-Standard-A"
    },
    {
      "name": "English",
      "code": "en-US",
      "voice": "elevenlabs.rachel"
    }
  ]
}
```
</CodeBlock>
</CodeBlocks>

### Configure per-language ElevenLabs parameters

Configure different stability and similarity values for each language using `languages[].params`:

<CodeBlocks>
<CodeBlock title="YAML">
```yaml
ai:
  languages:
    - name: English
      code: en-US
      voice: elevenlabs.josh
      params:
        stability: 0.6
        similarity: 0.8
    - name: Spanish
      code: es
      voice: elevenlabs.maria
      params:
        stability: 0.4
        similarity: 0.9
```
</CodeBlock>
<CodeBlock title="JSON">
```json
{
  "ai": {
    "languages": [
      {
        "name": "English",
        "code": "en-US",
        "voice": "elevenlabs.josh",
        "params": {
          "stability": 0.6,
          "similarity": 0.8
        }
      },
      {
        "name": "Spanish",
        "code": "es",
        "voice": "elevenlabs.maria",
        "params": {
          "stability": 0.4,
          "similarity": 0.9
        }
      }
    ]
  }
}
```
</CodeBlock>
</CodeBlocks>
