Stop noise reduction (which was started with [`denoise`](/docs/swml/reference/calling/denoise)).

<ParamField path="stop_denoise" type="object" required={true} toc={true}>
  An empty object that accepts no parameters.
</ParamField>


## **Variables**

Set by the method:

- **denoise_result:** (out) `off`, set only when the request to stop noise reduction succeeds. If the stop fails, for example because noise reduction isn't on, `denoise_result` keeps its previous value (or stays unset). `off` reports the stop request, not the effect on the audio.

## **Examples**

### Stop denoise

This example assumes noise reduction was already started with [`denoise`](/docs/swml/reference/calling/denoise) earlier in the call.

<CodeBlocks>
<CodeBlock title="YAML">
```yaml
version: 1.0.0
sections:
  main:
    - stop_denoise: {}
    - play:
        url: 'say: Denoising ${denoise_result}'
```
</CodeBlock>
<CodeBlock title="JSON">
```json
{
  "version": "1.0.0",
  "sections": {
    "main": [
      {
        "stop_denoise": {}
      },
      {
        "play": {
          "url": "say: Denoising ${denoise_result}"
        }
      }
    ]
  }
}
```
</CodeBlock>
</CodeBlocks>
