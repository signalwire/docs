Start noise reduction. For an inbound call that hasn't been answered and isn't ending, the method attempts to answer it before starting noise reduction. You can stop it at any time using [`stop_denoise`](/docs/swml/reference/calling/stop-denoise).

<ParamField path="denoise" type="object" required={true} toc={true}>
  An empty object that accepts no parameters.
</ParamField>


## **Variables**

Set by the method:

- **denoise_result:** (out) `on` | `failed`. `on` means the request to start noise reduction was accepted; it reports the request, not the effect on the audio. `failed` means the start request didn't succeed, which includes calling `denoise` while noise reduction is already on, so `failed` doesn't mean noise reduction is off.

## **Examples**

### Start denoise

<CodeBlocks>
<CodeBlock title="YAML">
```yaml
version: 1.0.0
sections:
  main:
    - answer: {}
    - denoise: {}
    - play:
        url: 'say: Denoising ${denoise_result}'
```
</CodeBlock>
