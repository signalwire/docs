Join an ad-hoc audio conference started on either the SignalWire or Compatibility API.
This method allows you to connect the current call to a named conference where multiple participants can communicate simultaneously.

## **Properties**

<ParamField path="join_conference" type="object" required={true} toc={true}>
  An object that accepts the following properties.
</ParamField>

<Indent>

<ParamField path="join_conference.name" type="string" required={true} toc={true}>
  Name of conference.
</ParamField>


<ParamField path="join_conference.muted" type="boolean" default="false" toc={true}>
  Whether to join the conference in a muted state. If set to `true`, the participant will be muted upon joining.
</ParamField>


<ParamField path="join_conference.beep" type="string" default="true" toc={true}>
  Sets the behavior of the beep sound when joining or leaving the conference.

  **Possible Values**: `true`, `false`, `onEnter`, `onExit`
</ParamField>

<ParamField path="join_conference.start_on_enter" type="boolean" default="true" toc={true}>
  Whether this participant can start the conference. A conference starts once at least one participant with `start_on_enter` set to `true` has joined and the number of participants has reached `min_participants` (2 by default). Until then, participants wait.
</ParamField>


<ParamField path="join_conference.end_on_exit" type="boolean" default="false" toc={true}>
  Ends the conference when the main participant leaves. This means the end action will not wait on more participants to leave before ending.
</ParamField>


<ParamField path="join_conference.wait_url" type="string" toc={true}>
  A URL that SignalWire requests with an HTTP `GET` while this participant waits for the conference to start. Default hold music is played if not set. Set it to an empty string (`""`) to play silence instead.
</ParamField>


<ParamField path="join_conference.max_participants" type="integer" default="100000" toc={true}>
  The maximum number of participants allowed in the conference. If the limit is reached, new participants will not be able to join.
</ParamField>


<ParamField path="join_conference.min_participants" type="integer" default="2" toc={true}>
  The number of participants that must join before the conference starts. Set it to `1` to let a single participant with `start_on_enter` start the conference. Use a value from 1 up to `max_participants`. When both are given as numbers, a `min_participants` larger than `max_participants` is rejected. A value that is outside that range when the call runs, for example from a variable, falls back to 2.

  Like `max_participants`, it is set when the conference is created; joining an existing conference doesn't change it.
</ParamField>


<ParamField path="join_conference.record" type="string" default="do-not-record" toc={true}>
  Enables or disables recording of the conference. With `record-from-start`, recording starts once at least two participants have joined, even if `min_participants` lets the conference start earlier. Recording is configured when the conference is created.

  **Possible Values**: `do-not-record`, `record-from-start`
</ParamField>

<ParamField path="join_conference.region" type="string" default="global" toc={true}>
  Specifies the geographical region requested for hosting the conference.

  **Possible Values**: `global`, `us`, `eu`, `ch`
</ParamField>


<ParamField path="join_conference.trim" type="string" default="trim-silence" toc={true}>
  If set to `trim-silence`, it will remove silence from the start of the recording. If set to `do-not-trim`, it will keep the silence.

  **Possible Values**: `trim-silence`, `do-not-trim`
</ParamField>

<ParamField path="join_conference.coach" type="string" toc={true}>
  Joins the conference in coaching mode for the participant identified by the given [call SID](/docs/platform/what-is-a-sid). The coach hears the whole conference, but is heard only by the coached participant -- the other participants cannot hear the coach. Use this to whisper guidance to an agent while they are on a live call.

  The call SID must belong to a call that is currently connected to the in-progress conference. Specifying a call SID that does not exist or is no longer connected will result in a failure.
</ParamField>


<ParamField path="join_conference.status_callback_event" type="string" toc={true}>
  A space-separated list of one or more events to listen for and send to the status callback URL. When `status_callback` is set and this list is not set or empty, only `end` is sent.

  **Possible Values**: `start`, `end`, `join`, `leave`, `mute`, `hold`, `modify`, `speaker`, `announcement`
</ParamField>

<ParamField path="join_conference.status_callback_event_type" type="string" toc={true}>
  The content type used when sending status events to the status callback URL.

  **Possible Values**: `cxml`, `laml`, `relay`
</ParamField>

<ParamField path="join_conference.status_callback" type="string" toc={true}>
  The URL to which status events will be sent. This URL must be publicly accessible and able to handle HTTP requests. Learn more about [status callbacks][statuscallbacks].
</ParamField>


<ParamField path="join_conference.status_callback_method" type="string" default="POST" toc={true}>
  The HTTP method to use when sending status events to the status callback URL. Notifications in the `relay` format are always sent with `POST`, even if `GET` is set.

  **Possible Values**: `GET`, `POST`
</ParamField>

<ParamField path="join_conference.recording_status_callback" type="string" toc={true}>
  The URL to which recording status events will be sent. This URL must be publicly accessible and able to handle HTTP requests. Learn more about [status callbacks][statuscallbacks].
</ParamField>


<ParamField path="join_conference.recording_status_callback_method" type="string" default="POST" toc={true}>
  The HTTP method to use when sending recording status events to the recording status callback URL. Notifications in the `relay` format are always sent with `POST`, even if `GET` is set.

  **Possible Values**: `GET`, `POST`
</ParamField>

<ParamField path="join_conference.recording_status_callback_event" type="string" toc={true}>
  A space-separated list of one or more events to listen for and send to the recording status callback URL.

  **Possible Values**: `in-progress`, `completed`, `absent`
</ParamField>

<ParamField path="join_conference.recording_status_callback_event_type" type="string" toc={true}>
  The content type used when sending recording status events to the recording status callback URL.

  **Possible Values**: `cxml`, `laml`, `relay`
</ParamField>

<ParamField path="join_conference.emit_call_quality" type="boolean" default="false" toc={true}>
  When `true`, a `participant-call-quality` event with audio quality statistics is sent when this participant leaves, if statistics are available. To receive it, include `leave` in `status_callback_event`. See [status callbacks][statuscallbacks] for the fields.
</ParamField>


<ParamField path="join_conference.stream" type="object" toc={true}>
  Attach a WebSocket stream to the conference. Conference audio is streamed to the `url`, enabling real-time audio processing, transcription, or AI agents that listen to the conference. Uses the same stream schema as the `stream` device type in [`connect`](/docs/swml/reference/calling/connect).

  The stream is set up only while the conference has not started yet. A `stream` sent by a participant joining a conference that has already started does not add a stream.
</ParamField>

<Indent>

<ParamField path="join_conference.stream.url" type="string" required={true} toc={true}>
  Secure WebSocket URL (must start with `wss://`) that the conference audio is streamed to. Plain `ws://` is not supported.
</ParamField>


<ParamField path="join_conference.stream.name" type="string" toc={true}>
  A friendly name to identify the stream at the WebSocket endpoint.
</ParamField>


<ParamField path="join_conference.stream.codec" type="string" toc={true}>
  Audio codec for the streamed audio. Supported values: `PCMU`, `PCMA`, `G722`, `L16`. Codec can include rate and ptime modifiers (e.g., `PCMU@40i`, `L16@24000h@40i`).
</ParamField>


<ParamField path="join_conference.stream.status_url" type="string" toc={true}>
  HTTP or HTTPS URL to which stream status events will be sent.
</ParamField>


<ParamField path="join_conference.stream.status_url_method" type="string" default="POST" toc={true}>
  The HTTP method to use when sending stream status events to the status URL.

  **Possible Values**: `GET`, `POST`
</ParamField>

<ParamField path="join_conference.stream.realtime" type="boolean" default="false" toc={true}>
  Realtime mode for the conference stream. A boolean `realtime` value is accepted, but it is not currently applied to the conference stream.
</ParamField>


<ParamField path="join_conference.stream.authorization_bearer_token" type="string" toc={true}>
  Bearer token sent in the `Authorization` header when the WebSocket connection is opened, so your endpoint can authenticate the request.
</ParamField>


<ParamField path="join_conference.stream.custom_parameters" type="object" toc={true}>
  Custom key-value pairs delivered to your WebSocket endpoint when the stream connects. Use them to pass context such as a session or customer ID.
</ParamField>

</Indent>

</Indent>

## **Variables**

<ParamField path="join_conference_result" type="string" toc={true}>
  The result of the conference join. Possible values: `joined` (the participant joined the conference) or `failed` (the participant could not join). The value is set when `join_conference` finishes, not at the moment the participant joins.
</ParamField>


<ParamField path="return_value" type="string" toc={true}>
  Contains the same value as `join_conference_result` for use in conditional logic.
</ParamField>


## **StatusCallbacks**

<Markdown src="/snippets/common/_status-callback-advisory.mdx" />

A POST request will be sent to `status_callback` with a JSON payload for events specified in `status_callback_event`. Both conference and recording events share the same `calling.conference` event type; the specific event is identified by `params.status`.

<ParamField path="event_type" type="string" toc={true}>
  The type of event. Always `calling.conference`.
</ParamField>


<ParamField path="event_channel" type="string" toc={true}>
  The channel for the event. For participant events, the channel of the participant's call. For conference and recording events, the conference ID.
</ParamField>


<ParamField path="timestamp" type="number" toc={true}>
  Unix timestamp (float) when the event was generated.
</ParamField>


<ParamField path="project_id" type="string" toc={true}>
  The project ID associated with the call.
</ParamField>


<ParamField path="space_id" type="string" toc={true}>
  The Space ID associated with the call.
</ParamField>


<ParamField path="params" type="object" toc={true}>
  An object containing conference-specific parameters.
</ParamField>

<Indent>

<ParamField path="params.call_id" type="string" toc={true}>
  The call ID of the participant.
</ParamField>


<ParamField path="params.name" type="string" toc={true}>
  The name of the conference.
</ParamField>


<ParamField path="params.conference_id" type="string" toc={true}>
  The unique ID of the conference.
</ParamField>


<ParamField path="params.status" type="string" toc={true}>
  The conference event. **Valid values:** `conference-start`, `conference-end`, `participant-join`, `participant-leave`, `participant-mute`, `participant-unmute`, `participant-hold`, `participant-unhold`, `participant-speech-start`, `participant-speech-stop`, `participant-modify`, `participant-call-quality`, `announcement-end`, `announcement-fail`, `record-start`, `record-pause`, `record-resume`, `record-stop`.

  `announcement-end` and `announcement-fail` are sent when `status_callback_event` includes `announcement`. `participant-call-quality` is sent when a participant that joined with `emit_call_quality: true` leaves, if `status_callback_event` includes `leave` and audio statistics are available.
</ParamField>


<ParamField path="params.conference_node_id" type="string" toc={true}>

<ParamField path="params.size" type="number" toc={true}>

### Basic Conference Join

<CodeBlocks>
<CodeBlock title="YAML">
```yaml
version: 1.0.0
sections:
  main:
    - join_conference:
        name: "team_meeting"
```
</CodeBlock>
<CodeBlock title="JSON">
```json
{
  "version": "1.0.0",
  "sections": {
    "main": [
      {
        "join_conference": {
          "name": "team_meeting"
        }
      }
    ]
  }
}
```
</CodeBlock>
</CodeBlocks>
