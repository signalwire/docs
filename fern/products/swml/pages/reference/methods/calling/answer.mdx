Answer incoming call and set an optional maximum duration.

## **Properties**

<ParamField path="answer" type="object" required={true} toc={true}>
  An object that accepts the following properties.
</ParamField>

<Indent>

<ParamField path="answer.max_duration" type="integer | string" default="14400 seconds (4 hours)" toc={true}>
  Maximum duration in seconds for the call. Also accepts a SWML variable reference (string) such as `${vars.max_call_seconds}`, which is substituted when the method runs and must resolve to a valid duration.
</ParamField>


<ParamField path="answer.codecs" type="string | string[]" toc={true}>
  Codecs to offer, as a comma-separated string (`"PCMU,PCMA,OPUS"`) or an array of strings with one codec per entry. Each array entry can also be a SWML variable reference, resolved when the method runs.

  Valid codecs depend on the call type:

  - Phone calls: `PCMU`, `PCMA`, `G722`, `G729`, `AMR-WB`.
  - SIP and WebRTC calls: all of the above, plus `OPUS`, `VP8`, `H264`.

  If the requested codecs aren't valid for the call type, they're ignored, a [`relay_script_method_parameter_invalid_value`](/docs/swml/reference/errors) warning is reported, and `answer` continues without them.
</ParamField>


<ParamField path="answer.username" type="string" toc={true}>
  Username to use for SIP authentication challenges. Applied only together with a `password` that isn't empty after variable expansion.
</ParamField>


<ParamField path="answer.password" type="string" toc={true}>
  Password to use for SIP authentication challenges. When it isn't empty after variable expansion, it's applied together with `username`.
</ParamField>

</Indent>

## Variables

Set by the method:

- **answer_result:** (out) `success` or `failed`. `success` is also set when there was nothing to answer, for example on an outbound call or a call that's already answered, so it doesn't by itself mean this method newly answered the call. `failed` means the answer request for this invocation was unsuccessful.

### Maximum duration from a variable

<CodeBlocks>
<CodeBlock title="YAML">
```yaml

  main:
    - set:
        max_call_seconds: 600
    - answer:
        max_duration: '${vars.max_call_seconds}'
```
</CodeBlock>
<CodeBlock title="JSON">
```json
{
  "version": "1.0.0",
  "sections": {
    "main": [
      {
        "set": {
          "max_call_seconds": 600
        }
      },
      {
        "answer": {
          "max_duration": "${vars.max_call_seconds}"
        }
      }
    ]
  }
}
```
</CodeBlock>
</CodeBlocks>
