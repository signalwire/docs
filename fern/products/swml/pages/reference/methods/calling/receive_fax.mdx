Receive a fax being delivered to this call.

## **Properties**

<ParamField path="receive_fax" type="object" required={true} toc={true}>
  An object that accepts the following properties.
</ParamField>

<Indent>

<ParamField path="receive_fax.status_url" type="string" toc={true}>
  HTTP or HTTPS URL to deliver receive fax status events. Learn more about [status callbacks][statuscallbacks].

  Also accepts a SWML variable reference (string), substituted when the method runs. The resolved value must be an HTTP or HTTPS URL.
</ParamField>

</Indent>

## **Variables**

Set by the method:

- **receive_fax_document:** (out) URL of received document.
- **receive_fax_identity:** (out) identity of this fax station.
- **receive_fax_remote_identity:** (out) identity of the sending fax station.
- **receive_fax_pages:** (out) number of pages received.
- **receive_fax_result_code:** (out) fax status code.
- **receive_fax_result_text:** (out) description of fax status code.
- **receive_fax_result:** (out) `success` | `failed`.

#### Page progress events

A separate callback is sent for each page as the fax progresses:

<ParamField path="params.fax.type" type="string" toc={true}>
  Always `"page"` for page progress events.
</ParamField>

<ParamField path="params.fax.params.direction" type="string" toc={true}>
  The direction of the fax.
</ParamField>

<ParamField path="params.fax.params.number" type="number" toc={true}>
  The page number that was just processed.
</ParamField>


### Raw JSON example

```json
{
  "event_type": "calling.call.fax",
  "event_channel": "swml:xxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
  "timestamp": 1640000000.123,
  "project_id": "xxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
  "space_id": "xxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
  "params": {
    "call_id": "xxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
    "node_id": "xxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
    "control_id": "xxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
    "fax": {
      "type": "finished",
      "params": {
        "direction": "receive",
        "identity": "+15551231234",
        "remote_identity": "+15553214321",
        "document": "https://example.com/received-fax.pdf",
        "pages": 3,
        "success": true,
        "result": 0,
        "result_text": "OK",
        "format": "pdf"
      }
    }
  }
}
```

The `document` value above is illustrative. Use the URL returned in the event.

### Error events

When the fax operation can't be executed, SignalWire may send an event with `event_type` set to `calling.error` to `status_url` instead of a `calling.call.fax` event. Its `params` object has no `fax` object. It carries the call identifiers and these fields:

<ParamField path="params.error.code" type="string" toc={true}>
  The error code.
</ParamField>


<ParamField path="params.error.message" type="string" toc={true}>
  A description of the error.
</ParamField>


<ParamField path="params.request" type="object" toc={true}>
  A copy of the request that failed, included for diagnostics only. Its shape isn't a stable contract.
</ParamField>

Check `event_type` before reading the rest of the payload. Not every failure produces an error event.

## **Examples**

### Receive a fax and post a result to a webhook

<CodeBlocks>
<CodeBlock title="YAML">
```yaml
version: 1.0.0
sections:
  main:
    - receive_fax: {}
    - execute:
        dest: 'https://<NGROK UUID>.ngrok-free.app'
```
</CodeBlock>
<CodeBlock title="JSON">
```json
{
  "version": "1.0.0",
  "sections": {
    "main": [
      {
        "receive_fax": {}
      },
      {
        "execute": {
          "dest": "https://<NGROK UUID>.ngrok-free.app"
        }
      }
    ]
  }
}
```
</CodeBlock>
</CodeBlocks>

In this example, when a fax is received, a POST request will be sent to the URL with all
the fax related variables (like `receive_fax_document`) already set.
Refer to the [`execute`](/docs/swml/reference/calling/execute) statement's documentation for more details on this behavior.
