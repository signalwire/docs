Start live translation of the call. The translation will be sent to the specified webhook URL.

## **Properties**

<ParamField path="live_translate" type="object" required={true} toc={true}>
  An object that accepts the following properties.
</ParamField>

<Indent>

<ParamField path="live_translate.action" type="string | object" required={true} toc={true}>
  The action to perform. See [actions](#actions) below.
  Also accepts a [SWML variable](/docs/swml/reference/variables) reference that resolves to one of the supported actions.
</ParamField>

</Indent>

## **Actions**

The `action` property controls the translation session. Use `start` to begin translating with configuration options, `stop` to end an active session, `summarize` to request an on-demand AI summary mid-session, or `inject` to insert a translated message into the conversation.

`start.direction` and its items, `start.speech_engine`, `start.filter_from`, `start.filter_to`, and `inject.direction` also accept a [SWML variable](/docs/swml/reference/variables) reference. The value it resolves to must be a value the property accepts: a listed value, or for the filters, a preset or a `prompt:` custom filter.

<ParamField path="start.webhook" type="string" toc={true}>
  The URL to receive translation events via HTTP POST.
  When `live_events` is enabled, partial results are sent as they occur.
  When `ai_summary` is enabled, summaries in both languages are sent when the session ends.

<ParamField path="start.from_lang" type="string" required={true} toc={true}>
  One of the two languages in the translation. The first direction in `direction` is translated into this language; a second direction is translated from it.
  Use a code that `speech_engine` recognizes (with the default Deepgram engine, a code from [Deepgram's Nova-3 language table](https://developers.deepgram.com/docs/models-languages-overview#nova-3)) and that the voice speaking this language supports.
  See [direction order](#direction-order).
</ParamField>

<ParamField path="start.to_lang" type="string" required={true} toc={true}>
  The other language in the translation. The first direction in `direction` is translated from this language; a second direction is translated into it.
  Use a code that `speech_engine` recognizes (with the default Deepgram engine, a code from [Deepgram's Nova-3 language table](https://developers.deepgram.com/docs/models-languages-overview#nova-3)) and that the voice speaking this language supports.
  See [direction order](#direction-order).
</ParamField>

<ParamField path="start.from_voice" type="string" default="azure.en-US-RyanMultilingualNeural" toc={true}>
  The TTS voice that speaks translations into `from_lang` (the first direction in `direction`).
  See [supported voices & languages](/docs/platform/voice/tts).
</ParamField>

<ParamField path="start.to_voice" type="string" default="azure.en-US-RyanMultilingualNeural" toc={true}>
  The TTS voice that speaks translations into `to_lang` (a second direction in `direction`).
  See [supported voices & languages](/docs/platform/voice/tts).
</ParamField>

<ParamField path="start.filter_from" type="string" toc={true}>
  Translation filter for translations into `to_lang` (a second direction in `direction`).
  Adjusts the tone or style of translated speech.

  Preset values: `polite` (removes insults, maintains sentiment), `rude` (adds insults, maintains sentiment),
  `professional` (removes slang), `shakespeare` (iambic pentameter), `gen-z` (Gen-Z slang and expressions).

  For custom filters, use the `prompt:` prefix (e.g., `prompt:Use formal business language`).
</ParamField>

<ParamField path="start.filter_to" type="string" toc={true}>
  Translation filter for translations into `from_lang` (the first direction in `direction`).
  Adjusts the tone or style of translated speech.

  Preset values: `polite`, `rude`, `professional`, `shakespeare`, `gen-z`.

  For custom filters, use the `prompt:` prefix.
</ParamField>

<ParamField path="start.live_events" type="boolean" default="false" toc={true}>
  Whether to enable live events.
</ParamField>

<ParamField path="start.ai_summary" type="boolean" default="false" toc={true}>
  Whether to enable automatic AI summarization.
  When enabled, AI-generated summaries in both languages will be sent to your webhook when the translation session ends.
</ParamField>

<ParamField path="start.speech_timeout" type="integer" default="60000" toc={true}>
  The timeout for speech recognition in milliseconds. Minimum value: `1500`.
</ParamField>

<ParamField path="start.vad_silence_ms" type="integer" default="700 | 500" toc={true}>
  Voice activity detection silence time in milliseconds.
  Default depends on the speech engine: `700` for Deepgram, `500` for Google. Omitting the value or setting it to `0` uses the engine default.
</ParamField>

<ParamField path="start.vad_thresh" type="integer" default="400" toc={true}>
  Voice activity detection threshold. Range: `0` to `1800`.
</ParamField>

<ParamField path="start.debug_level" type="integer" default="0" toc={true}>
  Debug level for logging.
  Ignored unless SignalWire has enabled debugging on its side, so you can leave it unset.
</ParamField>

<ParamField path="start.direction" type="string[]" required={true} toc={true}>
  The call directions to translate, as an ordered array. Possible values: `remote-caller`, `local-caller`.
  At least one direction is required.
  The order of the array decides how `from_lang`, `to_lang`, the voices, and the filters are assigned; see [direction order](#direction-order).
</ParamField>

<ParamField path="start.speech_engine" type="string" default="deepgram" toc={true}>
  The speech recognition engine to use. Possible values: `deepgram`, `google`.
</ParamField>

<ParamField path="start.ai_summary_prompt" type="string" toc={true}>
  The AI prompt that instructs how to summarize the conversation when `ai_summary` is enabled.

<Tab title="stop">

Set `action` to the string `"stop"` to stop the live translation session.

This action is designed for use on active calls that have an existing translation session running.
You can send this action via the [Call Commands REST API](/docs/apis/rest/calls/call-commands),
or include it in a SWML section executed via [`transfer`](/docs/swml/reference/calling/transfer) or [`execute`](/docs/swml/reference/calling/execute) during a call.

</Tab>

Pass a `summarize` object instead to override the webhook or the prompt.

## Direction order

`start.direction` is an ordered array, and the order decides how the language, voice, and filter settings are applied to each direction:

| Position in `direction` | Translated from | Translated into | Voice | Filter |
|---|---|---|---|---|
| First | `to_lang` | `from_lang` | `from_voice` | `filter_to` |
| Second, if present | `from_lang` | `to_lang` | `to_voice` | `filter_from` |

For example, with `from_lang: en-US`, `to_lang: es-ES`, and `direction: [remote-caller, local-caller]`, the `remote-caller` direction is translated from Spanish into English and spoken with `from_voice`, and the `local-caller` direction is translated from English into Spanish and spoken with `to_voice`. Listing `local-caller` first swaps these assignments.

## Action usage context

| Action | Call start | Live call |
|--------|-----------|-----------|
| `start` | ✅ Primary use | ✅ Can start mid-call |
| `stop` | ❌ No session to stop | ✅ Designed for this |
| `summarize` | ❌ No content to summarize | ✅ Designed for this |
| `inject` | ❌ No session exists | ✅ Designed for this |

**Call start:** The initial SWML document returned when a call first arrives.

**Live call:** Actions sent to active calls via the [Call Commands REST API](/docs/apis/rest/calls/call-commands) or SWML sections executed via [`transfer`](/docs/swml/reference/calling/transfer) or [`execute`](/docs/swml/reference/calling/execute) during a call.

<Info title="ai_summary vs summarize action">
- **`ai_summary: true`** (in `start`): Automatically generates summary when session **ends**
- **`summarize` action**: On-demand summary **during** an active session
</Info>

## **Examples**

<Tabs>
  <Tab title="Start">

<CodeBlocks>
<CodeBlock title="YAML">
```yaml
version: 1.0.0
sections:
  main:
    - answer: {}
    - live_translate:
        action:
          start:
            webhook: 'https://example.com/webhook'
            from_lang: en-US
            to_lang: es-ES
            from_voice: elevenlabs.josh
            to_voice: elevenlabs.josh
            live_events: true
            direction:
              - remote-caller
              - local-caller
            speech_engine: deepgram
```
</CodeBlock>
<CodeBlock title="JSON">
```json
{
  "version": "1.0.0",
  "sections": {
    "main": [
      { "answer": {} },
      {
        "live_translate": {
          "action": {
            "start": {
              "webhook": "https://example.com/webhook",
              "from_lang": "en-US",
              "to_lang": "es-ES",
              "from_voice": "elevenlabs.josh",
              "to_voice": "elevenlabs.josh",
              "live_events": true,
              "direction": ["remote-caller", "local-caller"],
              "speech_engine": "deepgram"
            }
          }
        }
      }
    ]
  }
}
```
</CodeBlock>
