Event emitted when the server pushes media params.

The event is emitted whether or not the constraints were applied — read [`applied`](#applied) to tell the two apart. A push naming a leg this call does not hold emits nothing at all, because the event carries no leg identity to report it against.

## **Properties**

<ParamField path="applied" type="boolean" required toc={true}>
  `false` when the constraints did not reach every sender of a pushed kind: the sender carries media the SDK did not capture, the browser refused the constraints and re-acquisition failed, or the leg sends no media of that kind at all.
</ParamField>

<ParamField path="audio" type="MediaTrackConstraints" toc={true}>
  Audio constraints pushed by the server, if any. See [`MediaTrackConstraints`](https://developer.mozilla.org/en-US/docs/Web/API/MediaTrackConstraints).
</ParamField>

<ParamField path="timestamp" type="number" required toc={true}>
  Timestamp when the event occurred (epoch ms).
</ParamField>

<ParamField path="video" type="MediaTrackConstraints" toc={true}>
  Video constraints pushed by the server, if any. See [`MediaTrackConstraints`](https://developer.mozilla.org/en-US/docs/Web/API/MediaTrackConstraints).
</ParamField>
