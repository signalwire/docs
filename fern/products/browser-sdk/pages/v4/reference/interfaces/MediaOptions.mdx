Options controlling which media tracks to send and receive.

## **Extended by**

- [`DialOptions`](/docs/browser-sdk/v4/reference/interfaces/dial-options)
- [`CallOptions`](/docs/browser-sdk/v4/reference/interfaces/call-options)

## **Properties**

<ParamField path="audio" type="boolean" toc={true}>
  Enable audio input. Defaults to `true` when not specified.
</ParamField>

<ParamField path="fallbackToReceiveOnly" type="boolean" default="true" toc={true}>
  When local media can't be acquired (permission denied or device unavailable), continue the call in receive-only mode instead of failing. Ignored when the call is not set to receive any media — with nothing to receive there is no call left to fall back to, so the failure is fatal.
</ParamField>

<ParamField path="inputAudioDeviceConstraints" type="MediaTrackConstraints" toc={true}>
  Custom constraints for the audio input track. See [`MediaTrackConstraints`](https://developer.mozilla.org/en-US/docs/Web/API/MediaTrackConstraints).
</ParamField>

<ParamField path="inputAudioStream" type="MediaStream" toc={true}>
  Pre-existing audio stream to use instead of `getUserMedia`. See [`MediaStream`](https://developer.mozilla.org/en-US/docs/Web/API/MediaStream).
</ParamField>

<ParamField path="inputVideoDeviceConstraints" type="MediaTrackConstraints" toc={true}>
  Custom constraints for the video input track. See [`MediaTrackConstraints`](https://developer.mozilla.org/en-US/docs/Web/API/MediaTrackConstraints).
</ParamField>

<ParamField path="inputVideoStream" type="MediaStream" toc={true}>
  Pre-existing video stream to use instead of `getUserMedia`. See [`MediaStream`](https://developer.mozilla.org/en-US/docs/Web/API/MediaStream).
</ParamField>

<ParamField path="receiveAudio" type="boolean" toc={true}>
  Whether to receive remote audio.
</ParamField>

<ParamField path="receiveVideo" type="boolean" toc={true}>
  Whether to receive remote video.
</ParamField>

<ParamField path="video" type="boolean" toc={true}>
  Enable video input. Defaults to `false` when not specified.
</ParamField>
