```ts
stopScreenShare(): Promise<void>
```
Stops the current screen share. Safe to call when no share is active or while one is already stopping — it returns without sending a second teardown.

Stopping a share whose leg has not finished connecting rejects the pending [`startScreenShare`](/docs/browser-sdk/v4/reference/self-participant/start-screen-share) call with [`AuxiliaryLegCancelledError`](/docs/browser-sdk/v4/reference/errors/auxiliary-leg-cancelled-error), so the caller can tell a cancel apart from a share that actually came up.

## **Returns**

`Promise<void>`

## **Examples**

```ts
await selfParticipant.stopScreenShare();
```
