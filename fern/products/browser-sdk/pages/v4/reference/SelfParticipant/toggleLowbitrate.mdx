```ts
toggleLowbitrate(): Promise<void>
```
Toggles low-bitrate mode for this participant's media. When enabled the server reduces the bitrate it sends for this member — useful on a constrained connection.

Read the current state from [`lowbitrate$`](/docs/browser-sdk/v4/reference/self-participant/lowbitrate$).

## **Returns**

`Promise<void>`

## **Inherited from**

[`Participant`](/docs/browser-sdk/v4/reference/participant).[`toggleLowbitrate`](/docs/browser-sdk/v4/reference/participant#togglelowbitrate)

## **Examples**

```ts
await selfParticipant.toggleLowbitrate();
```
