```ts
get self$(): Observable<CallSelfParticipant>
```
Observable of the local (self) participant.

It withholds emission until self exists, so it never emits `null` — unlike the `self` snapshot getter below. Awaiting its first value is the simplest way to wait out [`CallNotReadyError`](/docs/browser-sdk/v4/reference/errors/call-not-ready-error) before issuing call control.

## self

```ts
get self(): CallSelfParticipant | null
```

The local participant, or `null` if not yet joined.

## **Examples**

```ts
call.self$.subscribe((self) => {
  console.log('self:', self);
});
```
