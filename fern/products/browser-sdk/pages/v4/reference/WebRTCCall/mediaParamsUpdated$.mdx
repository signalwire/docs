```ts
get mediaParamsUpdated$(): Observable<MediaParamsEvent>
```
Observable that emits when the server pushes media params.

It emits whether or not the constraints were applied — read [`applied`](/docs/browser-sdk/v4/reference/interfaces/media-params-event) on the event to tell the two apart. A push naming a leg this call does not hold emits nothing at all, because the event carries no leg identity to report it against.

## **Examples**

```ts
call.mediaParamsUpdated$.subscribe(({ audio, video, applied }) => {
  if (!applied) {
    console.warn('Server pushed media params the call could not apply', { audio, video });
  }
});
```
