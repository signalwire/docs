Amazon Web Services' Polly TTS engine includes several models to accommodate different use cases.

## Models

SignalWire supports the following three Amazon models. 

<CardGroup cols={3}>

  <Card title="Standard" href="https://docs.aws.amazon.com/polly/latest/dg/standard-voices.html">
    Polly Standard is a traditional, cost-effective, and reliable TTS model.
    
    Example voice ID string: `amazon.Emma:en-GB` or `amazon.Emma:standard:en-GB`
  </Card>

  <Card title="Neural" href="https://docs.aws.amazon.com/polly/latest/dg/neural-voices.html">
    Polly Neural produces more natural, human-like speech than Polly Standard.
    
    Example voice ID string: `amazon.Kendra:neural:en-US`
  </Card>

  <Card title="Generative" href="https://docs.aws.amazon.com/polly/latest/dg/generative-voices.html">
    Polly Generative is Amazon's largest and most realistic model.

    Example voice ID string: `amazon.Danielle:generative:en-US`
  </Card>

</CardGroup>

## Usage

Amazon voice IDs conform to the following format:

```
amazon.<voice>:<model>:<language>
```

| Parameter                                                 | Possible values                                                               | Description                             |
| :-------------------------------------------------------- | :---------------------------------------------------------------------------- | :-------------------------------------- |
| `engine`<br/><span class="required-arg">required</span>   | <ul><li>`amazon`</li><li>`polly` (will be deprecated in the future)</li></ul> | TTS engine                              |
| `voice`<br/><span class="required-arg">required</span>    | Choose from the [**Name/ID** column][polly]                                   | Voice ID                                |
| `model`<br/><span class="optional-arg">optional</span>    | `standard`, `neural`, or `generative`                                         | Amazon Polly model. Default: `standard` |
| `language`<br/><span class="optional-arg">optional</span> | Choose from the [**Language code** column][polly]                             | Sets model language. Default: `en-US`   |

**Examples:**
```
amazon.Joanna
amazon.Joanna:standard:en-US
amazon.Kendra:neural:en-US
amazon.Matthew:neural:en-US
amazon.Danielle:generative:en-US
amazon.Amy:generative:en-GB
amazon.Aditi:standard:hi-IN
```

**Simplified Format:**

For voices that only support one model, you can omit the model parameter:
```
amazon.<voice>:<language>
```

Example: `amazon.Aditi:hi-IN` (Standard model implied)

<Note>
The `polly` engine code is being deprecated. Use `amazon` instead.
</Note>

<Warning>
Amazon Polly has a limit of 3000 chargeable characters in a single request.
If your TTS request is longer than 3000 characters, you will experience silence.
</Warning>

## Use Amazon Polly voices on a call

An Amazon Polly voice string such as `amazon.Ruth:neural` works wherever SignalWire speaks text: an AI
agent's `languages`, the `say_voice` of SWML's `play`, and a `tts` media item sent with Relay or
the REST Calling API. The examples below all use `amazon.Ruth:neural`. To control speech while it plays, see
[Speak text on a call](/docs/platform/voice/speak-text).

Replace these values in the samples:

| Value | Replace with |
|---|---|
| `<YOUR_BASIC_AUTH_PASSWORD>` | A password you choose for your SWML server; SignalWire sends it from the URL you give it |
| `<YOUR_PROJECT_ID>` | Your Project ID |
| `<YOUR_API_TOKEN>` | An API token with the **Voice** permission, used only in server code |
| `<YOUR_SPACE>` | Your Space's subdomain in `<YOUR_SPACE>.signalwire.com` |
| `<YOUR_CALL_ID>` | The ID of an answered call, for the REST command |

### Give an AI agent an Amazon Polly voice via SWML

The [`languages`](/docs/swml/reference/calling/ai/languages#use-voice-strings) list of the SWML
[`ai`](/docs/swml/reference/calling/ai) method sets the voice an AI agent speaks in. The
[Server SDKs](/docs/server-sdks) build the document and serve it at `/swml` on port 3000, only to
requests that carry the username `signalwire` and your password.

<CodeBlocks>
<CodeBlock title="Python — SWML builder">
```python
# Install: python -m pip install signalwire-sdk
# Save as polly_ai_agent.py and run: python polly_ai_agent.py
from signalwire import SWMLBuilder, SWMLService

service = SWMLService(
    name="polly-ai-agent",
    route="/swml",
    port=3000,
    basic_auth=("signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"),
)
SWMLBuilder(service).ai(
    prompt_text="You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride.",
    languages=[{
        "name": "English",
        "code": "en-US",
        "voice": "amazon.Ruth:neural",
    }],
)

service.serve()
```
</CodeBlock>
<CodeBlock title="TypeScript — SWML builder">
```typescript
// Install: npm install @signalwire/sdk
// This sample also runs as JavaScript: save as polly-ai-agent.mjs,
// then run: node polly-ai-agent.mjs
import { SWMLService } from "@signalwire/sdk";

const service = new SWMLService({
  name: "polly-ai-agent",
  route: "/swml",
  port: 3000,
  basicAuth: ["signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"],
});
service.getBuilder().ai({
  // @ts-expect-error The ai verb takes a { text } prompt; the SDK types prompt as a string or array.
  prompt: { text: "You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride." },
  languages: [
    { name: "English", code: "en-US", voice: "amazon.Ruth:neural" },
  ],
});

await service.serve();
```
</CodeBlock>
<CodeBlock title="YAML">
```yaml
version: 1.0.0
sections:
  main:
    - ai:
        prompt:
          text: "You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride."
        languages:
          - name: English
            code: en-US
            voice: "amazon.Ruth:neural"
```
</CodeBlock>
<CodeBlock title="JSON">
```json

  "sections": {
    "main": [
      {
        "ai": {
          "prompt": {
```

To send calls from your phone number to the server, follow
[Answer a call via SWML](/docs/platform/voice/make-and-receive-calls#answer-a-call-via-swml).
Call the number, and the agent greets you in the Amazon Polly voice. If you hear a different voice, the
voice string isn't in SignalWire's catalog, so the call falls back to a default voice. See
[Custom and cloned voices](/docs/platform/voice/tts#custom-and-cloned-voices).

### Speak text in an Amazon Polly voice via SWML

The SWML builder's `say()` writes a [`play`](/docs/swml/reference/calling/play) with a `say:` URL
and the voice in `say_voice`. This server speaks one sentence in the Amazon Polly voice, then hangs up.
Serve it and point your number at it the same way as the AI agent above.

<CodeBlocks>
<CodeBlock title="Python — SWML builder">
```python
# Install: python -m pip install signalwire-sdk
# Save as polly_tts.py and run: python polly_tts.py
from signalwire import SWMLBuilder, SWMLService

service = SWMLService(
    name="polly-tts",
    route="/swml",
    port=3000,
    basic_auth=("signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"),
)
SWMLBuilder(service).say(
    "Hello from Bayview Taxi. You are hearing Amazon Polly text to speech on SignalWire.",
    voice="amazon.Ruth:neural",
).hangup()

service.serve()
```
</CodeBlock>
<CodeBlock title="TypeScript — SWML builder">
```typescript
// Install: npm install @signalwire/sdk
// This sample also runs as JavaScript: save as polly-tts.mjs,
// then run: node polly-tts.mjs
import { SWMLService } from "@signalwire/sdk";

const service = new SWMLService({
  name: "polly-tts",
  route: "/swml",
  port: 3000,
  basicAuth: ["signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"],
});
service.getBuilder()
  .say("Hello from Bayview Taxi. You are hearing Amazon Polly text to speech on SignalWire.", {
    voice: "amazon.Ruth:neural",
  })
  .hangup();

await service.serve();
```
</CodeBlock>
<CodeBlock title="YAML">
```yaml
version: 1.0.0
sections:
  main:
    - play:
        url: "say:Hello from Bayview Taxi. You are hearing Amazon Polly text to speech on SignalWire."
        say_voice: "amazon.Ruth:neural"
    - hangup: {}
```
</CodeBlock>
<CodeBlock title="JSON">
```json
{
  "version": "1.0.0",
  "sections": {
    "main": [
      {
        "play": {
          "url": "say:Hello from Bayview Taxi. You are hearing Amazon Polly text to speech on SignalWire.",
          "say_voice": "amazon.Ruth:neural"
        }
      },
      {
        "hangup": {}
      }
    ]
  }
}
```
</CodeBlock>
</CodeBlocks>

### Speak text in an Amazon Polly voice via WebSocket (Relay)

A Relay client in the [Server SDKs](/docs/server-sdks) passes the voice string in a `tts` media
item. This handler answers calls on the `default` topic, speaks in the Amazon Polly voice, and hangs
up when the speech ends.

<CodeBlocks>
<CodeBlock title="Python — Relay client">
```python
# Install: python -m pip install signalwire-sdk
# Save as polly_relay.py and run: python polly_relay.py
from signalwire.relay import RelayClient

client = RelayClient(
    project="<YOUR_PROJECT_ID>",
    token="<YOUR_API_TOKEN>",
    contexts=["default"],
)

@client.on_call
async def handle_call(call):
    await call.answer()

    async def hang_up_after_playback(_event):
        if call.state != "ended":
            await call.hangup()

    await call.play([{
        "type": "tts",
        "params": {
            "text": "Hello from Bayview Taxi. You are hearing Amazon Polly text to speech on SignalWire.",
            "voice": "amazon.Ruth:neural",
        },
    }], on_completed=hang_up_after_playback)
    await call.wait_for_ended()

client.run()
```
</CodeBlock>
<CodeBlock title="TypeScript — Relay client">
```typescript
// Install: npm install @signalwire/sdk
// This sample also runs as JavaScript: save as polly-relay.mjs,
// then run: node polly-relay.mjs
import { RelayClient } from "@signalwire/sdk";

const client = new RelayClient({
  project: "<YOUR_PROJECT_ID>",
  token: "<YOUR_API_TOKEN>",
  contexts: ["default"],
});

client.onCall(async (call) => {
  await call.answer();
  await call.play([{
    type: "tts",
    params: {
      text: "Hello from Bayview Taxi. You are hearing Amazon Polly text to speech on SignalWire.",
      voice: "amazon.Ruth:neural",
    },
  }], {
    onCompleted: async () => {
      if (call.state !== "ended") await call.hangup();
    },
  });
  await call.waitForEnded();
});

await client.run();
```
</CodeBlock>
</CodeBlocks>

To route calls from your phone number to the handler, assign the number to a Relay Application
on the `default` topic, as described in
[Answer a call via WebSocket (Relay)](/docs/platform/voice/make-and-receive-calls#answer-a-call-via-websocket-relay).

### Speak text in an Amazon Polly voice on a call in progress via REST

To speak on a call that's already up, such as from a backend job, send
[`calling.play`](/docs/apis/rest/calls/call-commands) with the call's ID and the same `tts` media
item. `control_id` names the playback so later commands can stop or pause it.

<CodeBlocks>
<CodeBlock title="Python — REST client">
```python
# Install: python -m pip install signalwire-sdk
# Save as polly_rest.py and run: python polly_rest.py
from signalwire.rest import RestClient

client = RestClient(
    project="<YOUR_PROJECT_ID>",
    token="<YOUR_API_TOKEN>",
    host="<YOUR_SPACE>.signalwire.com",
)

client.calling.play(
    "<YOUR_CALL_ID>",
    control_id="polly-greeting",
    play=[{
        "type": "tts",
        "params": {
            "text": "Hello from Bayview Taxi. You are hearing Amazon Polly text to speech on SignalWire.",
            "voice": "amazon.Ruth:neural",
        },
    }],
)
```
</CodeBlock>
<CodeBlock title="TypeScript — REST client">
```typescript
// Install: npm install @signalwire/sdk
// This sample also runs as JavaScript: save as polly-rest.mjs,
// then run: node polly-rest.mjs
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "<YOUR_PROJECT_ID>",
  token: "<YOUR_API_TOKEN>",
  host: "<YOUR_SPACE>.signalwire.com",
});

await client.calling.play("<YOUR_CALL_ID>", [{
  type: "tts",
  params: {
    text: "Hello from Bayview Taxi. You are hearing Amazon Polly text to speech on SignalWire.",
    voice: "amazon.Ruth:neural",
  },
}], { control_id: "polly-greeting" });
```
</CodeBlock>
<CodeBlock title="cURL — Calling API">
```bash
curl -X POST "https://<YOUR_SPACE>.signalwire.com/api/calling/calls" \
  -u "<YOUR_PROJECT_ID>:<YOUR_API_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "command": "calling.play",
    "id": "<YOUR_CALL_ID>",
    "params": {
      "control_id": "polly-greeting",
      "play": [
        {
          "type": "tts",
          "params": {
            "text": "Hello from Bayview Taxi. You are hearing Amazon Polly text to speech on SignalWire.",
            "voice": "amazon.Ruth:neural"
          }
        }
      ]
    }
  }'
```
</CodeBlock>
</CodeBlocks>

The command returns once SignalWire accepts it, and the call hears the sentence in the Amazon Polly
voice.

### Create a SWML Script that uses an Amazon Polly voice

A SWML Script hosted in SignalWire runs the Amazon Polly-voiced AI agent above without a server of
your own.

1. In the Dashboard, open **My Resources**, select **+ Add**, then **Script**, then **SWML Script**.
2. Name the script and leave **Used For** set to **Calling**.
3. Under **Handle Calls Using**, choose **Hosted Script** and paste this document into
   **Primary Script**.
4. Select **Create**.

<CodeBlocks>
<CodeBlock title="YAML">
```yaml
version: 1.0.0
sections:
  main:
    - ai:
        prompt:
          text: "You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride."
        languages:
          - name: English
            code: en-US
            voice: "amazon.Ruth:neural"
```
</CodeBlock>
<CodeBlock title="JSON">
```json
{
  "version": "1.0.0",
  "sections": {
    "main": [
      {
        "ai": {
          "prompt": {
            "text": "You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride."
          },
          "languages": [
            {
              "name": "English",
              "code": "en-US",
              "voice": "amazon.Ruth:neural"
            }
          ]
        }
      }
    ]
  }
}
```
</CodeBlock>
</CodeBlocks>

Assign the script to your phone number as in
[Answer a call via SWML](/docs/platform/voice/make-and-receive-calls#answer-a-call-via-swml), then
call the number. The agent answers in the Amazon Polly voice.
