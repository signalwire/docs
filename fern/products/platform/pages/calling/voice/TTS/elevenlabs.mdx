Every ElevenLabs [voice](#voices) can be used with all of the ElevenLabs [models](#models).

## Usage

ElevenLabs voice IDs conform to the following format:

```
elevenlabs.<voice>:<model>
```

**Examples**:
```
elevenlabs.Rachel:eleven_flash_v2_5
elevenlabs.21m00Tcm4TlvDq8ikWAM:eleven_v3
elevenlabs.Brian:eleven_multilingual_v2
```

## Languages

ElevenLabs' multilingual models are designed to be interchangeably compatible with all supported languages.
Rather than enforcing language selection with language `code`,
this TTS model automatically uses the appropriate language of the input text.

Consult ElevenLabs' 
[supported languages resource](https://help.elevenlabs.io/hc/en-us/articles/13313366263441-What-languages-do-you-support)
for an up-to-date list of supported languages.

## Use ElevenLabs voices on a call

An ElevenLabs voice string such as `elevenlabs.rachel` works wherever SignalWire speaks text: an AI
agent's `languages`, the `say_voice` of SWML's `play`, and a `tts` media item sent with Relay or
the REST Calling API. The examples below all use `elevenlabs.rachel`. To control speech while it plays, see
[Speak text on a call](/docs/platform/voice/speak-text).

Replace these values in the samples:

| Value | Replace with |
|---|---|
| `<YOUR_BASIC_AUTH_PASSWORD>` | A password you choose for your SWML server; SignalWire sends it from the URL you give it |
| `<YOUR_PROJECT_ID>` | Your Project ID |
| `<YOUR_API_TOKEN>` | An API token with the **Voice** permission, used only in server code |
| `<YOUR_SPACE>` | Your Space's subdomain in `<YOUR_SPACE>.signalwire.com` |
| `<YOUR_CALL_ID>` | The ID of an answered call, for the REST command |

### Give an AI agent an ElevenLabs voice via SWML

The [`languages`](/docs/swml/reference/calling/ai/languages#use-voice-strings) list of the SWML
[`ai`](/docs/swml/reference/calling/ai) method sets the voice an AI agent speaks in. The
[Server SDKs](/docs/server-sdks) build the document and serve it at `/swml` on port 3000, only to
requests that carry the username `signalwire` and your password.

<CodeBlocks>
<CodeBlock title="Python — SWML builder">
```python
# Install: python -m pip install signalwire-sdk
# Save as elevenlabs_ai_agent.py and run: python elevenlabs_ai_agent.py
from signalwire import SWMLBuilder, SWMLService

service = SWMLService(
    name="elevenlabs-ai-agent",
    route="/swml",
    port=3000,
    basic_auth=("signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"),
)
SWMLBuilder(service).ai(
    prompt_text="You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride.",
    languages=[{
        "name": "English",
        "code": "en-US",
        "voice": "elevenlabs.rachel",
    }],
)

service.serve()
```
</CodeBlock>
<CodeBlock title="TypeScript — SWML builder">
```typescript
// Install: npm install @signalwire/sdk
// This sample also runs as JavaScript: save as elevenlabs-ai-agent.mjs,
// then run: node elevenlabs-ai-agent.mjs
import { SWMLService } from "@signalwire/sdk";

const service = new SWMLService({
  name: "elevenlabs-ai-agent",
  route: "/swml",
  port: 3000,
  basicAuth: ["signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"],
});
service.getBuilder().ai({
  // @ts-expect-error The ai verb takes a { text } prompt; the SDK types prompt as a string or array.
  prompt: { text: "You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride." },
  languages: [
    { name: "English", code: "en-US", voice: "elevenlabs.rachel" },
  ],
});

await service.serve();
```
</CodeBlock>

To send calls from your phone number to the server, follow
[Answer a call via SWML](/docs/platform/voice/make-and-receive-calls#answer-a-call-via-swml).
Call the number, and the agent greets you in the ElevenLabs voice. If you hear a different voice, the
voice string isn't in SignalWire's catalog, so the call falls back to a default voice. See
[Custom and cloned voices](/docs/platform/voice/tts#custom-and-cloned-voices).

### Speak text in an ElevenLabs voice via SWML

The SWML builder's `say()` writes a [`play`](/docs/swml/reference/calling/play) with a `say:` URL
and the voice in `say_voice`. This server speaks one sentence in the ElevenLabs voice, then hangs up.
Serve it and point your number at it the same way as the AI agent above.

<CodeBlocks>
<CodeBlock title="Python — SWML builder">
```python
# Install: python -m pip install signalwire-sdk
# Save as elevenlabs_tts.py and run: python elevenlabs_tts.py
from signalwire import SWMLBuilder, SWMLService

service = SWMLService(
    name="elevenlabs-tts",
    route="/swml",
    port=3000,
    basic_auth=("signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"),
)
SWMLBuilder(service).say(
    "Hello from Bayview Taxi. You are hearing ElevenLabs text to speech on SignalWire.",
    voice="elevenlabs.rachel",
).hangup()

service.serve()
```
</CodeBlock>
<CodeBlock title="TypeScript — SWML builder">
```typescript
// Install: npm install @signalwire/sdk
// This sample also runs as JavaScript: save as elevenlabs-tts.mjs,
// then run: node elevenlabs-tts.mjs
import { SWMLService } from "@signalwire/sdk";

const service = new SWMLService({
  name: "elevenlabs-tts",
  route: "/swml",
  port: 3000,
  basicAuth: ["signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"],
});
service.getBuilder()
  .say("Hello from Bayview Taxi. You are hearing ElevenLabs text to speech on SignalWire.", {
    voice: "elevenlabs.rachel",
  })
  .hangup();

await service.serve();
```
</CodeBlock>
<CodeBlock title="YAML">
```yaml
version: 1.0.0
sections:
  main:
    - play:
        url: "say:Hello from Bayview Taxi. You are hearing ElevenLabs text to speech on SignalWire."
        say_voice: "elevenlabs.rachel"
    - hangup: {}
```
</CodeBlock>
<CodeBlock title="JSON">
```json
{
  "version": "1.0.0",
  "sections": {
    "main": [
      {
        "play": {
          "url": "say:Hello from Bayview Taxi. You are hearing ElevenLabs text to speech on SignalWire.",
          "say_voice": "elevenlabs.rachel"
        }
      },

        "hangup": {}
```

### Speak text in an ElevenLabs voice via WebSocket (Relay)

A Relay client in the [Server SDKs](/docs/server-sdks) passes the voice string in a `tts` media
item. This handler answers calls on the `default` topic, speaks in the ElevenLabs voice, and hangs
up when the speech ends.

<CodeBlocks>
<CodeBlock title="Python — Relay client">
```python
# Install: python -m pip install signalwire-sdk
# Save as elevenlabs_relay.py and run: python elevenlabs_relay.py
from signalwire.relay import RelayClient

client = RelayClient(
    project="<YOUR_PROJECT_ID>",
    token="<YOUR_API_TOKEN>",
    contexts=["default"],
)

@client.on_call
async def handle_call(call):
    await call.answer()

    async def hang_up_after_playback(_event):
        if call.state != "ended":
            await call.hangup()

    await call.play([{
        "type": "tts",
        "params": {
            "text": "Hello from Bayview Taxi. You are hearing ElevenLabs text to speech on SignalWire.",
            "voice": "elevenlabs.rachel",
        },
    }], on_completed=hang_up_after_playback)
    await call.wait_for_ended()

client.run()
```
</CodeBlock>
<CodeBlock title="TypeScript — Relay client">
```typescript
// Install: npm install @signalwire/sdk
// This sample also runs as JavaScript: save as elevenlabs-relay.mjs,
// then run: node elevenlabs-relay.mjs
import { RelayClient } from "@signalwire/sdk";

const client = new RelayClient({
  project: "<YOUR_PROJECT_ID>",
  token: "<YOUR_API_TOKEN>",
  contexts: ["default"],
});

client.onCall(async (call) => {
  await call.answer();
  await call.play([{
    type: "tts",
    params: {
      text: "Hello from Bayview Taxi. You are hearing ElevenLabs text to speech on SignalWire.",
      voice: "elevenlabs.rachel",
    },
  }], {
    onCompleted: async () => {
      if (call.state !== "ended") await call.hangup();
    },
  });
  await call.waitForEnded();
});

await client.run();
```
</CodeBlock>
</CodeBlocks>

To route calls from your phone number to the handler, assign the number to a Relay Application
on the `default` topic, as described in
[Answer a call via WebSocket (Relay)](/docs/platform/voice/make-and-receive-calls#answer-a-call-via-websocket-relay).

### Speak text in an ElevenLabs voice on a call in progress via REST

To speak on a call that's already up, such as from a backend job, send
[`calling.play`](/docs/apis/rest/calls/call-commands) with the call's ID and the same `tts` media
item. `control_id` names the playback so later commands can stop or pause it.

<CodeBlocks>
<CodeBlock title="Python — REST client">
```python
# Install: python -m pip install signalwire-sdk
# Save as elevenlabs_rest.py and run: python elevenlabs_rest.py
from signalwire.rest import RestClient

client = RestClient(
    project="<YOUR_PROJECT_ID>",
    token="<YOUR_API_TOKEN>",
    host="<YOUR_SPACE>.signalwire.com",
)

client.calling.play(
    "<YOUR_CALL_ID>",
    control_id="elevenlabs-greeting",
    play=[{
        "type": "tts",
        "params": {
            "text": "Hello from Bayview Taxi. You are hearing ElevenLabs text to speech on SignalWire.",
            "voice": "elevenlabs.rachel",
        },
    }],
)
```
</CodeBlock>
<CodeBlock title="TypeScript — REST client">
```typescript
// Install: npm install @signalwire/sdk
// This sample also runs as JavaScript: save as elevenlabs-rest.mjs,
// then run: node elevenlabs-rest.mjs
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "<YOUR_PROJECT_ID>",
  token: "<YOUR_API_TOKEN>",
  host: "<YOUR_SPACE>.signalwire.com",
});

await client.calling.play("<YOUR_CALL_ID>", [{
  type: "tts",
  params: {
    text: "Hello from Bayview Taxi. You are hearing ElevenLabs text to speech on SignalWire.",
    voice: "elevenlabs.rachel",
  },
}], { control_id: "elevenlabs-greeting" });
```
</CodeBlock>
<CodeBlock title="cURL — Calling API">
```bash
curl -X POST "https://<YOUR_SPACE>.signalwire.com/api/calling/calls" \
  -u "<YOUR_PROJECT_ID>:<YOUR_API_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "command": "calling.play",
    "id": "<YOUR_CALL_ID>",
    "params": {
      "control_id": "elevenlabs-greeting",
      "play": [
        {
          "type": "tts",
          "params": {
            "text": "Hello from Bayview Taxi. You are hearing ElevenLabs text to speech on SignalWire.",
            "voice": "elevenlabs.rachel"
          }
        }
      ]
    }
  }'
```
</CodeBlock>
</CodeBlocks>

The command returns once SignalWire accepts it, and the call hears the sentence in the ElevenLabs
voice.

### Create a SWML Script that uses an ElevenLabs voice

A SWML Script hosted in SignalWire runs the ElevenLabs-voiced AI agent above without a server of
your own.

1. In the Dashboard, open **My Resources**, select **+ Add**, then **Script**, then **SWML Script**.
2. Name the script and leave **Used For** set to **Calling**.
3. Under **Handle Calls Using**, choose **Hosted Script** and paste this document into
   **Primary Script**.
4. Select **Create**.

<CodeBlocks>
<CodeBlock title="YAML">
```yaml
version: 1.0.0
sections:
  main:
    - ai:
        prompt:
          text: "You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride."
        languages:
          - name: English
            code: en-US
            voice: "elevenlabs.rachel"
```
</CodeBlock>
<CodeBlock title="JSON">
```json
{
  "version": "1.0.0",
  "sections": {
    "main": [
      {
        "ai": {
          "prompt": {
            "text": "You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride."
          },
          "languages": [
            {
              "name": "English",
              "code": "en-US",
              "voice": "elevenlabs.rachel"
            }
          ]
        }
      }
    ]
  }
}
```
</CodeBlock>
</CodeBlocks>

Assign the script to your phone number as in
[Answer a call via SWML](/docs/platform/voice/make-and-receive-calls#answer-a-call-via-swml), then
call the number. The agent answers in the ElevenLabs voice.
