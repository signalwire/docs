OpenAI offers versatile multilingual voices balancing low latency and good quality.
While voices are optimized for English, they perform well across all 
[supported languages][languages].

Consult 
[OpenAI's Text-to-Speech documentation][tts]
for more information and audio samples for available voices.

## Models

OpenAI offers two TTS models with different quality and latency characteristics:

| Model | Description |
|-------|-------------|
| `tts-1` | **Default** - Standard quality, optimized for speed |
| `tts-1-hd` | High-definition quality, improved audio fidelity |

OpenAI provides 6 fully multilingual voices optimized for natural-sounding speech:

| Voice | Description |
|-------|-------------|
| `alloy` | Neutral, balanced voice |
| `echo` | Warm, expressive voice |
| `fable` | British accent, articulate |
| `onyx` | Deep, authoritative voice |
| `nova` | Energetic, friendly voice |
| `shimmer` | Soft, gentle voice |

## Languages

All OpenAI voices are fully multilingual and automatically adapt to the input text language.

Consult OpenAI's [supported languages resource][languages]
for an up-to-date list.

## Usage

OpenAI voice IDs conform to the following format:

```
openai.<voice>:<model>
```

**Parameters:**
- `voice` (required): One of: alloy, echo, fable, onyx, nova, shimmer
- `model` (optional): `tts-1` (default) or `tts-1-hd`

**Examples:**
```
openai.alloy
openai.nova:tts-1-hd
openai.fable:tts-1
```

## Use OpenAI voices on a call

An OpenAI voice string such as `openai.alloy` works in each of these places: an AI
agent's `languages`, the `say_voice` of SWML's `play`, and a `tts` media item sent with Relay or
the REST Calling API. The examples below all use `openai.alloy`. To control speech while it plays, see
[Speak text on a call](/docs/platform/voice/speak-text).

Replace these values in the samples:

| Value | Replace with |
|---|---|
| `<YOUR_BASIC_AUTH_PASSWORD>` | A password you choose for your SWML server. You include it in the server URL you give SignalWire: `https://signalwire:<password>@<host>/swml` |
| `<YOUR_PROJECT_ID>` | Your Project ID |
| `<YOUR_API_TOKEN>` | An API token with the **Voice** permission, used only in server code |
| `<YOUR_SPACE>` | Your Space's subdomain in `<YOUR_SPACE>.signalwire.com` |
| `<YOUR_CALL_ID>` | The ID of an answered call, for the REST command |

### Give an AI agent an OpenAI voice via SWML

The [`languages`](/docs/swml/reference/calling/ai/languages#use-voice-strings) list of the SWML
[`ai`](/docs/swml/reference/calling/ai) method sets the voice an AI agent speaks in. The
[Server SDKs](/docs/server-sdks) build the document and serve it at `/swml` on port 3000, only to
requests that carry the username `signalwire` and your password.

<CodeBlocks>
<CodeBlock title="Python — SWML builder">
```python
# Install: python -m pip install signalwire-sdk
# Save as openai_ai_agent.py and run: python openai_ai_agent.py
from signalwire import SWMLBuilder, SWMLService

service = SWMLService(
    name="openai-ai-agent",
    route="/swml",
    port=3000,
    basic_auth=("signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"),
)
SWMLBuilder(service).ai(
    prompt_text="You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride.",
    languages=[{
        "name": "English",
        "code": "en-US",
        "voice": "openai.alloy",
    }],
)

service.serve()
```
</CodeBlock>
<CodeBlock title="TypeScript — SWML builder">
```typescript
// Install: npm install @signalwire/sdk
// This sample also runs as JavaScript: save as openai-ai-agent.mjs,
// then run: node openai-ai-agent.mjs
import { SWMLService } from "@signalwire/sdk";

const service = new SWMLService({
  name: "openai-ai-agent",
  route: "/swml",
  port: 3000,
  basicAuth: ["signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"],
});
service.getBuilder().ai({
  // The ai verb takes a { text } prompt; the SDK types prompt as a string or array.
  prompt: { text: "You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride." } as never,
  languages: [
    { name: "English", code: "en-US", voice: "openai.alloy" },
  ],
});

await service.serve();
```
</CodeBlock>
<CodeBlock title="YAML">
```yaml
version: 1.0.0
sections:
  main:
    - ai:
        prompt:
          text: "You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride."

          - name: English
            code: en-US
            voice: "openai.alloy"
```
</CodeBlock>
<CodeBlock title="JSON">

To send calls from your phone number to the server, follow
[Answer a call via SWML](/docs/platform/voice/make-and-receive-calls#answer-a-call-via-swml).
Call the number, and the agent greets you in the OpenAI voice. If you hear a different voice, the
voice string isn't in SignalWire's catalog, so the call falls back to a default voice. See
[Custom and cloned voices](/docs/platform/voice/tts#custom-and-cloned-voices).

### Speak text in an OpenAI voice via SWML

The SWML builder's `say()` writes a [`play`](/docs/swml/reference/calling/play) with a `say:` URL
and the voice in `say_voice`. This server speaks one sentence in the OpenAI voice, then hangs up.
Serve it and point your number at it the same way as the AI agent above.

<CodeBlocks>
<CodeBlock title="Python — SWML builder">
```python
# Install: python -m pip install signalwire-sdk
# Save as openai_tts.py and run: python openai_tts.py
from signalwire import SWMLBuilder, SWMLService

service = SWMLService(
    name="openai-tts",
    route="/swml",
    port=3000,
    basic_auth=("signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"),
)
SWMLBuilder(service).say(
    "Hello from Bayview Taxi. You are hearing OpenAI text to speech on SignalWire.",
    voice="openai.alloy",
).hangup()

service.serve()
```
</CodeBlock>
<CodeBlock title="TypeScript — SWML builder">
```typescript
// Install: npm install @signalwire/sdk
// This sample also runs as JavaScript: save as openai-tts.mjs,
// then run: node openai-tts.mjs
import { SWMLService } from "@signalwire/sdk";

const service = new SWMLService({
  name: "openai-tts",
  route: "/swml",
  port: 3000,
  basicAuth: ["signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"],
});
service.getBuilder()
  .say("Hello from Bayview Taxi. You are hearing OpenAI text to speech on SignalWire.", {
    voice: "openai.alloy",
  })
  .hangup();

await service.serve();
```
</CodeBlock>
<CodeBlock title="YAML">
```yaml
version: 1.0.0
sections:
  main:
    - play:
        url: "say:Hello from Bayview Taxi. You are hearing OpenAI text to speech on SignalWire."
        say_voice: "openai.alloy"
    - hangup: {}
```
</CodeBlock>
<CodeBlock title="JSON">
```json
{
  "version": "1.0.0",
  "sections": {
    "main": [
      {
        "play": {
          "url": "say:Hello from Bayview Taxi. You are hearing OpenAI text to speech on SignalWire.",
          "say_voice": "openai.alloy"
        }
      },
      {
        "hangup": {}
      }
    ]
  }
}
```
</CodeBlock>

### Speak text in an OpenAI voice via WebSocket (Relay)

A Relay client in the [Server SDKs](/docs/server-sdks) passes the voice string in a `tts` media
item. This handler answers calls on the `default` topic, speaks in the OpenAI voice, and hangs
up when the speech ends.

<CodeBlocks>
<CodeBlock title="Python — Relay client">
```python
# Install: python -m pip install signalwire-sdk
# Save as openai_relay.py and run: python openai_relay.py
from signalwire.relay import RelayClient

client = RelayClient(
    project="<YOUR_PROJECT_ID>",
    token="<YOUR_API_TOKEN>",
    contexts=["default"],
)

@client.on_call
async def handle_call(call):
    await call.answer()

    async def hang_up_after_playback(_event):
        if call.state != "ended":
            await call.hangup()

    await call.play([{
        "type": "tts",
        "params": {
            "text": "Hello from Bayview Taxi. You are hearing OpenAI text to speech on SignalWire.",
            "voice": "openai.alloy",
        },
    }], on_completed=hang_up_after_playback)
    await call.wait_for_ended()

client.run()
```
</CodeBlock>
<CodeBlock title="TypeScript — Relay client">
```typescript
// Install: npm install @signalwire/sdk
// This sample also runs as JavaScript: save as openai-relay.mjs,
// then run: node openai-relay.mjs
import { RelayClient } from "@signalwire/sdk";

const client = new RelayClient({
  project: "<YOUR_PROJECT_ID>",
  token: "<YOUR_API_TOKEN>",
  contexts: ["default"],
});

client.onCall(async (call) => {
  await call.answer();
  await call.play([{
    type: "tts",
    params: {
      text: "Hello from Bayview Taxi. You are hearing OpenAI text to speech on SignalWire.",
      voice: "openai.alloy",
    },
  }], {
    onCompleted: async () => {
      if (call.state !== "ended") await call.hangup();
    },
  });
  await call.waitForEnded();
});

await client.run();
```
</CodeBlock>
</CodeBlocks>

To route calls from your phone number to the handler, assign the number to a Relay Application
on the `default` topic, as described in
[Answer a call via WebSocket (Relay)](/docs/platform/voice/make-and-receive-calls#answer-a-call-via-websocket-relay).
Call the number to hear the sentence. If you hear a different voice, SignalWire couldn't use the
voice string and played a fallback voice. If the play is rejected as a bad request, check the voice
string for characters a `tts` item doesn't accept, such as spaces, parentheses, or `/`.

### Speak text in an OpenAI voice on a call in progress via REST

To speak on a call that's already up, such as from a backend job, send
[`calling.play`](/docs/apis/rest/calls/call-commands) with the call's ID and the same `tts` media
item. `control_id` names the playback so later commands can stop or pause it.

<CodeBlocks>
<CodeBlock title="Python — REST client">
```python
# Install: python -m pip install signalwire-sdk
# Save as openai_rest.py and run: python openai_rest.py
from signalwire.rest import RestClient

client = RestClient(
    project="<YOUR_PROJECT_ID>",
    token="<YOUR_API_TOKEN>",
    host="<YOUR_SPACE>.signalwire.com",
)

client.calling.play(
    "<YOUR_CALL_ID>",
    control_id="openai-greeting",
    play=[{
        "type": "tts",
        "params": {
            "text": "Hello from Bayview Taxi. You are hearing OpenAI text to speech on SignalWire.",
            "voice": "openai.alloy",
        },
    }],
)
```
</CodeBlock>
<CodeBlock title="TypeScript — REST client">
```typescript
// Install: npm install @signalwire/sdk
// This sample also runs as JavaScript: save as openai-rest.mjs,
// then run: node openai-rest.mjs
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "<YOUR_PROJECT_ID>",
  token: "<YOUR_API_TOKEN>",
  host: "<YOUR_SPACE>.signalwire.com",
});

await client.calling.play("<YOUR_CALL_ID>", [{
  type: "tts",
  params: {
    text: "Hello from Bayview Taxi. You are hearing OpenAI text to speech on SignalWire.",
    voice: "openai.alloy",
  },
}], { control_id: "openai-greeting" });
```
</CodeBlock>
<CodeBlock title="cURL — Calling API">
```bash
curl -X POST "https://<YOUR_SPACE>.signalwire.com/api/calling/calls" \
  -u "<YOUR_PROJECT_ID>:<YOUR_API_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "command": "calling.play",
    "id": "<YOUR_CALL_ID>",
    "params": {
      "control_id": "openai-greeting",
      "play": [
        {
          "type": "tts",
          "params": {
            "text": "Hello from Bayview Taxi. You are hearing OpenAI text to speech on SignalWire.",
            "voice": "openai.alloy"
          }
        }
      ]
    }
  }'
```
</CodeBlock>
</CodeBlocks>

The command returns once SignalWire accepts it, and the call hears the sentence in the OpenAI
voice.
If the call hears a different voice, SignalWire couldn't use the voice string and played a fallback
voice. If the call hears nothing, check the voice string for characters a `tts` item doesn't
accept, such as spaces, parentheses, or `/`. The request still returns success in that case, so
silence on the call is the only sign.

### Create a SWML Script that uses an OpenAI voice

A SWML Script hosted in SignalWire runs the OpenAI-voiced AI agent above without a server of
your own.

1. In the Dashboard, open **My Resources**, select **+ Add**, then **Script**, then **SWML Script**.
2. Name the script and leave **Used For** set to **Calling**.
3. Under **Handle Calls Using**, choose **Hosted Script** and paste this document into
   **Primary Script**.
4. Select **Create**.

<CodeBlocks>
<CodeBlock title="YAML">
```yaml
version: 1.0.0
sections:
  main:
    - ai:
        prompt:
          text: "You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride."
        languages:
          - name: English
            code: en-US
            voice: "openai.alloy"
```
</CodeBlock>
<CodeBlock title="JSON">
```json
{
  "version": "1.0.0",
  "sections": {
    "main": [
      {
        "ai": {
          "prompt": {
            "text": "You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride."
          },
          "languages": [
            {
              "name": "English",
              "code": "en-US",
              "voice": "openai.alloy"
            }
          ]
        }
      }
    ]
  }
}
```
</CodeBlock>
</CodeBlocks>

Assign the script to your phone number as in
[Answer a call via SWML](/docs/platform/voice/make-and-receive-calls#answer-a-call-via-swml), then
call the number. The agent answers in the OpenAI voice.
