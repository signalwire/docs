MiniMax is a text-to-speech engine offering expressive voices across many languages, with controls
for emotion, speed, pitch, and volume.

## Models

SignalWire supports the following MiniMax models. Pick a `turbo` model for speed and cost, or an
`hd` model for the highest quality. If you don't specify a model, `speech-2.6-turbo` is used.

| Model | Description |
|-------|-------------|
| `speech-2.6-turbo` | **Default.** Latest turbo model: faster and lower-cost |
| `speech-2.6-hd` | Latest HD model: higher quality |
| `speech-02-turbo` | Previous-generation turbo model |
| `speech-02-hd` | Previous-generation HD model |
| `speech-01-turbo` | First-generation turbo model |
| `speech-01-hd` | First-generation HD model |

MiniMax provides a large library of system voices across many languages.
A voice's **Voice ID** is what you put in the [voice string](#usage): for example,
`English_CalmWoman` becomes `minimax.English_CalmWoman`.

<Warning>
Only MiniMax's built-in **system voices** are supported. Cloned and AI-generated voices do not
work — you must use one of the default voice IDs that MiniMax provides.
</Warning>

<Info>
Some voice IDs contain spaces or parentheses (for example, `Cantonese_ProfessionalHost (F)`).
These voice IDs work only in an AI agent's `languages`. SWML `play`, Relay, and the REST Calling
API reject a voice string that contains spaces or parentheses. In an AI agent, wrap the whole
voice string in quotes, for example
`voice: "minimax.Cantonese_ProfessionalHost (F):speech-2.6-turbo"`.
</Info>

## Languages

MiniMax supports the following languages and automatically detects the language of your text:

Arabic, Cantonese, Chinese — Mandarin, Czech, Dutch, English, Finnish, French, German, Greek, Hindi, Indonesian, Italian, Japanese, Korean, Polish, Portuguese, Romanian, Russian, Spanish, Thai, Turkish, Ukrainian, Vietnamese.

Refer to the [MiniMax developer platform](https://platform.minimax.io/)
for the most up-to-date reference to supported languages and voices.

## Usage

A voice identifier string has three parts: the `minimax` engine code, a voice ID, and an optional model.

**Format**: `minimax.<voiceId>:<model>`

- `voiceId` (required): a MiniMax system voice ID (for example, `English_CalmWoman`); see [Voices](#voices).
- `model` (optional): one of the [models](#models) above. Defaults to `speech-2.6-turbo`.

**Examples**:
```text
minimax.English_CalmWoman:speech-2.6-turbo
minimax.English_Trustworth_Man:speech-2.6-hd
minimax.Japanese_KindLady:speech-2.6-turbo
```

You can also set the model with the separate
[`model`](/docs/swml/reference/calling/ai/languages#use-voice-strings)
parameter of the [`languages`](/docs/swml/reference/calling/ai/languages) SWML method
instead of appending `:model` to the voice string:

```yaml
languages:
- name: English
  code: en-US
  voice: minimax.English_CalmWoman
  model: speech-2.6-turbo
```

## Use MiniMax voices on a call

A MiniMax voice string such as `minimax.English_CalmWoman:speech-2.6-turbo` works in each of these places: an AI
agent's `languages`, the `say_voice` of SWML's `play`, and a `tts` media item sent with Relay or
the REST Calling API. A voice ID with spaces or parentheses works only in an AI agent; see
[Voices](#voices). The examples below all use `minimax.English_CalmWoman:speech-2.6-turbo`. To control speech while it plays, see
[Speak text on a call](/docs/platform/voice/speak-text).

Replace these values in the samples:

| Value | Replace with |
|---|---|
| `<YOUR_BASIC_AUTH_PASSWORD>` | A password you choose for your SWML server. You include it in the server URL you give SignalWire: `https://signalwire:<password>@<host>/swml` |
| `<YOUR_PROJECT_ID>` | Your Project ID |
| `<YOUR_API_TOKEN>` | An API token with the **Voice** permission, used only in server code |
| `<YOUR_SPACE>` | Your Space's subdomain in `<YOUR_SPACE>.signalwire.com` |
| `<YOUR_CALL_ID>` | The ID of an answered call, for the REST command |

### Give an AI agent a MiniMax voice via SWML

The [`languages`](/docs/swml/reference/calling/ai/languages#use-voice-strings) list of the SWML
[`ai`](/docs/swml/reference/calling/ai) method sets the voice an AI agent speaks in. The
[Server SDKs](/docs/server-sdks) build the document and serve it at `/swml` on port 3000, only to
requests that carry the username `signalwire` and your password.

<CodeBlocks>
<CodeBlock title="Python — SWML builder">
```python
# Install: python -m pip install signalwire-sdk
# Save as minimax_ai_agent.py and run: python minimax_ai_agent.py
from signalwire import SWMLBuilder, SWMLService

service = SWMLService(
    name="minimax-ai-agent",
    route="/swml",
    port=3000,
    basic_auth=("signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"),
)
SWMLBuilder(service).ai(
    prompt_text="You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride.",
    languages=[{
        "name": "English",
        "code": "en-US",
        "voice": "minimax.English_CalmWoman:speech-2.6-turbo",
    }],
)

service.serve()
```
</CodeBlock>
<CodeBlock title="TypeScript — SWML builder">
```typescript
// Install: npm install @signalwire/sdk
// This sample also runs as JavaScript: save as minimax-ai-agent.mjs,
// then run: node minimax-ai-agent.mjs
import { SWMLService } from "@signalwire/sdk";

const service = new SWMLService({
  name: "minimax-ai-agent",
  route: "/swml",
  port: 3000,
  basicAuth: ["signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"],
});
service.getBuilder().ai({
  // The ai verb takes a { text } prompt; the SDK types prompt as a string or array.
  prompt: { text: "You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride." } as never,
  languages: [
    { name: "English", code: "en-US", voice: "minimax.English_CalmWoman:speech-2.6-turbo" },
  ],
});

await service.serve();
```
</CodeBlock>

To send calls from your phone number to the server, follow
[Answer a call via SWML](/docs/platform/voice/make-and-receive-calls#answer-a-call-via-swml).
Call the number, and the agent greets you in the MiniMax voice. If you hear a different voice, the
voice string isn't in SignalWire's catalog, so the call falls back to a default voice. See
[Custom and cloned voices](/docs/platform/voice/tts#custom-and-cloned-voices).

### Speak text in a MiniMax voice via SWML

The SWML builder's `say()` writes a [`play`](/docs/swml/reference/calling/play) with a `say:` URL
and the voice in `say_voice`. This server speaks one sentence in the MiniMax voice, then hangs up.
Serve it and point your number at it the same way as the AI agent above.

<CodeBlocks>
<CodeBlock title="Python — SWML builder">
```python
# Install: python -m pip install signalwire-sdk
# Save as minimax_tts.py and run: python minimax_tts.py
from signalwire import SWMLBuilder, SWMLService

service = SWMLService(
    name="minimax-tts",
    route="/swml",
    port=3000,
    basic_auth=("signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"),
)
SWMLBuilder(service).say(
    "Hello from Bayview Taxi. You are hearing MiniMax text to speech on SignalWire.",
    voice="minimax.English_CalmWoman:speech-2.6-turbo",
).hangup()

service.serve()
```
</CodeBlock>
<CodeBlock title="TypeScript — SWML builder">
```typescript
// Install: npm install @signalwire/sdk
// This sample also runs as JavaScript: save as minimax-tts.mjs,
// then run: node minimax-tts.mjs
import { SWMLService } from "@signalwire/sdk";

const service = new SWMLService({
  name: "minimax-tts",
  route: "/swml",
  port: 3000,
  basicAuth: ["signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"],
});
service.getBuilder()
  .say("Hello from Bayview Taxi. You are hearing MiniMax text to speech on SignalWire.", {
    voice: "minimax.English_CalmWoman:speech-2.6-turbo",
  })
  .hangup();

await service.serve();
```
</CodeBlock>
<CodeBlock title="YAML">
```yaml

sections:
  main:
    - play:
        url: "say:Hello from Bayview Taxi. You are hearing MiniMax text to speech on SignalWire."
        say_voice: "minimax.English_CalmWoman:speech-2.6-turbo"
    - hangup: {}
```
</CodeBlock>
<CodeBlock title="JSON">
```json

  "sections": {
    "main": [
      {
        "play": {
          "url": "say:Hello from Bayview Taxi. You are hearing MiniMax text to speech on SignalWire.",
```

### Speak text in a MiniMax voice via WebSocket (Relay)

A Relay client in the [Server SDKs](/docs/server-sdks) passes the voice string in a `tts` media
item. This handler answers calls on the `default` topic, speaks in the MiniMax voice, and hangs
up when the speech ends.

<CodeBlocks>
<CodeBlock title="Python — Relay client">
```python
# Install: python -m pip install signalwire-sdk
# Save as minimax_relay.py and run: python minimax_relay.py
from signalwire.relay import RelayClient

client = RelayClient(
    project="<YOUR_PROJECT_ID>",
    token="<YOUR_API_TOKEN>",
    contexts=["default"],
)

@client.on_call
async def handle_call(call):
    await call.answer()

    async def hang_up_after_playback(_event):
        if call.state != "ended":
            await call.hangup()

    await call.play([{
        "type": "tts",
        "params": {
            "text": "Hello from Bayview Taxi. You are hearing MiniMax text to speech on SignalWire.",
            "voice": "minimax.English_CalmWoman:speech-2.6-turbo",
        },
    }], on_completed=hang_up_after_playback)
    await call.wait_for_ended()

client.run()
```
</CodeBlock>
<CodeBlock title="TypeScript — Relay client">
```typescript
// Install: npm install @signalwire/sdk
// This sample also runs as JavaScript: save as minimax-relay.mjs,
// then run: node minimax-relay.mjs
import { RelayClient } from "@signalwire/sdk";

const client = new RelayClient({
  project: "<YOUR_PROJECT_ID>",
  token: "<YOUR_API_TOKEN>",
  contexts: ["default"],
});

client.onCall(async (call) => {
  await call.answer();
  await call.play([{
    type: "tts",
    params: {
      text: "Hello from Bayview Taxi. You are hearing MiniMax text to speech on SignalWire.",
      voice: "minimax.English_CalmWoman:speech-2.6-turbo",
    },
  }], {
    onCompleted: async () => {
      if (call.state !== "ended") await call.hangup();
    },
  });
  await call.waitForEnded();
});

await client.run();
```
</CodeBlock>
</CodeBlocks>

To route calls from your phone number to the handler, assign the number to a Relay Application
on the `default` topic, as described in
[Answer a call via WebSocket (Relay)](/docs/platform/voice/make-and-receive-calls#answer-a-call-via-websocket-relay).
Call the number to hear the sentence. If you hear a different voice, SignalWire couldn't use the
voice string and played a fallback voice. If the play is rejected as a bad request, check the voice
string for characters a `tts` item doesn't accept, such as spaces, parentheses, or `/`.

### Speak text in a MiniMax voice on a call in progress via REST

To speak on a call that's already up, such as from a backend job, send
[`calling.play`](/docs/apis/rest/calls/call-commands) with the call's ID and the same `tts` media
item. `control_id` names the playback so later commands can stop or pause it.

<CodeBlocks>
<CodeBlock title="Python — REST client">
```python
# Install: python -m pip install signalwire-sdk
# Save as minimax_rest.py and run: python minimax_rest.py
from signalwire.rest import RestClient

client = RestClient(
    project="<YOUR_PROJECT_ID>",
    token="<YOUR_API_TOKEN>",
    host="<YOUR_SPACE>.signalwire.com",
)

client.calling.play(
    "<YOUR_CALL_ID>",
    control_id="minimax-greeting",
    play=[{
        "type": "tts",
        "params": {
            "text": "Hello from Bayview Taxi. You are hearing MiniMax text to speech on SignalWire.",
            "voice": "minimax.English_CalmWoman:speech-2.6-turbo",
        },
    }],
)
```
</CodeBlock>
<CodeBlock title="TypeScript — REST client">
```typescript
// Install: npm install @signalwire/sdk
// This sample also runs as JavaScript: save as minimax-rest.mjs,
// then run: node minimax-rest.mjs
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "<YOUR_PROJECT_ID>",
  token: "<YOUR_API_TOKEN>",
  host: "<YOUR_SPACE>.signalwire.com",
});

await client.calling.play("<YOUR_CALL_ID>", [{
  type: "tts",
  params: {
    text: "Hello from Bayview Taxi. You are hearing MiniMax text to speech on SignalWire.",
    voice: "minimax.English_CalmWoman:speech-2.6-turbo",
  },
}], { control_id: "minimax-greeting" });
```
</CodeBlock>
<CodeBlock title="cURL — Calling API">
```bash
curl -X POST "https://<YOUR_SPACE>.signalwire.com/api/calling/calls" \
  -u "<YOUR_PROJECT_ID>:<YOUR_API_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "command": "calling.play",
    "id": "<YOUR_CALL_ID>",
    "params": {
      "control_id": "minimax-greeting",
      "play": [
        {
          "type": "tts",
          "params": {
            "text": "Hello from Bayview Taxi. You are hearing MiniMax text to speech on SignalWire.",
            "voice": "minimax.English_CalmWoman:speech-2.6-turbo"
          }
        }
      ]
    }
  }'
```
</CodeBlock>
</CodeBlocks>

The command returns once SignalWire accepts it, and the call hears the sentence in the MiniMax
voice.
If the call hears a different voice, SignalWire couldn't use the voice string and played a fallback
voice. If the request is rejected, check the voice string for characters a `tts` item doesn't
accept, such as spaces, parentheses, or `/`.

### Create a SWML Script that uses a MiniMax voice

A SWML Script hosted in SignalWire runs the MiniMax-voiced AI agent above without a server of
your own.

1. In the Dashboard, open **My Resources**, select **+ Add**, then **Script**, then **SWML Script**.
2. Name the script and leave **Used For** set to **Calling**.
3. Under **Handle Calls Using**, choose **Hosted Script** and paste this document into
   **Primary Script**.
4. Select **Create**.

<CodeBlocks>
<CodeBlock title="YAML">
```yaml
version: 1.0.0
sections:
  main:
    - ai:
        prompt:
          text: "You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride."
        languages:
          - name: English
            code: en-US
            voice: "minimax.English_CalmWoman:speech-2.6-turbo"
```
</CodeBlock>
<CodeBlock title="JSON">
```json
{
  "version": "1.0.0",
  "sections": {
    "main": [
      {
        "ai": {
          "prompt": {
            "text": "You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride."
          },
          "languages": [
            {
              "name": "English",
              "code": "en-US",
              "voice": "minimax.English_CalmWoman:speech-2.6-turbo"
            }
          ]
        }
      }
    ]
  }
}
```
</CodeBlock>
</CodeBlocks>

Assign the script to your phone number as in
[Answer a call via SWML](/docs/platform/voice/make-and-receive-calls#answer-a-call-via-swml), then
call the number. The agent answers in the MiniMax voice.
