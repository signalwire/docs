Mistral's Voxtral text-to-speech models deliver realistic, emotionally expressive
multilingual speech with low latency.

## Models

| Model | Description |
|-------|-------------|
| `voxtral-mini-tts-latest` | **Default.** Latest Voxtral Mini TTS model |

Model IDs are passed through to Mistral directly, so newer Voxtral TTS models work as soon as
Mistral releases them. See
[Mistral's text-to-speech documentation](https://docs.mistral.ai/capabilities/audio/text_to_speech)
for current models.

Voice IDs are passed through to Mistral's hosted voice library — a voice named `myvoice`
becomes `mistral.myvoice` in the [voice string](#usage).
Find the available voices in
[Mistral AI Studio](https://console.mistral.ai/) under **Audio › Text-to-speech**.

<Warning>
There is no default or fallback voice — always set a valid Mistral voice ID.
Note that the preset names published with the open-weight Voxtral model (such as `casual_male`)
are **not** accepted by Mistral's hosted API — use a voice from Mistral AI Studio.
</Warning>

## Languages

Voxtral TTS supports English, French, Spanish, Portuguese, Italian, Dutch, German, Hindi, and
Arabic. Language is determined by the model and voice; refer to
[Mistral's documentation](https://docs.mistral.ai/capabilities/audio/text_to_speech)
for the most up-to-date language coverage.

## Usage

A voice identifier string has three parts: the `mistral` engine code, a voice ID, and an optional model.

**Format**: `mistral.<voiceId>:<model>`

- `voiceId` (required): a Mistral voice ID from [Mistral AI Studio](https://console.mistral.ai/); see [Voices](#voices).
- `model` (optional): a [Voxtral TTS model](#models). Defaults to `voxtral-mini-tts-latest`.

**Examples** (replace `myvoice` with a voice ID from Mistral AI Studio):
```text
mistral.myvoice
mistral.myvoice:voxtral-mini-tts-latest
```

You can also set the model with the separate
[`model`](/docs/swml/reference/calling/ai/languages#use-voice-strings)
parameter of the [`languages`](/docs/swml/reference/calling/ai/languages) SWML method
instead of appending `:model` to the voice string:

```yaml
languages:
- name: English
  code: en-US
  voice: mistral.myvoice
  model: voxtral-mini-tts-latest
```

## Use Mistral voices on a call

A Mistral voice string such as `mistral.<YOUR_MISTRAL_VOICE_ID>` works wherever SignalWire speaks text: an AI
agent's `languages`, the `say_voice` of SWML's `play`, and a `tts` media item sent with Relay or
the REST Calling API. The examples below all use `mistral.<YOUR_MISTRAL_VOICE_ID>`. To control speech while it plays, see
[Speak text on a call](/docs/platform/voice/speak-text).

Replace these values in the samples:

| Value | Replace with |
|---|---|
| `<YOUR_BASIC_AUTH_PASSWORD>` | A password you choose for your SWML server; SignalWire sends it from the URL you give it |
| `<YOUR_PROJECT_ID>` | Your Project ID |
| `<YOUR_API_TOKEN>` | An API token with the **Voice** permission, used only in server code |
| `<YOUR_SPACE>` | Your Space's subdomain in `<YOUR_SPACE>.signalwire.com` |
| `<YOUR_CALL_ID>` | The ID of an answered call, for the REST command |
| `<YOUR_MISTRAL_VOICE_ID>` | A voice ID from Mistral AI Studio; see [Voices](#voices) |

### Give an AI agent a Mistral voice via SWML

The [`languages`](/docs/swml/reference/calling/ai/languages#use-voice-strings) list of the SWML
[`ai`](/docs/swml/reference/calling/ai) method sets the voice an AI agent speaks in. The
[Server SDKs](/docs/server-sdks) build the document and serve it at `/swml` on port 3000, only to
requests that carry the username `signalwire` and your password.

<CodeBlocks>
<CodeBlock title="Python — SWML builder">
```python
# Install: python -m pip install signalwire-sdk
# Save as mistral_ai_agent.py and run: python mistral_ai_agent.py
from signalwire import SWMLBuilder, SWMLService

service = SWMLService(
    name="mistral-ai-agent",
    route="/swml",
    port=3000,
    basic_auth=("signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"),
)
SWMLBuilder(service).ai(
    prompt_text="You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride.",
    languages=[{
        "name": "English",
        "code": "en-US",
        "voice": "mistral.<YOUR_MISTRAL_VOICE_ID>",
    }],
)

service.serve()
```
</CodeBlock>
<CodeBlock title="TypeScript — SWML builder">
```typescript
// Install: npm install @signalwire/sdk
// This sample also runs as JavaScript: save as mistral-ai-agent.mjs,
// then run: node mistral-ai-agent.mjs
import { SWMLService } from "@signalwire/sdk";

const service = new SWMLService({
  name: "mistral-ai-agent",
  route: "/swml",
  port: 3000,
  basicAuth: ["signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"],
});
service.getBuilder().ai({
  // @ts-expect-error The ai verb takes a { text } prompt; the SDK types prompt as a string or array.
  prompt: { text: "You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride." },
  languages: [
    { name: "English", code: "en-US", voice: "mistral.<YOUR_MISTRAL_VOICE_ID>" },
  ],
});

await service.serve();
```
</CodeBlock>
<CodeBlock title="YAML">
```yaml

    - ai:

          text: "You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride."

```
</CodeBlock>

To send calls from your phone number to the server, follow
[Answer a call via SWML](/docs/platform/voice/make-and-receive-calls#answer-a-call-via-swml).
Call the number, and the agent greets you in the Mistral voice. If you hear a different voice, the
voice string isn't in SignalWire's catalog, so the call falls back to a default voice. See
[Custom and cloned voices](/docs/platform/voice/tts#custom-and-cloned-voices).

### Speak text in a Mistral voice via SWML

The SWML builder's `say()` writes a [`play`](/docs/swml/reference/calling/play) with a `say:` URL
and the voice in `say_voice`. This server speaks one sentence in the Mistral voice, then hangs up.
Serve it and point your number at it the same way as the AI agent above.

<CodeBlocks>
<CodeBlock title="Python — SWML builder">
```python
# Install: python -m pip install signalwire-sdk
# Save as mistral_tts.py and run: python mistral_tts.py
from signalwire import SWMLBuilder, SWMLService

service = SWMLService(
    name="mistral-tts",
    route="/swml",
    port=3000,
    basic_auth=("signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"),
)
SWMLBuilder(service).say(
    "Hello from Bayview Taxi. You are hearing Mistral text to speech on SignalWire.",
    voice="mistral.<YOUR_MISTRAL_VOICE_ID>",
).hangup()

service.serve()
```
</CodeBlock>
<CodeBlock title="TypeScript — SWML builder">
```typescript
// Install: npm install @signalwire/sdk
// This sample also runs as JavaScript: save as mistral-tts.mjs,
// then run: node mistral-tts.mjs
import { SWMLService } from "@signalwire/sdk";

const service = new SWMLService({
  name: "mistral-tts",
  route: "/swml",
  port: 3000,
  basicAuth: ["signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"],
});
service.getBuilder()
  .say("Hello from Bayview Taxi. You are hearing Mistral text to speech on SignalWire.", {
    voice: "mistral.<YOUR_MISTRAL_VOICE_ID>",
  })
  .hangup();

await service.serve();
```
</CodeBlock>
<CodeBlock title="YAML">
```yaml
version: 1.0.0
sections:
  main:
    - play:
        url: "say:Hello from Bayview Taxi. You are hearing Mistral text to speech on SignalWire."
        say_voice: "mistral.<YOUR_MISTRAL_VOICE_ID>"
    - hangup: {}
```
</CodeBlock>
<CodeBlock title="JSON">
```json
{
  "version": "1.0.0",
  "sections": {
    "main": [
      {
        "play": {
          "url": "say:Hello from Bayview Taxi. You are hearing Mistral text to speech on SignalWire.",
          "say_voice": "mistral.<YOUR_MISTRAL_VOICE_ID>"
        }
      },
      {
        "hangup": {}
```

### Speak text in a Mistral voice via WebSocket (Relay)

A Relay client in the [Server SDKs](/docs/server-sdks) passes the voice string in a `tts` media
item. This handler answers calls on the `default` topic, speaks in the Mistral voice, and hangs
up when the speech ends.

<CodeBlocks>
<CodeBlock title="Python — Relay client">
```python
# Install: python -m pip install signalwire-sdk
# Save as mistral_relay.py and run: python mistral_relay.py
from signalwire.relay import RelayClient

client = RelayClient(
    project="<YOUR_PROJECT_ID>",
    token="<YOUR_API_TOKEN>",
    contexts=["default"],
)

@client.on_call
async def handle_call(call):
    await call.answer()

    async def hang_up_after_playback(_event):
        if call.state != "ended":
            await call.hangup()

    await call.play([{
        "type": "tts",
        "params": {
            "text": "Hello from Bayview Taxi. You are hearing Mistral text to speech on SignalWire.",
            "voice": "mistral.<YOUR_MISTRAL_VOICE_ID>",
        },
    }], on_completed=hang_up_after_playback)
    await call.wait_for_ended()

client.run()
```
</CodeBlock>
<CodeBlock title="TypeScript — Relay client">
```typescript
// Install: npm install @signalwire/sdk
// This sample also runs as JavaScript: save as mistral-relay.mjs,
// then run: node mistral-relay.mjs
import { RelayClient } from "@signalwire/sdk";

const client = new RelayClient({
  project: "<YOUR_PROJECT_ID>",
  token: "<YOUR_API_TOKEN>",
  contexts: ["default"],
});

client.onCall(async (call) => {
  await call.answer();
  await call.play([{
    type: "tts",
    params: {
      text: "Hello from Bayview Taxi. You are hearing Mistral text to speech on SignalWire.",
      voice: "mistral.<YOUR_MISTRAL_VOICE_ID>",
    },
  }], {
    onCompleted: async () => {
      if (call.state !== "ended") await call.hangup();
    },
  });
  await call.waitForEnded();
});

await client.run();
```
</CodeBlock>
</CodeBlocks>

To route calls from your phone number to the handler, assign the number to a Relay Application
on the `default` topic, as described in
[Answer a call via WebSocket (Relay)](/docs/platform/voice/make-and-receive-calls#answer-a-call-via-websocket-relay).

### Speak text in a Mistral voice on a call in progress via REST

To speak on a call that's already up, such as from a backend job, send
[`calling.play`](/docs/apis/rest/calls/call-commands) with the call's ID and the same `tts` media
item. `control_id` names the playback so later commands can stop or pause it.

<CodeBlocks>
<CodeBlock title="Python — REST client">
```python
# Install: python -m pip install signalwire-sdk
# Save as mistral_rest.py and run: python mistral_rest.py
from signalwire.rest import RestClient

client = RestClient(
    project="<YOUR_PROJECT_ID>",
    token="<YOUR_API_TOKEN>",
    host="<YOUR_SPACE>.signalwire.com",
)

client.calling.play(
    "<YOUR_CALL_ID>",
    control_id="mistral-greeting",
    play=[{
        "type": "tts",
        "params": {
            "text": "Hello from Bayview Taxi. You are hearing Mistral text to speech on SignalWire.",
            "voice": "mistral.<YOUR_MISTRAL_VOICE_ID>",
        },
    }],
)
```
</CodeBlock>
<CodeBlock title="TypeScript — REST client">
```typescript
// Install: npm install @signalwire/sdk
// This sample also runs as JavaScript: save as mistral-rest.mjs,
// then run: node mistral-rest.mjs
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "<YOUR_PROJECT_ID>",
  token: "<YOUR_API_TOKEN>",
  host: "<YOUR_SPACE>.signalwire.com",
});

await client.calling.play("<YOUR_CALL_ID>", [{
  type: "tts",
  params: {
    text: "Hello from Bayview Taxi. You are hearing Mistral text to speech on SignalWire.",
    voice: "mistral.<YOUR_MISTRAL_VOICE_ID>",
  },
}], { control_id: "mistral-greeting" });
```
</CodeBlock>
<CodeBlock title="cURL — Calling API">
```bash
curl -X POST "https://<YOUR_SPACE>.signalwire.com/api/calling/calls" \
  -u "<YOUR_PROJECT_ID>:<YOUR_API_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "command": "calling.play",
    "id": "<YOUR_CALL_ID>",
    "params": {
      "control_id": "mistral-greeting",
      "play": [
        {
          "type": "tts",
          "params": {
            "text": "Hello from Bayview Taxi. You are hearing Mistral text to speech on SignalWire.",
            "voice": "mistral.<YOUR_MISTRAL_VOICE_ID>"
          }
        }
      ]
    }
  }'
```
</CodeBlock>
</CodeBlocks>

The command returns once SignalWire accepts it, and the call hears the sentence in the Mistral
voice.

### Create a SWML Script that uses a Mistral voice

A SWML Script hosted in SignalWire runs the Mistral-voiced AI agent above without a server of
your own.

1. In the Dashboard, open **My Resources**, select **+ Add**, then **Script**, then **SWML Script**.
2. Name the script and leave **Used For** set to **Calling**.
3. Under **Handle Calls Using**, choose **Hosted Script** and paste this document into
   **Primary Script**.
4. Select **Create**.

<CodeBlocks>
<CodeBlock title="YAML">
```yaml
version: 1.0.0
sections:
  main:
    - ai:
        prompt:
          text: "You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride."
        languages:
          - name: English
            code: en-US
            voice: "mistral.<YOUR_MISTRAL_VOICE_ID>"
```
</CodeBlock>
<CodeBlock title="JSON">
```json
{
  "version": "1.0.0",
  "sections": {
    "main": [
      {
        "ai": {
          "prompt": {
            "text": "You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride."
          },
          "languages": [
            {
              "name": "English",
              "code": "en-US",
              "voice": "mistral.<YOUR_MISTRAL_VOICE_ID>"
            }
          ]
        }
      }
    ]
  }
}
```
</CodeBlock>
</CodeBlocks>

Assign the script to your phone number as in
[Answer a call via SWML](/docs/platform/voice/make-and-receive-calls#answer-a-call-via-swml), then
call the number. The agent answers in the Mistral voice.
