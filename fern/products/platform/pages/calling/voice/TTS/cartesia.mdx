Cartesia offers a wide selection of fully multilingual voices with very low latency.
[Create a Cartesia account](https://play.cartesia.ai) to browse and test voices in the Cartesia Playground.

## Models

Cartesia provides multiple generations of its Sonic TTS model:

| Model | Description |
|-------|-------------|
| `sonic-3` | **Default.** Latest model with enhanced naturalness |
| `sonic-2` | Second-generation model with improved quality |
| `sonic-turbo` | Optimized for ultra-low latency |
| `sonic` | The first version of Sonic, optimized for accuracy and low latency. |


All Cartesia voices can be used with any model.

## Usage

Cartesia voice IDs conform to the following format:

```
cartesia.<voice_id>:<model>
```

**Parameters:**
- `voice_id` (required): The UUID voice identifier from the [Voices](#voices) table
- `model` (optional): One of the Sonic models listed above (default: `sonic-3`)

**Examples:**
```
cartesia.a167e0f3-df7e-4d52-a9c3-f949145efdab
cartesia.694f9389-aac1-45b6-b726-9d9369183238:sonic-3
cartesia.829ccd10-f8b3-43cd-b8a0-4aeaa81f3b30:sonic-turbo
```

## Languages

Cartesia voices are fully multilingual when used with `sonic-multilingual`, `sonic-2`, `sonic-3`, or `sonic-3` models. 
The multilingual models automatically adapt to the input text language.

Supported languages include: English, Spanish, French, German, Italian, Portuguese, Dutch, Polish, Russian, Chinese, Japanese, Korean, Hindi, Turkish, Swedish, and many more.

For the complete list, refer to Cartesia's
[Sonic 3 language support](https://docs.cartesia.ai/build-with-cartesia/tts-models/latest#language-support)
and
[Sonic 2 language support](https://docs.cartesia.ai/build-with-cartesia/tts-models/older-models#sonic-2-language-support)
references.

## Use Cartesia voices on a call

A Cartesia voice string such as `cartesia.a167e0f3-df7e-4d52-a9c3-f949145efdab` works wherever SignalWire speaks text: an AI
agent's `languages`, the `say_voice` of SWML's `play`, and a `tts` media item sent with Relay or
the REST Calling API. The examples below all use `cartesia.a167e0f3-df7e-4d52-a9c3-f949145efdab`. To control speech while it plays, see
[Speak text on a call](/docs/platform/voice/speak-text).

Cartesia voices are not yet supported in Call Flow Builder.

Replace these values in the samples:

| Value | Replace with |
|---|---|
| `<YOUR_BASIC_AUTH_PASSWORD>` | A password you choose for your SWML server; SignalWire sends it from the URL you give it |
| `<YOUR_PROJECT_ID>` | Your Project ID |
| `<YOUR_API_TOKEN>` | An API token with the **Voice** permission, used only in server code |
| `<YOUR_SPACE>` | Your Space's subdomain in `<YOUR_SPACE>.signalwire.com` |
| `<YOUR_CALL_ID>` | The ID of an answered call, for the REST command |

### Give an AI agent a Cartesia voice via SWML

The [`languages`](/docs/swml/reference/calling/ai/languages#use-voice-strings) list of the SWML
[`ai`](/docs/swml/reference/calling/ai) method sets the voice an AI agent speaks in. The
[Server SDKs](/docs/server-sdks) build the document and serve it at `/swml` on port 3000, only to
requests that carry the username `signalwire` and your password.

<CodeBlocks>
<CodeBlock title="Python — SWML builder">
```python
# Install: python -m pip install signalwire-sdk
# Save as cartesia_ai_agent.py and run: python cartesia_ai_agent.py
from signalwire import SWMLBuilder, SWMLService

service = SWMLService(
    name="cartesia-ai-agent",
    route="/swml",
    port=3000,
    basic_auth=("signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"),
)
SWMLBuilder(service).ai(
    prompt_text="You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride.",
    languages=[{
        "name": "English",
        "code": "en-US",
        "voice": "cartesia.a167e0f3-df7e-4d52-a9c3-f949145efdab",
    }],
)

service.serve()
```
</CodeBlock>
<CodeBlock title="TypeScript — SWML builder">

### Speak text in a Cartesia voice via SWML

The SWML builder's `say()` writes a [`play`](/docs/swml/reference/calling/play) with a `say:` URL
and the voice in `say_voice`. This server speaks one sentence in the Cartesia voice, then hangs up.
Serve it and point your number at it the same way as the AI agent above.

<CodeBlocks>
<CodeBlock title="Python — SWML builder">
```python
# Install: python -m pip install signalwire-sdk
# Save as cartesia_tts.py and run: python cartesia_tts.py
from signalwire import SWMLBuilder, SWMLService

service = SWMLService(
    name="cartesia-tts",
    route="/swml",
    port=3000,
    basic_auth=("signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"),
)
SWMLBuilder(service).say(
    "Hello from Bayview Taxi. You are hearing Cartesia text to speech on SignalWire.",
    voice="cartesia.a167e0f3-df7e-4d52-a9c3-f949145efdab",
).hangup()

service.serve()
```
</CodeBlock>
<CodeBlock title="TypeScript — SWML builder">

### Speak text in a Cartesia voice via WebSocket (Relay)

A Relay client in the [Server SDKs](/docs/server-sdks) passes the voice string in a `tts` media
item. This handler answers calls on the `default` topic, speaks in the Cartesia voice, and hangs
up when the speech ends.

```python
    token="<YOUR_API_TOKEN>",
    contexts=["default"],
)

    await call.answer()

    async def hang_up_after_playback(_event):
        if call.state != "ended":
            await call.hangup()

    await call.play([{
        "type": "tts",
        "params": {
            "text": "Hello from Bayview Taxi. You are hearing Cartesia text to speech on SignalWire.",
            "voice": "cartesia.a167e0f3-df7e-4d52-a9c3-f949145efdab",

    }], on_completed=hang_up_after_playback)
```

### Speak text in a Cartesia voice on a call in progress via REST

To speak on a call that's already up, such as from a backend job, send
[`calling.play`](/docs/apis/rest/calls/call-commands) with the call's ID and the same `tts` media
item. `control_id` names the playback so later commands can stop or pause it.

<CodeBlocks>
<CodeBlock title="Python — REST client">
```python
# Install: python -m pip install signalwire-sdk
# Save as cartesia_rest.py and run: python cartesia_rest.py
from signalwire.rest import RestClient

client = RestClient(
    project="<YOUR_PROJECT_ID>",
    token="<YOUR_API_TOKEN>",
    host="<YOUR_SPACE>.signalwire.com",
)

client.calling.play(
    "<YOUR_CALL_ID>",
    control_id="cartesia-greeting",
    play=[{
        "type": "tts",
        "params": {
            "text": "Hello from Bayview Taxi. You are hearing Cartesia text to speech on SignalWire.",
            "voice": "cartesia.a167e0f3-df7e-4d52-a9c3-f949145efdab",
        },
    }],
)
```
</CodeBlock>
<CodeBlock title="TypeScript — REST client">
```typescript

// then run: node cartesia-rest.mjs

}], { control_id: "cartesia-greeting" });
```
</CodeBlock>

### Create a SWML Script that uses a Cartesia voice

A SWML Script hosted in SignalWire runs the Cartesia-voiced AI agent above without a server of
your own.

1. In the Dashboard, open **My Resources**, select **+ Add**, then **Script**, then **SWML Script**.
2. Name the script and leave **Used For** set to **Calling**.
3. Under **Handle Calls Using**, choose **Hosted Script** and paste this document into
   **Primary Script**.
4. Select **Create**.

<CodeBlocks>
<CodeBlock title="YAML">
```yaml
version: 1.0.0
sections:
  main:
    - ai:
        prompt:
          text: "You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride."
        languages:
          - name: English
            code: en-US
            voice: "cartesia.a167e0f3-df7e-4d52-a9c3-f949145efdab"
```
</CodeBlock>
<CodeBlock title="JSON">
```json
{
  "version": "1.0.0",
  "sections": {
    "main": [
      {
        "ai": {
          "prompt": {

          },
          "languages": [
            {
              "name": "English",
              "code": "en-US",
              "voice": "cartesia.a167e0f3-df7e-4d52-a9c3-f949145efdab"
            }
          ]
        }
      }
    ]
  }
}
```
</CodeBlock>
</CodeBlocks>

Assign the script to your phone number as in
[Answer a call via SWML](/docs/platform/voice/make-and-receive-calls#answer-a-call-via-swml), then
call the number. The agent answers in the Cartesia voice.
