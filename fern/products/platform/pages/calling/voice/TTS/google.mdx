Google Cloud offers a number of robust text-to-speech
[voice models](https://cloud.google.com/text-to-speech/docs/voice-types).
SignalWire supports all Google Cloud voices in both General Availability and Preview 
[launch stages](https://cloud.google.com/products?hl=en#product-launch-stages),
except for the Studio model.

## Models

Google Cloud offers multiple TTS model types with varying quality and pricing:

| Model Type | Description |
|------------|-------------|
| `Standard` | Basic, budget-friendly TTS model |
| `WaveNet` | Deep learning-based, natural and lifelike speech |
| `Neural2` | Advanced model with human-like pronunciation |
| `Polyglot` | Multi-language variants of specific voices |

The model type is encoded in the voice name (e.g., `en-US-Neural2-A`, `es-ES-Wavenet-B`).

- [Standard](https://cloud.google.com/text-to-speech/docs/voice-types#standard_voices)
is a basic, reliable, and budget-friendly text-to-speech model.
The Standard model is less natural-sounding than WaveNet and Neural2, but more cost-effective.
- [WaveNet](https://cloud.google.com/text-to-speech/docs/voice-types#wavenet_voices)
is powered by deep learning technology and offers more natural and lifelike speech output.
- [Neural2](https://cloud.google.com/text-to-speech/docs/voice-types#neural2_voices)
is based on the same technology used to create Custom Voices
and prioritizes natural and human-like pronunciation and intonation.
- [Polyglot](https://cloud.google.com/text-to-speech/docs/polyglot?hl=en#overview)
voices have variants in multiple languages. For example, at time of writing,
the `polyglot-1` voice has variants for English (Australia), English (US), French, German, Spanish (Spain), and Spanish (US).

## Billing

Google Cloud TTS usage on SignalWire is billed according to the following SKU codes:

| Billing SKU | Models | Description |
|-------------|--------|-------------|
| `gcloud` | Standard, WaveNet | Traditional and WaveNet model billing |
| `gcloud_cog` | Neural2, Polyglot | Cognitive services (Neural2) model billing |

The billing SKU is automatically determined by the voice model type. Neural2 and Polyglot voices use the `gcloud_cog` SKU, while Standard and WaveNet voices use the `gcloud` SKU.

Consult the [Voice API Pricing](https://signalwire.com/pricing/voice) page for current rates.

## Usage

Copy the voice name in whole from the **Voice name** column of Google's table of
[supported voices](https://cloud.google.com/text-to-speech/docs/voices) — that is the voice half of
the string, not a complete voice string on its own.
Google Cloud voice IDs encode language and model information,
so no modification is needed to make these selections.
Prepend `gcloud.` and the string is ready for use.
For example: `gcloud.en-GB-Wavenet-A`

Google Cloud voice IDs conform to the following format:

```
gcloud.<voice>
```

Where `<voice>` is the complete voice name from Google's [supported voices table](https://cloud.google.com/text-to-speech/docs/voices).

**Voice name pattern:**

Google Cloud voice names follow: `<language>-<model>-<variant>`

- `language`: Language code (e.g., `en-US`, `es-ES`, `ja-JP`)
- `model`: Model type (e.g., `Standard`, `Wavenet`, `Neural2`, `Polyglot`)
- `variant`: Voice variant letter (e.g., `A`, `B`, `C`)

**Examples:**
```
gcloud.en-US-Neural2-A
gcloud.en-GB-Wavenet-B
gcloud.es-ES-Neural2-A
gcloud.ja-JP-Neural2-B
gcloud.fr-FR-Wavenet-C
gcloud.de-DE-Standard-A
gcloud.en-US-Polyglot-1
```

**Case insensitivity:**

Voice IDs are case-insensitive. These are equivalent:
```
gcloud.en-US-Neural2-A
gcloud.en-us-neural2-a
```

**Note:** Google Cloud voice IDs already encode language and model information.

## Languages

Sample all available voices with
[Google's supported voices and languages reference](https://cloud.google.com/text-to-speech/docs/voices).
Copy the voice identifier string in whole from the **Voice name** column, then prepend `gcloud.` to
get the string SignalWire accepts — the voice name on its own resolves against a default engine that
can change.

Unlike the other supported engines, Google Cloud voice identifier strings include both voice and language keys,
following the pattern `<language>-<model>-<variant>`.
Prefixed with the engine, complete voice strings look like this:

- English (UK) WaveNet female voice: `gcloud.en-GB-Wavenet-A`
- Spanish (Spain) Neural2 male voice: `gcloud.es-ES-Neural2-B`
- Mandarin Chinese Standard female voice: `gcloud.cmn-CN-Standard-D`

## Use Google Cloud voices on a call

A Google Cloud voice string such as `gcloud.en-US-Neural2-A` works wherever SignalWire speaks text: an AI
agent's `languages`, the `say_voice` of SWML's `play`, and a `tts` media item sent with Relay or
the REST Calling API. The examples below all use `gcloud.en-US-Neural2-A`. To control speech while it plays, see
[Speak text on a call](/docs/platform/voice/speak-text).

Replace these values in the samples:

| Value | Replace with |
|---|---|
| `<YOUR_BASIC_AUTH_PASSWORD>` | A password you choose for your SWML server; SignalWire sends it from the URL you give it |
| `<YOUR_PROJECT_ID>` | Your Project ID |
| `<YOUR_API_TOKEN>` | An API token with the **Voice** permission, used only in server code |
| `<YOUR_SPACE>` | Your Space's subdomain in `<YOUR_SPACE>.signalwire.com` |
| `<YOUR_CALL_ID>` | The ID of an answered call, for the REST command |

### Give an AI agent a Google Cloud voice via SWML

The [`languages`](/docs/swml/reference/calling/ai/languages#use-voice-strings) list of the SWML
[`ai`](/docs/swml/reference/calling/ai) method sets the voice an AI agent speaks in. The
[Server SDKs](/docs/server-sdks) build the document and serve it at `/swml` on port 3000, only to
requests that carry the username `signalwire` and your password.

<CodeBlocks>
<CodeBlock title="Python — SWML builder">
```python
# Install: python -m pip install signalwire-sdk
# Save as google_ai_agent.py and run: python google_ai_agent.py
from signalwire import SWMLBuilder, SWMLService

service = SWMLService(
    name="google-ai-agent",
    route="/swml",
    port=3000,
    basic_auth=("signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"),
)
SWMLBuilder(service).ai(
    prompt_text="You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride.",
    languages=[{
        "name": "English",
        "code": "en-US",
        "voice": "gcloud.en-US-Neural2-A",
    }],
)

service.serve()
```
</CodeBlock>
<CodeBlock title="TypeScript — SWML builder">
```typescript
// Install: npm install @signalwire/sdk
// This sample also runs as JavaScript: save as google-ai-agent.mjs,
// then run: node google-ai-agent.mjs
import { SWMLService } from "@signalwire/sdk";

const service = new SWMLService({
  name: "google-ai-agent",
  route: "/swml",
  port: 3000,
  basicAuth: ["signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"],
});
service.getBuilder().ai({
  // @ts-expect-error The ai verb takes a { text } prompt; the SDK types prompt as a string or array.
  prompt: { text: "You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride." },
  languages: [
    { name: "English", code: "en-US", voice: "gcloud.en-US-Neural2-A" },
  ],
});

await service.serve();
```
</CodeBlock>

To send calls from your phone number to the server, follow
[Answer a call via SWML](/docs/platform/voice/make-and-receive-calls#answer-a-call-via-swml).
Call the number, and the agent greets you in the Google Cloud voice. If you hear a different voice, the
voice string isn't in SignalWire's catalog, so the call falls back to a default voice. See
[Custom and cloned voices](/docs/platform/voice/tts#custom-and-cloned-voices).

### Speak text in a Google Cloud voice via SWML

The SWML builder's `say()` writes a [`play`](/docs/swml/reference/calling/play) with a `say:` URL
and the voice in `say_voice`. This server speaks one sentence in the Google Cloud voice, then hangs up.
Serve it and point your number at it the same way as the AI agent above.

<CodeBlocks>
<CodeBlock title="Python — SWML builder">
```python
# Install: python -m pip install signalwire-sdk
# Save as google_tts.py and run: python google_tts.py
from signalwire import SWMLBuilder, SWMLService

service = SWMLService(
    name="google-tts",
    route="/swml",
    port=3000,
    basic_auth=("signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"),
)
SWMLBuilder(service).say(
    "Hello from Bayview Taxi. You are hearing Google Cloud text to speech on SignalWire.",
    voice="gcloud.en-US-Neural2-A",
).hangup()

service.serve()
```
</CodeBlock>
<CodeBlock title="TypeScript — SWML builder">
```typescript
// Install: npm install @signalwire/sdk
// This sample also runs as JavaScript: save as google-tts.mjs,
// then run: node google-tts.mjs
import { SWMLService } from "@signalwire/sdk";

const service = new SWMLService({
  name: "google-tts",
  route: "/swml",
  port: 3000,
  basicAuth: ["signalwire", "<YOUR_BASIC_AUTH_PASSWORD>"],
});
service.getBuilder()
  .say("Hello from Bayview Taxi. You are hearing Google Cloud text to speech on SignalWire.", {
    voice: "gcloud.en-US-Neural2-A",
  })
  .hangup();

await service.serve();
```
</CodeBlock>
<CodeBlock title="YAML">
```yaml
version: 1.0.0
sections:
  main:
    - play:
        url: "say:Hello from Bayview Taxi. You are hearing Google Cloud text to speech on SignalWire."

    - hangup: {}
```
</CodeBlock>
<CodeBlock title="JSON">
```json

  "sections": {
    "main": [
      {
        "play": {
          "url": "say:Hello from Bayview Taxi. You are hearing Google Cloud text to speech on SignalWire.",
          "say_voice": "gcloud.en-US-Neural2-A"
```

### Speak text in a Google Cloud voice via WebSocket (Relay)

A Relay client in the [Server SDKs](/docs/server-sdks) passes the voice string in a `tts` media
item. This handler answers calls on the `default` topic, speaks in the Google Cloud voice, and hangs
up when the speech ends.

<CodeBlocks>
<CodeBlock title="Python — Relay client">
```python
# Install: python -m pip install signalwire-sdk
# Save as google_relay.py and run: python google_relay.py
from signalwire.relay import RelayClient

client = RelayClient(
    project="<YOUR_PROJECT_ID>",
    token="<YOUR_API_TOKEN>",
    contexts=["default"],
)

@client.on_call
async def handle_call(call):
    await call.answer()

    async def hang_up_after_playback(_event):
        if call.state != "ended":
            await call.hangup()

    await call.play([{
        "type": "tts",
        "params": {
            "text": "Hello from Bayview Taxi. You are hearing Google Cloud text to speech on SignalWire.",
            "voice": "gcloud.en-US-Neural2-A",
        },
    }], on_completed=hang_up_after_playback)
    await call.wait_for_ended()

client.run()
```
</CodeBlock>
<CodeBlock title="TypeScript — Relay client">
```typescript
// Install: npm install @signalwire/sdk
// This sample also runs as JavaScript: save as google-relay.mjs,
// then run: node google-relay.mjs
import { RelayClient } from "@signalwire/sdk";

const client = new RelayClient({
  project: "<YOUR_PROJECT_ID>",
  token: "<YOUR_API_TOKEN>",
  contexts: ["default"],
});

client.onCall(async (call) => {
  await call.answer();
  await call.play([{
    type: "tts",
    params: {
      text: "Hello from Bayview Taxi. You are hearing Google Cloud text to speech on SignalWire.",
      voice: "gcloud.en-US-Neural2-A",
    },
  }], {
    onCompleted: async () => {
      if (call.state !== "ended") await call.hangup();
    },
  });
  await call.waitForEnded();
});

await client.run();
```
</CodeBlock>
</CodeBlocks>

To route calls from your phone number to the handler, assign the number to a Relay Application
on the `default` topic, as described in
[Answer a call via WebSocket (Relay)](/docs/platform/voice/make-and-receive-calls#answer-a-call-via-websocket-relay).

### Speak text in a Google Cloud voice on a call in progress via REST

To speak on a call that's already up, such as from a backend job, send
[`calling.play`](/docs/apis/rest/calls/call-commands) with the call's ID and the same `tts` media
item. `control_id` names the playback so later commands can stop or pause it.

<CodeBlocks>
<CodeBlock title="Python — REST client">
```python
# Install: python -m pip install signalwire-sdk
# Save as google_rest.py and run: python google_rest.py
from signalwire.rest import RestClient

client = RestClient(
    project="<YOUR_PROJECT_ID>",
    token="<YOUR_API_TOKEN>",
    host="<YOUR_SPACE>.signalwire.com",
)

client.calling.play(
    "<YOUR_CALL_ID>",
    control_id="google-greeting",
    play=[{
        "type": "tts",
        "params": {
            "text": "Hello from Bayview Taxi. You are hearing Google Cloud text to speech on SignalWire.",
            "voice": "gcloud.en-US-Neural2-A",
        },
    }],
)
```
</CodeBlock>
<CodeBlock title="TypeScript — REST client">
```typescript
// Install: npm install @signalwire/sdk
// This sample also runs as JavaScript: save as google-rest.mjs,
// then run: node google-rest.mjs
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "<YOUR_PROJECT_ID>",
  token: "<YOUR_API_TOKEN>",
  host: "<YOUR_SPACE>.signalwire.com",
});

await client.calling.play("<YOUR_CALL_ID>", [{
  type: "tts",
  params: {
    text: "Hello from Bayview Taxi. You are hearing Google Cloud text to speech on SignalWire.",
    voice: "gcloud.en-US-Neural2-A",
  },
}], { control_id: "google-greeting" });
```
</CodeBlock>
<CodeBlock title="cURL — Calling API">
```bash
curl -X POST "https://<YOUR_SPACE>.signalwire.com/api/calling/calls" \
  -u "<YOUR_PROJECT_ID>:<YOUR_API_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "command": "calling.play",
    "id": "<YOUR_CALL_ID>",
    "params": {
      "control_id": "google-greeting",
      "play": [
        {
          "type": "tts",
          "params": {
            "text": "Hello from Bayview Taxi. You are hearing Google Cloud text to speech on SignalWire.",
            "voice": "gcloud.en-US-Neural2-A"
          }
        }
      ]
    }
  }'
```
</CodeBlock>
</CodeBlocks>

The command returns once SignalWire accepts it, and the call hears the sentence in the Google Cloud
voice.

### Create a SWML Script that uses a Google Cloud voice

A SWML Script hosted in SignalWire runs the Google Cloud-voiced AI agent above without a server of
your own.

1. In the Dashboard, open **My Resources**, select **+ Add**, then **Script**, then **SWML Script**.
2. Name the script and leave **Used For** set to **Calling**.
3. Under **Handle Calls Using**, choose **Hosted Script** and paste this document into
   **Primary Script**.
4. Select **Create**.

<CodeBlocks>
<CodeBlock title="YAML">
```yaml
version: 1.0.0
sections:
  main:
    - ai:
        prompt:
          text: "You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride."
        languages:
          - name: English
            code: en-US
            voice: "gcloud.en-US-Neural2-A"
```
</CodeBlock>
<CodeBlock title="JSON">
```json
{
  "version": "1.0.0",
  "sections": {
    "main": [
      {
        "ai": {
          "prompt": {
            "text": "You are Ada, the dispatcher for Bayview Taxi. Greet the caller and help them book a ride."
          },
          "languages": [
            {
              "name": "English",
              "code": "en-US",
              "voice": "gcloud.en-US-Neural2-A"
            }
          ]
        }
      }
    ]
  }
}
```
</CodeBlock>
</CodeBlocks>

Assign the script to your phone number as in
[Answer a call via SWML](/docs/platform/voice/make-and-receive-calls#answer-a-call-via-swml), then
call the number. The agent answers in the Google Cloud voice.
