Deploy a voice AI agent and call it over the public switched telephone network (PSTN) in about five minutes. Pick a tab below and follow it start to finish.

<Tabs>
<Tab title="Server SDK">

<Steps>

### Create a free account

[Sign up for a SignalWire account](https://signalwire.com/signup), or log in if you already have one.

### Install the SDK and write your agent

```bash
pip install signalwire-sdk
```

```python title="agent.py" {9-11}
from signalwire import AgentBase

agent = AgentBase(name="assistant")
agent.set_prompt_text(
    "You are a knowledgeable developer. Have an open-ended discussion "
    "with the caller about SignalWire and programmable communications."
)

# datetime and math are built-in skills, ready to add without writing a tool
agent.add_skill("datetime")
agent.add_skill("math")

if __name__ == "__main__":
    agent.run()
```

### Run it and expose it to the internet

```bash
python agent.py
```

The agent starts a local server on port 3000 and prints a Basic Auth username and password to the terminal. Note them down, then open a second terminal and give the agent a public URL:

```bash
ngrok http 3000
```

ngrok prints a forwarding address that looks like `https://abc123.ngrok-free.app`. That's your agent's public URL.

### Assign a phone number and call it

[Buy a phone number](https://my.signalwire.com?page=phone_numbers) using your $5 promotional credit. From your [SignalWire Dashboard](https://my.signalwire.com), click **Script**, then **External URL**, and set the Primary Script URL to `https://<username>:<password>@<your-ngrok-address>/`, using the credentials from your agent's terminal output. Select **Create**, then assign the number from your **Phone Numbers** list: click **Edit Settings**, and under **Inbound Call Settings**, choose **Assign Resource** and pick the script you just created.

Dial your newly configured AI agent over the PSTN from your cell phone or a VoIP dialer.

</Steps>

For a full walkthrough, including a development environment, custom tools, and deployment, see the [Server SDK quickstart](/docs/server-sdks/guides/quickstart).

</Tab>
<Tab title="SWML">

<Steps>

### Create a free account

[Sign up for a SignalWire account](https://signalwire.com/signup), or log in if you already have one.

### Create a SWML script

From your [SignalWire Dashboard](https://my.signalwire.com), click **Script**, then **SWML script**.
Paste the following script into the Primary Script field, then select **Create**.

<Info title="Fun fact">This simple YAML/JSON document is a complete calling application!</Info>

```yaml title="swml.yaml"
version: 1.0.0
sections:
  main:
    - ai:
        prompt:
          text: You are a knowledgeable developer. Have an open-ended discussion with the caller about SignalWire and programmable communications.
```

### Assign a phone number

[Buy a phone number](https://my.signalwire.com?page=phone_numbers) using your $5 promotional credit.
Select the number from your **Phone Numbers** list and click **Edit Settings**.
Under **Inbound Call Settings**, choose **Assign Resource**, pick the SWML script you just created,
and click **Save**.

### Give it a call

Dial your newly configured AI agent over the PSTN from your cell phone or a VoIP dialer.

</Steps>

</Tab>
</Tabs>

The YAML above is what a Server SDK agent generates for you at request time: `agent.run()` serves the same `ai` verb over HTTP, built from your Python. Writing SWML by hand and building it with a Server SDK produce the same document — one authored directly, one generated from code. For a single prompt like this one, both get you to a working agent equally fast. As an agent grows more tools, more state, and a real deployment pipeline, most teams keep that logic in code, where it lives alongside the rest of the application and its tests.
