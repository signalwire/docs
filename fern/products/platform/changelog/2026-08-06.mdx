## E911 registration is self-service through the REST API

You can now register an emergency address and enable E911 on a number yourself, instead of filing a support ticket. The E911 guide covers creating a carrier-validated address, assigning it to a number, and waiting for `e911_status` to become `active`, with examples rendered from the API spec.
