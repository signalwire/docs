## E911 self-service added to the REST API

Registering an emergency address and enabling E911 on a US phone number is now self-service, 
and no longer requires a support ticket. 

Create a carrier-validated address, assign it to the number, then poll until `e911_status` reads `active`.

To get started, read the [E911 guide](/docs/platform/e911)
and review the [API reference](/docs/apis/rest/e-911-addresses/assign-e-911-address).
