## Agents SDK for Python released

Build real-time AI voice agents in Python with the SignalWire Agents SDK, now part of the
[Server SDKs](/docs/server-sdks). Agents connect over SIP, PSTN, WebRTC, and messaging, and you can:

- Run agents as microservices, AWS Lambda functions, or CGI scripts.
- Add skills such as search, knowledge lookups, or custom tool calls with one line of code.
- Use tools built for the Model Context Protocol (MCP) without rewriting them.
