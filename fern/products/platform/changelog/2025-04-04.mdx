## Datasphere documents can be re-uploaded and re-vectorized

Re-upload a Datasphere document and re-vectorize it, so you can iterate on the content an
AI agent retrieves.

## Datasphere API endpoints for documents and chunks added

Retrieve a Datasphere document with [Get a document](/docs/apis/rest/documents/get-document).
To work with the chunks a document is split into, use
[List document chunks](/docs/apis/rest/chunks/list-document-chunks),
[Get a document chunk](/docs/apis/rest/chunks/get-document-chunk), and
[Delete a document chunk](/docs/apis/rest/chunks/delete-document-chunk).
