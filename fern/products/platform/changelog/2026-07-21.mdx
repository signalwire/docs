## Alias address management added to the REST API

Create, rename, and delete alias addresses from your own code instead of the Dashboard.
An alias is a named route in the `public` or `private` context, such as `/public/support`,
that forwards calls and messages to the resource you point it at.
[Create alias address](/docs/apis/rest/alias-addresses/create-alias-address) takes a `name` and the `resource_id` of its handler,
[Update alias address](/docs/apis/rest/alias-addresses/update-alias-address) renames it or changes its channels, codecs, or context,
and [Delete alias address](/docs/apis/rest/alias-addresses/delete-alias-address) removes it.
The handler can't be changed after creation: delete the alias and create a new one instead.

Two new validation codes, `invalid_channels` and `invalid_codecs`, are listed with the other [error codes](/docs/apis/error-codes).
See [Addresses](/docs/platform/addresses) for how contexts and aliases resolve.
