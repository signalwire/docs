## Dashboard home and navigation reorganized around resources

The Dashboard home page now has quick-link cards for creating new resources such as AI agents, SIP endpoints,
and subscribers. A new **My Resources** menu lists the resources you've already built, grouped by type.

## Assign a resource to a phone number or SIP endpoint in one step

Assigning a Call Fabric resource to a phone number or SIP endpoint is now a single **Assign** action in the
Dashboard.

## AI agent language selection starts with the provider

When you build an AI agent in the Dashboard, the **Languages** tab now has you choose a language by provider
first, then a voice.
