## Inbound messaging added to SWML

Handle inbound messages with SWML by assigning a SWML Script or SWML Webhook to a phone number.
[Messaging SWML](/docs/swml/reference/messaging) supports routing, conditional logic, and
replies, including switching on message content, variable expansion, HTTP requests, and
multi-section documents.

In the Dashboard, open **Phone Numbers**, select a number, and assign the script or webhook
under **Inbound Message Settings**. Over the REST API, create a handler with
[Create a SWML script](/docs/apis/rest/swml-scripts/create-swml-script) or
[Create a SWML webhook](/docs/apis/rest/swml-webhook/create-swml-webhook), then
[assign it to the phone number](/docs/apis/rest/phone-routes/assign-resource-phone-route).
This is available in the new Dashboard and the REST API; on the legacy Dashboard, contact
Support or Sales for access.

## Undelivered MMS error code changed from `30005` to `30011`

Some MMS delivery failures were misclassified as `unknown_destination_handset` (`30005`).
They're now reported as `mms_expired_rejected_failed_or_unsupported` (`30011`), which matches
the actual failure. See [error codes](/docs/apis/error-codes).
