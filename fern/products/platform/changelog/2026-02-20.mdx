## Fixed: Inbound messages to numbers without a handler were missing from logs

Inbound messages sent to a number with no handler assigned didn't appear in your logs. They now do, so you can see every message the number received.

## Fixed: Phone number status callback URL couldn't be updated with a Relay application handler

You couldn't update a phone number's status callback URL while a Relay application was assigned as its handler. This is now fixed.

## Fixed: `FriendlyName` wasn't saved when creating a number through the Compatibility API

The optional `FriendlyName` field was ignored when you [created a phone number](/docs/compatibility-api/rest/incoming-phone-numbers/create-incoming-phone-number) through the Compatibility API. It's now stored.
