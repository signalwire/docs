## Project API token list and regenerate endpoints added to the REST API

Rotate a Project API token without recreating it:
[Regenerate API token](/docs/apis/rest/project-tokens/regenerate-token) replaces a token's value
and keeps its ID, name, and permissions. The previous value stops working immediately, and the
new one is returned only in that response. To find the ID of each token you can manage, use
[List API tokens](/docs/apis/rest/project-tokens/list-tokens), which never returns token values.

Every token response, including [Create API token](/docs/apis/rest/project-tokens/create-token)
and [Update API token](/docs/apis/rest/project-tokens/update-token), now includes `last_used_at`,
the time the token last authenticated a request, and `revoked_at`.
