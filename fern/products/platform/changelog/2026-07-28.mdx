## Subscriber address endpoints moved to `/api/fabric/subscriber/addresses`, old path deprecated

Call `/api/fabric/subscriber/addresses` to list and fetch the addresses a Subscriber can reach,
alongside the other Subscriber endpoints: see
[List Resource Addresses from a Client](/docs/apis/rest/addresses/list-resource-addresses-client)
and [Get Resource Address from a Client](/docs/apis/rest/addresses/get-resource-address-client).
The old `/api/fabric/addresses` path still answers requests made with a Subscriber Access Token
(SAT) and returns the same response, with a `Deprecation: true` header and a `Link` header
naming the new path. No removal date is set.
