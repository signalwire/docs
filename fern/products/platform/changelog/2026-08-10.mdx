## Browser SDK v3 guides are retired

The Browser SDK v3 guides are removed and v3 is now reference-only, matching v2. The v3 and Click-to-Call reference documentation is unchanged, and the old guide URLs redirect. Note that v4 does not yet implement recording, RTMP streaming, or interactive live streaming, which some removed guides covered.

## New guide for AI tool calling

A new tool calling guide covers the mental model where the AI agent runs the conversation and your code owns the business logic, how a SWAIG function works, and a complete order-status agent in both SWML and the Python Server SDK. The best practices guide is rewritten around writing for realtime voice, speech-recognition hints, and testing with post-prompt reports.
