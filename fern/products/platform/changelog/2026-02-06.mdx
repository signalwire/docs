## Call quality metrics added to call details

Each call's details in the Dashboard now include call quality metrics, so you can troubleshoot audio problems on a single call:

- MOS score for overall audio quality
- Jitter
- Packet loss and packet statistics
- DTMF packet counts and other advanced metrics

## One SWML script editor across the Dashboard

The Dashboard now uses one code editor for SWML scripts everywhere. It adds:

- Multi-line formatting
- Basic syntax checks for YAML and XML
- Schema validation for SWML written in YAML
- A resizable editor
- Starter content when you create a new SWML script, instead of a blank editor
