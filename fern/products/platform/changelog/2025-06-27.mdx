## Media protection and HTTPS settings added per project

Each project now has its own settings to protect media URLs and to force HTTPS, so projects in the same Space
can be configured differently:

- **Protect media URLs** for recordings, messages, and faxes. When enabled, a media URL must be authenticated
  to be accessed.
- **Force HTTPS requests** for external application requests. When enabled, HTTP URLs are converted to HTTPS
  when saved.

See [media protection](/docs/platform/media-protection).

## Guest tokens hidden from subscriber lists

Guest tokens issued for temporary subscriber access no longer appear on the **Subscribers** tab under
**My Resources** or in API responses. See
[Create a subscriber guest token](/docs/apis/rest/subscribers/tokens/create-subscriber-guest-token).

## Postman and Bruno API collections updated

The SignalWire [Postman and Bruno API collections](https://github.com/signalwire/rest-apis) now include the
Fabric APIs, the cXML start and update stream endpoints, the Datasphere document and chunk endpoints, and the
RELAY recording endpoints. Download a collection and set its authentication variables to your own to start
making requests.
