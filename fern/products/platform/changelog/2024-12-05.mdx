## Datasphere added to the Dashboard

Add, delete, and tag documents in Datasphere from the Dashboard. Open the **Datasphere** tab
in the left menu, and use tags to group related documents.

## Datasphere API returns a clear error for documents over the size limit

Submitting a document that exceeds the size limit to the Datasphere API now returns a clear
error message. See [Create a document](/docs/apis/rest/documents/create-document).

## Call Fabric address visibility added to the API

Set the visibility of Call Fabric addresses through the API. See
[Addresses](/docs/platform/addresses).
