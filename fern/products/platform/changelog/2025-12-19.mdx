## cXML call events show API updates

When you update a cXML call through the API, the call's events show what changed, such as a status moving from In Progress to Completed.
The events appear in both the cXML calls view and the voice logs.

<Frame>
  ![A call's event list showing a "Call ended via API" event with the status change from In Progress to Completed.](/assets/images/changelog/2025-12-19/cxml-call-update-event.webp)
</Frame>
