## Webhook reference pages document the expected response

Webhook pages in the REST API reference now describe both directions: the payload SignalWire sends to your endpoint, and the response your endpoint returns. That includes the reply SignalWire parses from SWAIG tool webhooks, previously described only in prose, and a Bedrock-specific SWAIG output shape reflecting what amazon_bedrock agents actually read.
