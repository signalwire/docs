## Messaging SWML support added to the Dashboard SWML editor

The SWML editor in the new Dashboard now offers autocomplete, suggestions, and schema
validation for messaging SWML scripts, as it already did for voice scripts. The editor applies
the schema that matches your script type. If a script looks like the other type, the editor
flags it and offers to switch the type in one click.

## Custom SIP headers added to REST API call creation

Pass custom SIP headers when you create an outbound call through the REST API, to carry
metadata for routing, tracing, or downstream systems. This matches the `connect.headers`
support in SWML.
