## Error codes and messages added to Dashboard message logs

See why a message failed directly in the Dashboard: message logs now show the error code and
error message whenever either is present. Previously, these values were available only
through the API.

</Frame>

## Scripts filter split into SWML and cXML in the Dashboard

The Scripts filter on the Dashboard Resources page is now two filters, **SWML Scripts** and
**CXML Scripts**, so you can list scripts of one type at a time.

<Frame>
  ![The Resources page filter menu listing resource types, including separate CXML Scripts and SWML Scripts options.](/assets/images/changelog/2026-04-17/resources-filter-swml-cxml.webp)
</Frame>

## `codecs` accepts a comma-separated string on dial requests

Pass `codecs` as either an array of strings or a comma-separated string when you dial a call
with [Send call commands](/docs/apis/rest/calls/call-commands). Supported codecs are `PCMU`,
`PCMA`, `OPUS`, `G729`, `G722`, `VP8`, and `H264`.
