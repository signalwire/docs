## Voice Analytics dashboard added

See the health of voice calls across your project in one place: open **Analytics** in the
Dashboard and select **Voice**. The dashboard shows call volume, quality, and performance
trends, so you can spot problems without building your own observability tooling.

## Conference audience feature removed

The conference audience feature is deprecated and has been removed from the platform.

## Dashboard home info panel removed

The Dashboard home page no longer has the expandable info panel. Links to the Changelog,
Support, Docs, Community resources, and the Status page now sit in the top-right menu, and
documentation links open in a new window.

## Bahrain point of presence retired

The Bahrain real-time communications point of presence retires on March 27, 2026. After that,
calls route automatically to the next closest available node, and calls already in progress on
the Bahrain node continue until they end. You don't need to change anything.
