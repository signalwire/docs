## Fixed: Using `send_sms` in a messaging SWML script returned an unclear error

Using the voice-only [`send_sms`](/docs/swml/reference/calling/send-sms) method in a
[messaging SWML](/docs/swml/reference/messaging) script returned an error message that didn't
explain what went wrong. This is now fixed.
