## New SWML reference for ai.multilingual

The new ai.multilingual reference documents how one AI agent detects the language a caller speaks and answers in it, switching whenever the caller does — you give it a voice per language and it selects the match. Voice examples across the docs now always name their TTS engine, since a bare voice ID only works while it matches the platform default, which can change.

## Verify SWML request signatures

A new guide documents the HMAC signature SignalWire sends in the X-Signalwire-Signature header with every request for a SWML document, and shows how to verify it in Node, Python, or Ruby so your endpoint can reject forged requests. The signing isn't new — the documentation is, and the handle-incoming-calls guide now points to it.
