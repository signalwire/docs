## Send long text messages as a single MMS

Send a long text message as one MMS instead of several SMS segments. Set `SendAsMms` to `true` on the
Compatibility API's [Create a Message](/docs/compatibility-api/rest/messages/create-message) endpoint, or
`send_as_mms` in RELAY, and the message goes out as MMS even when the body contains only text.
