## Caller ID name (CNAM) self-service added to the REST API

Set the name call recipients see for your SignalWire phone numbers without opening a support ticket.
[Request a caller ID name](/docs/apis/rest/caller-id-name/request-caller-id-name) queues the name for compliance review,
[Get the caller ID name](/docs/apis/rest/caller-id-name/retrieve-caller-id-name) reports its `status` until it is `approved`, `rejected`, or `failed`,
and [Clear the caller ID name](/docs/apis/rest/caller-id-name/clear-caller-id-name) removes it.
Numbers whose carrier doesn't offer CNAM return `422`; for those, the support process in
[Caller ID & CNAM](/docs/platform/voice/how-to-set-caller-id-or-cnam) still applies.
