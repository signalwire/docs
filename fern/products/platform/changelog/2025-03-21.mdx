## cXML scripts and webhooks can handle faxes

Assign a cXML script or cXML webhook as the handler for incoming faxes. See
[Fax](/docs/platform/fax).

## AI agent errors added to call logs

Call logs now include more detail about errors an AI agent hits during a call, such as an
invalid function schema.
