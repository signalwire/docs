## Relay recordings added to the Dashboard logs

Find Relay recordings in the **Logs** menu of the Dashboard.

## SMS routing supports alphanumeric sender IDs

SMS routing now accepts alphanumeric values in the `From` field.

## Post-prompt penalty controls added to the AI Agent builder

Set penalty controls, such as frequency penalty, on an AI agent's post-prompt when you build
the agent in the Dashboard. Choosing a language and voice gender for the agent is also
simpler.
