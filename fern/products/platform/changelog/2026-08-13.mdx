## AI post-prompt and debug webhooks fully documented

The REST API reference now defines the AI post-prompt callback, the AI debug webhook, and the Bedrock post-prompt callback — including roughly 20 previously undocumented post-prompt fields and the 47 event types the debug stream can carry. The SWML ai and amazon_bedrock pages embed these definitions, so the payload lists track the spec instead of drifting.
