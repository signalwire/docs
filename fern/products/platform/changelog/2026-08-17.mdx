## Chat with an AI agent over the REST API

New documentation for the AI chat API: hold a text conversation with the same AI agent a phone call would reach, over a JSON-RPC endpoint with six methods. A guide covers both connection paths, the Python Server SDK reference documents the new AIChatClient and ChatGateway classes, and the error codes page gains the JSON-RPC error table.
