## AI agent chat added over HTTP

You can now chat by text with an AI agent that was previously reachable only by voice, over a JSON-RPC endpoint with six methods. The agent keeps its prompt, its tools, and its post-prompt reporting.

The Python Server SDK wraps the endpoint in [`AIChatClient`](/docs/server-sdks/reference/python/agents/ai-chat-client) and [`ChatGateway`](/docs/server-sdks/reference/python/agents/chat-gateway). JSON-RPC failures are listed with the rest of the [error codes](/docs/apis/error-codes).
