## SIP gateway transport settings added

You can now set the port, protocol, and authentication credentials on a SIP gateway. See
[Create a SIP gateway](/docs/apis/rest/sip-gateway/create-sip-gateway).

## Subscriber token refresh added to the REST API

Refresh a subscriber token programmatically with
[Refresh a subscriber token](/docs/apis/rest/subscribers/tokens/refresh-subscriber-token), which keeps
long-lived sessions going without issuing a new token from scratch.
