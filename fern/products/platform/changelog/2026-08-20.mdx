## Space Administration API added to the REST API

Manage your Space over REST instead of in the Dashboard: rename it, set its geographic permissions,
invite and remove members and choose which Projects each member can reach, read the balance and top it up,
configure low balance notifications and auto top-up, maintain the billing profile, list and download monthly
statements as JSON, CSV, or PDF, and read usage, payment history, and payment methods.
Every endpoint lives under `/api/space`, so none takes a Project in its path.

The API authenticates with a [Personal access token](/docs/apis/authorization#personal-access-tokens),
a user-level credential created from your user menu in the Dashboard that carries your owner or admin role
rather than a Project's scopes. Start with [Retrieve the space](/docs/apis/rest/space/get-space),
[List members](/docs/apis/rest/space/members/list-members), and
[Retrieve the balance](/docs/apis/rest/space/balance/get-balance).

## Personal access tokens accepted on the Projects and Project Tokens APIs

Create and delete root Projects over the API by authenticating
[Create a project](/docs/apis/rest/projects/create-subproject) and
[Delete a project](/docs/apis/rest/projects/delete-subproject) with a Personal access token; omit
`parent_project_id` to create a root Project. Then give the new Project its first credential with
[Create API token](/docs/apis/rest/project-tokens/create-token), naming it in `project_id`.
With a Project API token, both APIs behave as before and remain limited to Subprojects.

Deleting a Project now also requires that its Subprojects are removed first (`subprojects_must_be_removed`),
and the last Project in a Space can't be deleted (`last_project_cannot_be_deleted`).
