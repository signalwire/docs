Detect a fax tone. A typed convenience over [`detect()`][detect] that builds the
`{"type": "fax", "params": {...}}` configuration for you. All parameters are
keyword-only.

## **Parameters**

<ParamField path="tone" type="str | None" default="None" toc={true}>
  Which tone to detect: `"CED"` (called station) or `"CNG"` (calling station).
  Omit to match either tone.
</ParamField>

<ParamField path="timeout" type="float | None" default="None" toc={true}>
  Maximum seconds to run the detector before stopping. Keyword-only.
</ParamField>

<ParamField path="on_completed" type="Callable[[RelayEvent], Any] | None" default="None" toc={true}>
  Callback invoked when the operation reaches a terminal state. Can be a regular
  function or async coroutine. Keyword-only.
</ParamField>

## **Returns**

[`DetectAction`](/docs/server-sdks/reference/python/relay/actions) -- An action handle with `stop()` and `wait()` methods. It resolves on the first detection result.

## **Example**

```python {13-14}
from signalwire.relay import RelayClient

client = RelayClient(
    project="your-project-id",
    token="your-api-token",
    host="your-space.signalwire.com",
    contexts=["default"],
)

@client.on_call
async def handle_call(call):
    await call.answer()
    action = await call.detect_fax(tone="CED", timeout=20)
    event = await action.wait()

client.run()
```
