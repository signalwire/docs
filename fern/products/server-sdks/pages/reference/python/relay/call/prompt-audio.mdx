Play an audio file as a prompt and collect input. A typed convenience over
[`play_and_collect()`][play-and-collect] that builds the audio media item for you.

## Parameters

<ParamField path="url" type="str" required={true} toc={true}>
  URL of the audio file to play as the prompt.
</ParamField>

<ParamField path="collect" type="dict" required={true} toc={true}>
  Input collection configuration, in the same format as
  [`play_and_collect()`][play-and-collect].
</ParamField>

<ParamField path="volume" type="float | None" default="None" toc={true}>
  Volume adjustment in dB, from `-40.0` to `40.0`. Keyword-only.
</ParamField>

<ParamField path="on_completed" type="Callable[[RelayEvent], Any] | None" default="None" toc={true}>
  Callback invoked when the operation reaches a terminal state. Can be a regular
  function or async coroutine. Keyword-only.
</ParamField>

## Returns

[`CollectAction`](/docs/server-sdks/reference/python/relay/actions) -- An action handle that resolves when input is collected, the operation times out, or an error occurs.

## Example

```python {13-16}
from signalwire.relay import RelayClient

client = RelayClient(
    project="your-project-id",
    token="your-api-token",
    host="your-space.signalwire.com",
    contexts=["default"],
)

@client.on_call
async def handle_call(call):
    await call.answer()
    action = await call.prompt_audio(
        "https://example.com/menu.mp3",
        {"digits": {"max": 1, "digit_timeout": 5}},
    )
    event = await action.wait()

client.run()
```
