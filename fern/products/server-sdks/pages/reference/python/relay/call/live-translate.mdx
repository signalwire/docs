Start, summarize, or stop live translation on the call. Live translation recognizes what each
party says, translates it, and speaks the translation to the other party in place of the original
audio. The `action` dictionary takes the same shape as the [`live_translate`][swml-live-translate]
SWML method: a single `start`, `summarize`, `inject`, or `stop` key.

<Info>
See the [translate calls guide][translate-calls] for which language each party speaks and for the
webhook events.
</Info>

## **Parameters**

<ParamField path="action" type="dict" required={true} toc={true}>
  The action to perform. Set exactly one of `start`, `summarize`, `inject`, or `stop`.
</ParamField>

<Indent>

<ParamField path="action.start" type="dict" toc={true}>
  Start a live translation session.
</ParamField>

<Indent>

<ParamField path="action.start.from_lang" type="str" required={true} toc={true}>
  One of the two languages of the conversation, such as `"es-ES"`. `from_voice` speaks it.
</ParamField>

<ParamField path="action.start.to_lang" type="str" required={true} toc={true}>
  The other language of the conversation, such as `"en-US"`. `to_voice` speaks it.
</ParamField>

<ParamField path="action.start.direction" type="list[str]" required={true} toc={true}>
  The sides of the call to translate: `"remote-caller"`, `"local-caller"`, or both. The order
  decides which side speaks which language.
</ParamField>

<ParamField path="action.start.webhook" type="str" toc={true}>
  The URL that receives translation events as HTTP `POST` requests.
</ParamField>

<ParamField path="action.start.from_voice" type="str" default="azure.en-US-RyanMultilingualNeural" toc={true}>
  The voice that speaks translations into `from_lang`, as `<engine>.<voice>` with a lowercase
  engine name, such as `"azure.es-ES-ElviraNeural"`.
</ParamField>

<ParamField path="action.start.to_voice" type="str" default="azure.en-US-RyanMultilingualNeural" toc={true}>
  The voice that speaks translations into `to_lang`, such as `"elevenlabs.josh"`.
</ParamField>

<ParamField path="action.start.filter_from" type="str" toc={true}>
  A tone filter for speech in `from_lang`: `"polite"`, `"rude"`, `"professional"`,
  `"shakespeare"`, `"gen-z"`, or a custom instruction prefixed with `"prompt:"`.
</ParamField>

<ParamField path="action.start.filter_to" type="str" toc={true}>
  A tone filter for speech in `to_lang`, with the same values as `filter_from`.
</ParamField>

<ParamField path="action.start.live_events" type="bool" default="False" toc={true}>
  Whether to send each translated utterance to the webhook as it is spoken.
</ParamField>

<ParamField path="action.start.ai_summary" type="bool" default="False" toc={true}>
  Whether to add AI summaries to the event sent to the webhook when the session ends.
</ParamField>

<ParamField path="action.start.ai_summary_prompt" type="str" toc={true}>
  The prompt that tells the AI how to summarize the conversation when `ai_summary` is enabled.
</ParamField>

<ParamField path="action.start.speech_engine" type="str" default="deepgram" toc={true}>
  The speech recognition engine: `"deepgram"` or `"google"`.
</ParamField>

<ParamField path="action.start.speech_timeout" type="int" default="60000" toc={true}>
  The timeout for speech recognition, in milliseconds.
</ParamField>

<ParamField path="action.start.vad_silence_ms" type="int" toc={true}>
  The silence, in milliseconds, that ends an utterance. Defaults to `700` with Deepgram and `500`
  with Google.
</ParamField>

<ParamField path="action.start.vad_thresh" type="int" default="400" toc={true}>
  Voice activity detection threshold, from `0` to `1800`.
</ParamField>

</Indent>

<ParamField path="action.summarize" type="dict" toc={true}>
  Request an AI summary of the conversation so far, while translation continues. Pass an empty
  dictionary to send the summary to the webhook from `start` with the default summary prompt.
</ParamField>

<Indent>

<ParamField path="action.summarize.webhook" type="str" toc={true}>
  The URL that receives the summary.
</ParamField>

<ParamField path="action.summarize.prompt" type="str" toc={true}>
  The prompt that tells the AI how to summarize the conversation.
</ParamField>

</Indent>

<ParamField path="action.inject" type="dict" toc={true}>
  Insert a message into the session, to be translated and spoken on the call.
</ParamField>

<Indent>

<ParamField path="action.inject.message" type="str" required={true} toc={true}>
  The message to translate and speak.
</ParamField>

<ParamField path="action.inject.direction" type="str" required={true} toc={true}>
  The side of the call: `"remote-caller"` or `"local-caller"`.
</ParamField>

</Indent>

<ParamField path="action.stop" type="dict" toc={true}>
  Stop the live translation session on both sides. Pass an empty dictionary.
</ParamField>

</Indent>

<ParamField path="status_url" type="str | None" default="None" toc={true}>
  A status URL sent with the command. Translation events go to `action.start.webhook`.
</ParamField>

## **Returns**

`dict` -- Server response confirming the operation.

## **Example**

```python {14-21}
from signalwire.relay import RelayClient

client = RelayClient(
    project="your-project-id",
    token="your-api-token",
    contexts=["default"],
)

@client.on_call
async def handle_call(call):
    await call.answer()

    # Start live translation between Spanish and English
    await call.live_translate({
        "start": {
            "from_lang": "es-ES",
            "to_lang": "en-US",
            "direction": ["local-caller", "remote-caller"],
            "webhook": "https://example.com/translation-events",
        }
    })

    # Connect the caller to the other party, then let the call proceed...
    await call.wait_for_ended()

client.run()
```
