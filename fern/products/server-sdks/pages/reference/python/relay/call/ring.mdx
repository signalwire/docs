Send 180 Ringing on an inbound call without answering it. The caller hears ringback,
and an upstream carrier's post-dial-delay timer is satisfied while your application
decides what to do with the call. Ringing is signalling only: no media flows, the call
isn't answered, and it isn't billed as answered.

<Note>
Ringing takes control of the call, as [`answer()`][answer] does, so the call can't be
handed to another consumer with [`pass_()`][pass] afterward.
</Note>

## **Parameters**

None.

## **Returns**

`dict` -- Server response confirming the ring operation.

## **Example**

```python {11}
from signalwire.relay import RelayClient

client = RelayClient(
    project="your-project-id",
    token="your-api-token",
    contexts=["office"],
)

@client.on_call
async def handle_call(call):
    await call.ring()      # the caller hears ringback; the call isn't answered
    # ... look up where the call should go, then:
    await call.answer()
    await call.hangup()

client.run()
```
