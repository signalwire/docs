Play text-to-speech. A typed convenience over [`play()`][play] that builds the
`{"type": "tts", "params": {...}}` media item for you.

## Parameters

<ParamField path="text" type="str" required={true} toc={true}>
  The text to speak.
</ParamField>

<ParamField path="language" type="str | None" default="None" toc={true}>
  Language code for the voice, such as `"en-US"`. Keyword-only.
</ParamField>

<ParamField path="gender" type="str | None" default="None" toc={true}>
  Voice gender, `"male"` or `"female"`. Keyword-only.
</ParamField>

<ParamField path="voice" type="str | None" default="None" toc={true}>
  Voice ID. Keyword-only.
</ParamField>

<ParamField path="volume" type="float | None" default="None" toc={true}>
  Volume adjustment in dB, from `-40.0` to `40.0`. Keyword-only.
</ParamField>

<ParamField path="on_completed" type="Callable[[RelayEvent], Any] | None" default="None" toc={true}>
  Callback invoked when the operation reaches a terminal state. Can be a regular
  function or async coroutine. Keyword-only.
</ParamField>

## Returns

[`PlayAction`](/docs/server-sdks/reference/python/relay/actions) -- An action handle with `stop()`, `pause()`, `resume()`, `volume()`, and `wait()` methods.

## Example

```python {13}
from signalwire.relay import RelayClient

client = RelayClient(
    project="your-project-id",
    token="your-api-token",
    host="your-space.signalwire.com",
    contexts=["default"],
)

@client.on_call
async def handle_call(call):
    await call.answer()
    action = await call.play_tts("Welcome to Bayview Taxi.", language="en-US")
    await action.wait()

client.run()
```
