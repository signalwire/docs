Start, summarize, or stop live transcription on the call. Unlike
[`transcribe()`][transcribe], which
provides a post-call result, live transcription sends each utterance to your webhook as it is spoken.
The `action` dictionary takes the same shape as the [`live_transcribe`][swml-live-transcribe] SWML method:
a single `start`, `summarize`, or `stop` key.

<Info>
See also [`live_translate()`][live-translate] for real-time translation, and the
[transcribe calls guide][transcribe-calls] for the webhook events.
</Info>

## **Parameters**

<ParamField path="action" type="dict" required={true} toc={true}>
  The action to perform. Set exactly one of `start`, `summarize`, or `stop`.
</ParamField>

<Indent>

<ParamField path="action.start" type="dict" toc={true}>
  Start a live transcription session.
</ParamField>

<Indent>

<ParamField path="action.start.lang" type="str" required={true} toc={true}>
  The language to transcribe, such as `"en-US"`.
</ParamField>

<ParamField path="action.start.direction" type="list[str]" required={true} toc={true}>
  The sides of the call to transcribe: `"remote-caller"`, `"local-caller"`, or both.
</ParamField>

<ParamField path="action.start.webhook" type="str" toc={true}>
  The URL that receives transcription events as HTTP `POST` requests.
</ParamField>

<ParamField path="action.start.live_events" type="bool" default="False" toc={true}>
  Whether to send each utterance to the webhook as it is transcribed.
</ParamField>

<ParamField path="action.start.ai_summary" type="bool" default="False" toc={true}>
  Whether to send an AI summary of the conversation to the webhook when the session ends.
</ParamField>

<ParamField path="action.start.ai_summary_prompt" type="str" toc={true}>
  The prompt that tells the AI how to summarize the conversation when `ai_summary` is enabled.
</ParamField>

<ParamField path="action.start.speech_engine" type="str" default="deepgram" toc={true}>
  The speech recognition engine: `"deepgram"` or `"google"`.
</ParamField>

<ParamField path="action.start.speech_timeout" type="int" default="60000" toc={true}>
  The timeout for speech recognition, in milliseconds.
</ParamField>

<ParamField path="action.start.vad_silence_ms" type="int" toc={true}>
  Voice activity detection silence time, in milliseconds.
</ParamField>

<ParamField path="action.start.vad_thresh" type="int" default="400" toc={true}>
  Voice activity detection threshold, from `0` to `1800`.
</ParamField>

</Indent>

<ParamField path="action.summarize" type="dict" toc={true}>
  Request an AI summary of the conversation so far, while transcription continues. Pass an empty
  dictionary to use the prompt and webhook from `start`.
</ParamField>

<Indent>

<ParamField path="action.summarize.webhook" type="str" toc={true}>
  The URL that receives the summary.
</ParamField>

<ParamField path="action.summarize.prompt" type="str" toc={true}>
  The prompt that tells the AI how to summarize the conversation.
</ParamField>

</Indent>

<ParamField path="action.stop" type="dict" toc={true}>
  Stop the live transcription session. Pass an empty dictionary.
</ParamField>

</Indent>

## **Returns**

`dict` -- Server response confirming the operation.

## **Example**

```python {14-21}
from signalwire.relay import RelayClient

client = RelayClient(
    project="your-project-id",
    token="your-api-token",
    contexts=["default"],
)

@client.on_call
async def handle_call(call):
    await call.answer()

    # Start live transcription
    result = await call.live_transcribe({
        "start": {
            "lang": "en-US",
            "direction": ["remote-caller", "local-caller"],
            "webhook": "https://example.com/transcription-events",
            "live_events": True,
        }
    })
    print(f"Live transcription started: {result}")

    # Let the call proceed...
    await call.wait_for_ended()

client.run()
```
