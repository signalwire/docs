### projects.rotate_signing_key

Issue a new signing key for a project. The response is the only place the new
key is returned.

<EndpointSchemaSnippet endpoint="POST /api/projects/{id}/signing-key/rotate" />

## **Parameters**

<ParamField path="id" type="str" required={true} toc={true}>
  ID of the project whose key to rotate.
</ParamField>

<ParamField path="request_options" type="RequestOptions | None" toc={true}>
  Per-call timeout and retry overrides. See
  [`RequestOptions`](/docs/server-sdks/reference/python/rest/request-options).
</ParamField>

## **Returns**

`ProjectWithSigningKey` — the project with its new signing key.

## **Response Example**

<EndpointResponseSnippet endpoint="POST /api/projects/{id}/signing-key/rotate" />

## **Example**

```python {9}
from signalwire.rest import RestClient

client = RestClient(
    project="your-project-id",
    token="your-api-token",
    host="your-space.signalwire.com",
)

project = client.projects.rotate_signing_key("project-id")
print(project["id"])
```
