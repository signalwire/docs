### projects.list

List the authenticated root project and its subprojects. Returns one page; use
`client.projects.paginate()` to iterate every project across pages.

<EndpointSchemaSnippet endpoint="GET /api/projects" />

## **Response Example**

<EndpointResponseSnippet endpoint="GET /api/projects" />

## **Example**

```python {9}
from signalwire.rest import RestClient

client = RestClient(
    project="your-project-id",
    token="your-api-token",
    host="your-space.signalwire.com",
)

result = client.projects.list()
for project in result.get("data", []):
    kind = "subproject" if project["subproject"] else "root"
    print(project["name"], project["id"], kind)
```
