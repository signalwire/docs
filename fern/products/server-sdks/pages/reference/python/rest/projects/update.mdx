### projects.update

Update a project's name or protection settings. Only the fields you pass are
sent.

<EndpointSchemaSnippet endpoint="PATCH /api/projects/{id}" />

## Parameters

<ParamField path="id" type="str" required={true} toc={true}>
  ID of the project to update. Positional-only.
</ParamField>

<ParamField path="name" type="str | None" default="None" toc={true}>
  New display name.
</ParamField>

<ParamField path="protect_recordings" type="bool | None" default="None" toc={true}>
  Require authentication to download call recordings.
</ParamField>

<ParamField path="protect_message_media" type="bool | None" default="None" toc={true}>
  Require authentication to download message media.
</ParamField>

<ParamField path="protect_fax_media" type="bool | None" default="None" toc={true}>
  Require authentication to download fax media.
</ParamField>

<ParamField path="force_https_requests" type="bool | None" default="None" toc={true}>
  Reject webhook URLs that aren't HTTPS.
</ParamField>

<ParamField path="extras" type="Mapping[str, Any] | None" default="None" toc={true}>
  Additional request body fields merged into the payload as sent.
</ParamField>

<ParamField path="request_options" type="RequestOptions | None" default="None" toc={true}>
  Per-call timeout and retry overrides. See
  [`RequestOptions`](/docs/server-sdks/reference/python/rest/request-options).
</ParamField>

## Returns

`Project` — the updated project.

## Response Example

<EndpointResponseSnippet endpoint="PATCH /api/projects/{id}" />

## Example

```python {9}
from signalwire.rest import RestClient

client = RestClient(
    project="your-project-id",
    token="your-api-token",
    host="your-space.signalwire.com",
)

project = client.projects.update("project-id", name="Bayview Taxi - production")
print(project["name"])
```
