### projects.create

Create a subproject under the authenticated root project.

<EndpointSchemaSnippet endpoint="POST /api/projects" />

## **Parameters**

All parameters are keyword-only.

<ParamField path="name" type="str" required={true} toc={true}>
  Display name for the subproject.
</ParamField>

<ParamField path="protect_recordings" type="bool | None" toc={true}>
  Require authentication to download call recordings.
</ParamField>

<ParamField path="protect_message_media" type="bool | None" toc={true}>
  Require authentication to download message media.
</ParamField>

<ParamField path="protect_fax_media" type="bool | None" toc={true}>
  Require authentication to download fax media.
</ParamField>

<ParamField path="force_https_requests" type="bool | None" toc={true}>
  Reject webhook URLs that aren't HTTPS.
</ParamField>

<ParamField path="extras" type="Mapping[str, Any] | None" toc={true}>
  Additional request body fields merged into the payload as sent.
</ParamField>

<ParamField path="request_options" type="RequestOptions | None" toc={true}>
  Per-call timeout and retry overrides. See
  [`RequestOptions`](/docs/server-sdks/reference/python/rest/request-options).
</ParamField>

## **Returns**

`Project` — the new subproject. The response also carries `signing_key`, which
is returned only on creation and by `rotate_signing_key`, so store it now.

## **Response Example**

<EndpointResponseSnippet endpoint="POST /api/projects" />

## **Example**

```python {9}
from signalwire.rest import RestClient

client = RestClient(
    project="your-project-id",
    token="your-api-token",
    host="your-space.signalwire.com",
)

sub = client.projects.create(
    name="Bayview Taxi - staging",
    protect_recordings=True,
    force_https_requests=True,
)
print(sub["id"])
```
