### projects.get

Retrieve a single project or subproject. An ID outside the caller's project tree
returns `404`.

<EndpointSchemaSnippet endpoint="GET /api/projects/{id}" />

## Parameters

<ParamField path="resource_id" type="str" required={true} toc={true}>
  ID of the project or subproject to retrieve.
</ParamField>

<ParamField path="request_options" type="RequestOptions | None" default="None" toc={true}>
  Per-call timeout and retry overrides. See
  [`RequestOptions`](/docs/server-sdks/reference/python/rest/request-options).
</ParamField>

## Returns

`Project` — the project record.

## Response Example

<EndpointResponseSnippet endpoint="GET /api/projects/{id}" />

## Example

```python {9}
from signalwire.rest import RestClient

client = RestClient(
    project="your-project-id",
    token="your-api-token",
    host="your-space.signalwire.com",
)

project = client.projects.get("project-id")
print(project["name"], project["region_preference"])
```
