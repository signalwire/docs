### messages.update

Redact the body of a previously sent message. The API accepts only an empty
string for `body`; any other value is rejected. Messages still in progress
(`queued` or `initiated`) can't be redacted, and a redacted body can't be
recovered.

<EndpointSchemaSnippet endpoint="PATCH /api/messaging/messages/{message_id}" />

## **Parameters**

<ParamField path="message_id" type="str" required={true} toc={true}>
  ID of the message to redact.
</ParamField>

<ParamField path="body" type="str" required={true} toc={true}>
  New body. Pass `""` to redact. Keyword-only.
</ParamField>

<ParamField path="extras" type="Mapping[str, Any] | None" default="None" toc={true}>
  Additional request body fields merged into the payload as sent.
</ParamField>

<ParamField path="request_options" type="RequestOptions | None" default="None" toc={true}>
  Per-call timeout and retry overrides. See
  [`RequestOptions`](/docs/server-sdks/reference/python/rest/request-options).
</ParamField>

## **Returns**

`Message` — the updated message with its body cleared.

## **Response Example**

<EndpointResponseSnippet endpoint="PATCH /api/messaging/messages/{message_id}" />

## **Example**

```python {9}
from signalwire.rest import RestClient

client = RestClient(
    project="your-project-id",
    token="your-api-token",
    host="your-space.signalwire.com",
)

redacted = client.messages.update("message-id", body="")
print(redacted["body"])  # ""
```
