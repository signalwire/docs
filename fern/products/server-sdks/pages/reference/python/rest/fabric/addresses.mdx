Read-only access to the project's Resource Addresses: its alias, SIP, and phone number
addresses. Requests authenticate with the project credentials of the [`RestClient`][restclient].

Access via `client.fabric.addresses` on a [`RestClient`][restclient] instance.

### list

List the project's addresses, newest first. Each item has a `type` of `alias`, `sip`, or
`phone`, and the same fields as the matching [alias address][alias-address],
[SIP address][sip-address], or [phone number address][phone-number-address]. Pass `type` to
return one kind only, and `page_size`, `page_number`, and `page_token` to page through results.

### get

Retrieve one of the project's addresses by ID. It returns the same object as the matching
item from `list`.

## **Example**

```python {10,15}
from signalwire.rest import RestClient

client = RestClient(
    project="your-project-id",
    token="your-api-token",
    host="your-space.signalwire.com",
)

# List all addresses
addresses = client.fabric.addresses.list()
for addr in addresses.get("data", []):
    print(f"{addr['name']}: {addr['type']}")

# Get a specific address
address = client.fabric.addresses.get("address-id")
print(f"Address: {address['name']}")
```
