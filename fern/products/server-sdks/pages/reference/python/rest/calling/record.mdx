Start recording an active call. Pass a `control_id` to name the recording so you
can [pause][pause],
[resume][resume],
or [stop][stop] it later. The response never carries `control_id` back -- omit
it and you have no way to control this recording afterward.

## **Request**

<Schema type="Calling.CallRecordRequest" api="signalwire-rest" exclude={["command"]} />

## **Response**

<Schema type="Calling.CallResponse" api="signalwire-rest" />

## **Example**

```python {9}
from signalwire.rest import RestClient

client = RestClient(
    project="your-project-id",
    token="your-api-token",
    host="your-space.signalwire.com",
)

client.calling.record(
    call_id="call-id-xxx",
    control_id="record-1",
    audio={"format": "mp3", "stereo": True}
)
```
