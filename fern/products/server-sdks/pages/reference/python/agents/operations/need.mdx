[operation]: /docs/server-sdks/reference/python/agents/operations/operation

Raise `Need` from an [operation's][operation] `prepare()`, or from an `identify()`
`find` function, when something it needs wasn't said. Nothing is proposed. The model is
told what to ask, and keeps what the caller already gave for the next call. When the
operation has `guidance`, the call moves to the operation's own step.

```python
from signalwire.operations import Need
```

## Parameters

<ParamField path="ask" type="str" required={true} toc={true}>
  The question to ask the caller, in the operation's words.
</ParamField>

<ParamField path="fields" type="Sequence[str]" default="()" toc={true}>
  The fields still missing.
</ParamField>

## Example

```python
from signalwire.operations import Change, Field, Need, Operation


class Order(Operation):
    """Order a coffee."""

    size = Field(str, "Small, medium or large.", required=False)

    def prepare(self, call, f):
        if not f.size:
            raise Need("Which size would they like: small, medium or large?", ["size"])
        return Change(read_back=f"One {f.size} coffee. Shall I?", touches=["order:new"])
```
