Prefabs are ready-to-use agent classes that implement common conversational patterns.
Each prefab extends [`AgentBase`][agentbase], so you can
customize them with additional prompt sections, tools, skills, and languages. Use them
directly for rapid prototyping or subclass them for production use.

`FrontDeskAgent` and `PersonalAssistantAgent` are built on
[`ServiceAgent`][service-agent] from [`signalwire.operations`][operations], and take
the operations task packs for appointments, messages, and answers from documents.

```python
from signalwire.prefabs import (
    Department,
    FrontDeskAgent,
    InfoGathererAgent,
    PersonalAssistantAgent,
    SurveyAgent,
)
```

| Prefab | Purpose | Built-in Tools |
|--------|---------|----------------|
| [FrontDeskAgent](/docs/server-sdks/reference/python/agents/prefabs/front-desk-agent) | Put callers through to departments, book appointments, take messages, and answer from documents | `transfer_to_human`, plus the tools of the packs you give it |
| [InfoGathererAgent](/docs/server-sdks/reference/python/agents/prefabs/info-gatherer-agent) | Collect answers to a series of questions | `start_questions`, `submit_answer` |
| [PersonalAssistantAgent](/docs/server-sdks/reference/python/agents/prefabs/personal-assistant-agent) | Answer the phone for one person and ring them with a whisper | `put_through`, plus the tools of the packs you give it |
| [SurveyAgent](/docs/server-sdks/reference/python/agents/prefabs/survey-agent) | Conduct automated surveys with validation | `validate_response`, `log_response` |

These prefabs are deprecated. They still work, and raise a `DeprecationWarning` when
constructed:

| Prefab | Use instead |
|--------|-------------|
| [ConciergeAgent](/docs/server-sdks/reference/python/agents/prefabs/concierge-agent) | `FrontDeskAgent` with the `Appointments` pack for bookings, and [`InfoBotKnowledge`][infobot] for amenities and hours |
| [FAQBotAgent](/docs/server-sdks/reference/python/agents/prefabs/faq-bot-agent) | [`InfoBotKnowledge`][infobot] |
| [ReceptionistAgent](/docs/server-sdks/reference/python/agents/prefabs/receptionist-agent) | `FrontDeskAgent` |

<Tip>
All prefabs can be extended by subclassing. Add custom tools with `define_tool()`, extra
prompt sections with `prompt_add_section()`, and skills with `add_skill()`.
</Tip>

---

## Extending Prefabs

All prefabs inherit from [`AgentBase`][agentbase],
so you can add custom tools, prompt sections, and skills:

```python
from signalwire.prefabs import SurveyAgent
from signalwire.core.function_result import FunctionResult

class MySurvey(SurveyAgent):
    def __init__(self):
        super().__init__(
            survey_name="Customer Satisfaction",
            questions=[
                {"id": "rating", "text": "How would you rate our service?", "type": "rating", "scale": 5}
            ]
        )

        self.prompt_add_section("Brand", "You represent Acme Corp.")
        self.add_skill("datetime")

        self.define_tool(
            name="escalate",
            description="Escalate to human agent",
            parameters={},
            handler=self.escalate
        )

    def escalate(self, args, raw_data):
        return FunctionResult("Transferring to agent...").connect("+15551234567")

if __name__ == "__main__":
    MySurvey().run()
```
