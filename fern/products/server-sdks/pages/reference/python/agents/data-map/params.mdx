Set the JSON request body for the most recently added webhook, written as its
`params`. [`body()`][body] does the same.

The platform sends `params` as the request's JSON body, not as URL query
parameters, expanding templates in its values first, and a webhook with `params` is
always a POST, whatever its method. Put query-string values for a GET request in the
URL instead.

## **Parameters**

<ParamField path="data" type="dict[str, Any]" required={true} toc={true}>
  Request body dictionary. Values can contain templates, which read the call data, so
  arguments are `${args.name}`.
</ParamField>

## **Returns**

[`DataMap`][ref-datamap] -- Self for method chaining. Raises `ValueError` if no webhook has been
added yet.

## **Example**

```python {7}
from signalwire import DataMap, FunctionResult

dm = DataMap("search_docs")
dm.purpose("Search documentation")
dm.parameter("query", "string", "Search query", required=True)
dm.webhook("POST", "https://api.docs.example.com/search")
dm.params({"q": "${args.query}", "limit": 10})
dm.output(FunctionResult("Found: ${results[0].title}"))
```
