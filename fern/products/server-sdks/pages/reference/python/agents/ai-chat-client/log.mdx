Read the conversation back. This changes nothing about the conversation.

## **Parameters**

<ParamField path="conversation_id" type="str" required={true} toc={true}>
  The conversation to read.
</ParamField>

## **Returns**

`ChatLog` — carries `messages` and `call_timeline`.

Each message has `role`, `content`, and a `timestamp` in **microseconds**. `call_timeline` is a flat
stream of structured events covering session start and end, context switches, and tool calls.

<Warning>
  `messages` is the conversation as the service holds it, including `system` — your own prompt — and
  internal markers such as `system-log`. Filter to `user` and `assistant` before displaying a
  transcript, or you publish your prompt to your users.
  [`ChatGateway.visible_messages()`][visiblemessages] does this filtering for you.
</Warning>

## **Example**

```python {10,12}
import asyncio

from signalwire.ai_chat import AIChatClient

VISIBLE = {"user", "assistant"}


async def main():
    async with AIChatClient(space="your-space") as client:
        conversation = await client.log("chat-8f21")

        for message in conversation.messages:
            if message["role"] in VISIBLE:
                print(message["role"], message["content"])


asyncio.run(main())
```
