[swml-answer]: /docs/swml/reference/calling/answer

Add an [`answer`][swml-answer] verb to the main section. Answers an incoming call.
Arguments left as `None` are omitted from the verb.

## **Parameters**

<ParamField path="max_duration" type="int | None" default="None" toc={true}>
  Maximum call duration in seconds. The call is automatically hung up after this
  duration elapses.
</ParamField>

<ParamField path="codecs" type="str | None" default="None" toc={true}>
  Comma-separated list of audio codecs to use for the call. Valid values include:
  `PCMU`, `PCMA`, `G722`, `G729`, `AMR-WB`, `OPUS`, `VP8`, `H264`.
</ParamField>

<ParamField path="username" type="str | None" default="None" toc={true}>
  Username for SIP authentication challenges. Applied only together with a
  `password`.
</ParamField>

<ParamField path="password" type="str | None" default="None" toc={true}>
  Password for SIP authentication challenges, applied together with `username`.
</ParamField>

## **Returns**

`Self` -- The builder instance for method chaining.

## **Example**

```python {8}
from signalwire import SWMLService, SWMLBuilder

service = SWMLService(name="my-service")
builder = SWMLBuilder(service)

doc = (
    builder
    .answer(max_duration=3600, username="alice", password="s3cret")
    .play(url="https://example.com/welcome.mp3")
    .build()
)
print(doc)
```
