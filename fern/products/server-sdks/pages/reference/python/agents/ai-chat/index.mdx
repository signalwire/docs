`signalwire.ai_chat` holds a text conversation with an AI agent. The agent is the same one a phone
call would reach — same SWML, same prompt, same tools — and each request is one full turn.

Two classes, picked by where your code runs:

<CardGroup cols={2}>

<Card title="AIChatClient" href="/docs/server-sdks/reference/python/agents/ai-chat/ai-chat-client" icon="regular server">
  For code on your own server. Holds the API token and talks to SignalWire directly.
</Card>

<Card title="ChatGateway" href="/docs/server-sdks/reference/python/agents/ai-chat/chat-gateway" icon="regular globe">
  For browsers. Mounts in your web app, holds the token server-side, and hands the page a
  publishable key.
</Card>

</CardGroup>

A browser cannot use [`AIChatClient`][aichatclient] directly. Anything a page can read, a visitor
can read, and an API token in a page is a published API token — which is what
[`ChatGateway`][chatgateway] exists for.

## **Installation**

```bash
pip install signalwire-sdk
```

## **Credentials**

Both classes read credentials from their constructor first, then from the environment:

<ParamField path="SIGNALWIRE_PROJECT_ID" type="str" toc={true}>
  Your project ID. Required — a client without one raises `ValueError`.
</ParamField>

<ParamField path="SIGNALWIRE_API_TOKEN" type="str" toc={true}>
  An API token with the `chat` scope enabled.
</ParamField>

<ParamField path="SIGNALWIRE_SPACE" type="str" toc={true}>
  Your Space name, used to build the service URL. Required unless you pass `url` explicitly.
</ParamField>

So a configured environment needs no arguments at all:

```python
from signalwire.ai_chat import AIChatClient


async def send(message: str) -> str:
    async with AIChatClient() as client:
        reply = await client.chat("conv-123", message)
        return reply.text
```

## **Example**

One conversation, start to finish.

```python {10,13,16}
import asyncio

from signalwire.ai_chat import AIChatClient

CONFIG_URL = "https://your-agent.example.com/swml"


async def main():
    async with AIChatClient(space="your-space") as client:
        info = await client.create_conversation("conv-123", config_url=CONFIG_URL)
        print("agent:", info.initial_message)

        reply = await client.chat("conv-123", "Where is order A-771?")
        print("agent:", reply.text)

        await client.end("conv-123")


asyncio.run(main())
```
