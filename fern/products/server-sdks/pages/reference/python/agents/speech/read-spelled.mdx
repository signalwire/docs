Return the units a caller spelled, one uppercase letter, digit, or symbol each,
from the recognizer's text. It reads the common ways a caller spells:

- Letter by letter (`"s m i t h"`), or with a hyphen between letters (`"S-M-I-T-H"`).
- Letter names (`"ess em eye tee aitch"`).
- `"S as in Sam"`: the letter, with the word after "as in" skipped.
- NATO alphabet words (`"sierra mike"`).
- `"double l"` for two of a letter, and `"double u"` for W.
- Digit words (`"one two"`) and symbol words (`"dot"`, `"at"`, `"dash"`,
  `"underscore"`, `"plus"`, `"slash"`).

"Capital", "uppercase", "lowercase", and similar words before a letter are dropped.
A word that names no letter, such as `"smith"`, is taken as spelled: its letters.

```python
from signalwire.speech.spelling import read_spelled
```

## Parameters

<ParamField path="text" type="str" required={true} toc={true}>
  The recognizer's text.
</ParamField>

<ParamField path="oh_is_zero" type="bool" default="False" toc={true}>
  Keyword-only. `True` reads "oh" as the digit 0, for a code of digits. By default
  it's the letter O.
</ParamField>

## Returns

`list[str]` -- The units, in order. Pass them to
[`spelling_variants()`][spelling-variants] to list likely misrecognitions.

## Example

```python
from signalwire.speech.spelling import read_spelled

print(read_spelled("S as in Sam, m i t h"))
# ['S', 'M', 'I', 'T', 'H']
print(read_spelled("sierra mike india tango hotel"))
# ['S', 'M', 'I', 'T', 'H']
print(read_spelled("capital b double l oh"))
# ['B', 'L', 'L', 'O']
print(read_spelled("one two oh four", oh_is_zero=True))
# ['1', '2', '0', '4']
```
