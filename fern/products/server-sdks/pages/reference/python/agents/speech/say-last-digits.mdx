Return the last `n` digits of `text`, one word each, as one group: for "a card
ending in" or "the account ending in". Separators in `text` are ignored. The words
come from [`say_digits()`][say-digits].

```python
from signalwire.speech import say_last_digits
```

## Parameters

<ParamField path="text" type="str | int" required={true} toc={true}>
  The number, with any separators.
</ParamField>

<ParamField path="n" type="int" default="4" toc={true}>
  How many of the last digits to say. Raises `ValueError` unless it's a whole
  number of at least 1.
</ParamField>

<ParamField path="zero" type="str" default="zero" toc={true}>
  Keyword-only. The word for 0, such as `"oh"`.
</ParamField>

## Returns

`str` -- The words, or `""` when `text` has no digits.

## Example

```python
from signalwire.speech import say_last_digits

print(say_last_digits("4111 1111 1111 1234"))
# one two three four
print(say_last_digits("+1 415 555 0102", n=2, zero="oh"))
# oh two
```

Part of the [speech helpers][ref-speech] module.
