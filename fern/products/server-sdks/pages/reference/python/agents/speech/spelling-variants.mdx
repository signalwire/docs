Return the spellings `units` could be, given letters the recognizer confuses. The
spelling as heard comes first, then the variants with one change, then two, and so
on, up to `limit`. Look each one up in your own records, in order: the first that
matches is the likeliest.

Which letters a recognizer confuses depends on the recognizer and the voice, so no
confusion groups are built in. Measure them on your own calls.

```python
from signalwire.speech.spelling import spelling_variants
```

## Parameters

<ParamField path="units" type="Sequence[str]" required={true} toc={true}>
  The units as heard, such as the list [`read_spelled()`][read-spelled] returns.
</ParamField>

<ParamField path="groups" type="Mapping[str, Iterable[str]]" required={true} toc={true}>
  For each unit, the units it may have been, such as
  `{"S": "F", "F": "S", "M": "N", "N": "M"}`. A string value is read as its letters.
</ParamField>

<ParamField path="positions" type="Iterable[int] | None" default="None" toc={true}>
  Keyword-only. The positions in `units` that may vary, such as the letters the
  recognizer was least sure of: [`AgentBase.speech_finals()`](/docs/server-sdks/reference/python/agents/agent-base/speech-finals) gives a confidence for
  each word the recognizer heard. `None` lets every position vary.
</ParamField>

<ParamField path="limit" type="int" default="50" toc={true}>
  Keyword-only. The most spellings to return, the spelling as heard included.
</ParamField>

## Returns

`list[str]` -- The spellings, each joined into one string.

## Example

```python
from signalwire.speech.spelling import read_spelled, spelling_variants

units = read_spelled("S as in Sam, m i t h")
print(spelling_variants(units, {"S": "F", "M": "N"}))
# ['SMITH', 'FMITH', 'SNITH', 'FNITH']
print(spelling_variants(units, {"S": "F", "M": "N"}, positions=[1]))
# ['SMITH', 'SNITH']
```
