Return a whole number in English words, such as "one thousand four hundred five".
A negative number starts with "minus". [`say_money()`][say-money] uses it for each
part of an amount.

```python
from signalwire.speech import number_words
```

## Parameters

<ParamField path="n" type="int" required={true} toc={true}>
  The number. Its absolute value must be below one quadrillion.
</ParamField>

## Returns

`str` -- The number in words.

## Raises

`ValueError` for a value that isn't an `int` (a `bool` included), or a number of
a quadrillion or more.

## Example

```python
from signalwire.speech import number_words

print(number_words(1405))
# one thousand four hundred five
print(number_words(-42))
# minus forty-two
print(number_words(2_000_000_017))
# two billion seventeen
```

Part of the [speech helpers][ref-speech] module.
