Set how the call checks the [semantic gates][semanticgate] on its SWAIG functions.
Each argument sets one [AI parameter][ai-params]. An argument left as `None` leaves
that setting as it is, and the platform default applies to a setting that was never
set.

## Parameters

<ParamField path="enabled" type="bool | None" default="None" toc={true}>
  `False` runs gated functions without checking their gates. Sets
  `semantic_gates_enabled`; the platform default is `True`.
</ParamField>

<ParamField path="timeout_ms" type="int | None" default="None" toc={true}>
  How long one gate check may take, from 500 to 10000 milliseconds. A check that
  runs out of time blocks the function. Sets `semantic_gate_timeout_ms`; the
  platform default is 2500.
</ParamField>

<ParamField path="history" type="int | None" default="None" toc={true}>
  How many recent conversation entries the decision model reads, from 0 to 100.
  Sets `semantic_gate_history`; the platform default is 20.
</ParamField>

Raises `ValueError` when a value has the wrong type or is out of range. Values
checked before the one that raised stay set.

## Returns

[`AgentBase`][ref-agentbase] -- Returns self for method chaining.

## Examples

```python {5}
from signalwire import AgentBase

agent = AgentBase(name="account-agent", route="/account")
agent.set_prompt_text("You help callers manage their account.")
agent.set_semantic_gates(timeout_ms=4000, history=40)
agent.serve()
```
