Define a function that the platform implements itself, such as `end_call`, under
your own description and parameters. The function is sent with
`web_hook_url: "native"`, so the platform runs its own implementation by name and
calls no webhook. Use it to describe a platform function in your own words, or so
that a step's [function list][set-functions] can name it.

A tool from [`define_tool()`][define-tool] always gets the agent's webhook URL, so it
can't be a native function. To turn on the platform's built-in functions without
your own description, use [`set_native_functions()`][set-native-functions].

## Parameters

<ParamField path="name" type="str" required={true} toc={true}>
  The function's name, one the platform implements.
</ParamField>

<ParamField path="description" type="str" required={true} toc={true}>
  The description the model reads.
</ParamField>

<ParamField path="parameters" type="dict[str, Any] | None" default="None" toc={true}>
  The JSON Schema of its arguments, as the platform's implementation reads them.
  `None` sends an empty object schema.
</ParamField>

<ParamField path="**swaig_fields" type="Any" toc={true}>
  Other SWAIG function fields, such as `fillers`.
</ParamField>

## Returns

[`AgentBase`][ref-agentbase] -- Self for method chaining.

## Example

```python {5}
from signalwire import AgentBase

agent = AgentBase(name="frontline", route="/frontline")
agent.prompt_add_section("Role", "You answer questions.")
agent.define_native_tool("end_call", "End the call once the caller says goodbye.")

agent.serve()
```

The rendered function:

```json
{
  "function": "end_call",
  "description": "End the call once the caller says goodbye.",
  "parameters": {"type": "object", "properties": {}},
  "web_hook_url": "native"
}
```
