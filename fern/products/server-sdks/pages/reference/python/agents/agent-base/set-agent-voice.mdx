Set the agent's own voice, sent as the `voice` key of the SWML [`ai`][swml-ai] verb. A
language added with [`add_language()`][add-language] that has no voice of its own uses
this one.

The platform tries an agent's voices in this order: the language's own voice or voice
list, this voice for a language with none, the
[`set_fallback_voice()`][set-fallback-voice] list, and the platform's own last resort.

## Parameters

<ParamField path="voice" type="str | Sequence[str] | None" required={true} toc={true}>
  One voice as `engine.voice:model`, or a list of up to 8. In a list, the first voice
  speaks and the rest are tried in order when it fails. A one-item list stays a list.
  `None` clears the setting.
</ParamField>

## Returns

[`AgentBase`][ref-agentbase] -- Returns self for method chaining.

## Raises

`ValueError` for an empty voice, an empty list, a list of more than 8 voices, or a list
entry that isn't a non-empty string.

## Example

```python {5}
from signalwire import AgentBase

agent = AgentBase(name="sales", route="/sales")
agent.prompt_add_section("Role", "You answer sales calls.")
agent.set_agent_voice(["rime.spore:arcana", "elevenlabs.josh"])
agent.serve()
```

The `ai` verb renders with the voice list:

```json
{"ai": {"prompt": {"...": "..."}, "params": {}, "voice": ["rime.spore:arcana", "elevenlabs.josh"]}}
```

To set a voice for every voice field the agent leaves empty, including multilingual
languages, use [`set_default_voice()`][set-default-voice].
