Tell the recognizer how many digits the caller's answer in this step has, such
as a ZIP code or a PIN. The recognizer stops waiting once the caller has said
that many digits.

While a gather question with its own `expected_answer` is being asked, that
value replaces the step's. See
[`add_gather_question()`][ref-add-gather-question] and
[`expected_answer()`][ref-expected-answer].

Pass `digits` for an exact count, or both `min_digits` and `max_digits` for a
range.

## Parameters

<ParamField path="digits" type="int | None" default="None" toc={true}>
  The exact number of digits, from 1 to 64. Can't be combined with
  `min_digits` or `max_digits`.
</ParamField>

<ParamField path="min_digits" type="int | None" default="None" toc={true}>
  Keyword-only. The fewest digits, from 1 to 64. Requires `max_digits`.
</ParamField>

<ParamField path="max_digits" type="int | None" default="None" toc={true}>
  Keyword-only. The most digits, from 1 to 64, and at least `min_digits`.
  Requires `min_digits`.
</ParamField>

## Returns

[`Step`][ref-step] -- Self for method chaining.

## Raises

`ValueError` for a count outside 1 to 64, a `min_digits` greater than
`max_digits`, `digits` combined with a range, or a range with only one end.

## Examples

### Exact count

```python {7}
from signalwire import AgentBase

agent = AgentBase(name="zip", route="/zip")
agent.prompt_add_section("Role", "You look up stores.")

ctx = agent.define_contexts().add_context("default")
ctx.add_step("collect").set_text("Ask for the caller's ZIP code.").set_expected_answer(digits=5)

agent.serve()
```

The step renders as:

```json
{"name": "collect", "text": "Ask for the caller's ZIP code.", "expected_answer": {"digits": 5}}
```

### Range

```python
step.set_expected_answer(min_digits=4, max_digits=6)
```
