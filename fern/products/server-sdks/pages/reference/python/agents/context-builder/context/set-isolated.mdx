[ref-context]: /docs/server-sdks/reference/python/agents/context-builder/context

Set whether to truncate conversation history when this context is entered with
`change_context`. An isolated context drops every conversation entry except the
first, the base system prompt. The model starts with the base prompt and the
new context's step instructions, with no memory of earlier turns.

When the context also has a reset (a step's `set_reset_*()` methods on the step
that switches into it, or this context's `set_consolidate()` or
`set_full_reset()`), the reset runs in place of the truncation. Use a reset
with consolidation to summarize earlier history into one message instead of
dropping it.

## **Parameters**

<ParamField path="isolated" type="bool" required={true} toc={true}>
  Whether to truncate conversation history on entry.
</ParamField>

## **Returns**

[`Context`][ref-context] -- Self for method chaining.

## **Example**

```python {9}
from signalwire import AgentBase

agent = AgentBase(name="my-agent", route="/agent")

contexts = agent.define_contexts()
contexts.add_context("default").add_step("menu").set_text("Ask what the caller needs.")

secure = contexts.add_context("secure")
secure.set_isolated(True)
secure.set_system_prompt("You are verifying the caller's identity.")
secure.add_step("verify").set_text("Ask for the caller's account PIN.")

agent.serve()
```
