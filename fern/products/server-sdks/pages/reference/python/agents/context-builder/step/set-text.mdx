Set the step's prompt text directly. Cannot be used with `add_section()` or
`add_bullets()`.

<Warning>
Mixing `set_text()` with `add_section()` or `add_bullets()` raises `ValueError`.
Use one approach or the other.
</Warning>

The platform expands the text's variables, such as
`${global_data.order_total}`, when the step is entered. Current platform
releases expand it again, in place, before a request whenever a value it reads
has changed. Earlier releases and realtime models keep the values from entry:
for those, return
[`FunctionResult.refresh_step()`](/docs/server-sdks/reference/python/agents/function-result/refresh-step)
after a later `update_global_data()` to enter the step again with the new
values.

## **Parameters**

<ParamField path="text" type="str" required={true} toc={true}>
  Plain-text prompt instructions for this step.
</ParamField>

## **Returns**

[`Step`][ref-step] -- Self for method chaining.

## **Example**

```python {8}
from signalwire import AgentBase

agent = AgentBase(name="my-agent", route="/agent")

contexts = agent.define_contexts()
ctx = contexts.add_context("default")
step = ctx.add_step("greeting")
step.set_text("Welcome the caller and ask how you can help.")

agent.serve()
```
