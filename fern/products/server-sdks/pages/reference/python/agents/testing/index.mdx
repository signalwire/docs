The `signalwire.testing` module tests a call flow, such as a confirmation that
spans several steps, without the platform or a model. [`swaig-test`][swaig-test]
runs one tool call; [`CallSimulator`][call-simulator] runs a sequence of them
through a simulated call and checks each one the way the platform does.
[`RequestRecorder`][request-recorder] records real tool requests so you can run
them against changed code.

```python
from signalwire.testing import CallSimulator, RequestRecorder, SimulatedCall, ToolMentionError
```
