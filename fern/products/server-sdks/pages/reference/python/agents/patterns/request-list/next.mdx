Return the oldest request not yet taken up, with the words the agent opens it with.

## Parameters

<ParamField path="raw_data" type="Mapping[str, Any] | None" required={true} toc={true}>
  The SWAIG request, as a tool handler receives it.
</ParamField>

## Returns

`dict[str, str] | None` -- `{"kind": ..., "about": ..., "opener": ...}`, with the opener
from [`opener()`][opener], or `None` when nothing is noted.

## Example

```python {7}
from signalwire import FunctionResult
from signalwire.patterns import RequestList

later = RequestList("later", openers={"balance": "You also asked about your balance."})

def next_request(args, raw_data):
    request = later.next(raw_data)
    if request is None:
        return FunctionResult("Nothing else is waiting. Ask if there's anything else.")
    return FunctionResult(f"Take this up next: {request['opener']}")
```
