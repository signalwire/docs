[set-global-data]: /docs/server-sdks/reference/python/agents/agent-base/set-global-data

Return the `global_data` to start a call with: an empty list and empty text, so step
text that shows the list has a value before anything is noted. Pass it to
[`set_global_data()`][set-global-data].

## Returns

`dict[str, Any]` -- `{global_key: [], "<global_key>_text": ""}`.

## Example

```python {5-6}
from signalwire import AgentBase
from signalwire.patterns import RequestList

agent = AgentBase(name="desk", route="/desk")
later = RequestList("later")
agent.set_global_data(later.defaults())
# global_data: {"later": [], "later_text": ""}
```
