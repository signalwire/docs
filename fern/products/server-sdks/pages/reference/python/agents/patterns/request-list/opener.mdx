Return how the agent opens a request when it takes it up: the opener for the request's
kind with `{about}` replaced, or what the request is about when its kind has no opener.

## Parameters

<ParamField path="request" type="Mapping[str, str]" required={true} toc={true}>
  A request, as `{"kind": ..., "about": ...}`.
</ParamField>

## Returns

`str` -- The opening words.

## Example

```python {4}
from signalwire.patterns import RequestList

later = RequestList("later", openers={"question": "You had a question: {about}."})
print(later.opener({"kind": "question", "about": "store hours"}))
# You had a question: store hours.
```
