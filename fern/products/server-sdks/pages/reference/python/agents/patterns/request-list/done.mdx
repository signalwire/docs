Remove the oldest request once it has been taken up. The result updates the list and
its text in `global_data`.

## Parameters

<ParamField path="raw_data" type="Mapping[str, Any] | None" required={true} toc={true}>
  The SWAIG request, as a tool handler receives it.
</ParamField>

<ParamField path="result" type="FunctionResult | None" default="None" toc={true}>
  A result to add to, in place of a new one.
</ParamField>

## Returns

[`FunctionResult`][functionresult] -- The result, with the shortened list.

## Example

```python {7}
from signalwire import FunctionResult
from signalwire.patterns import RequestList

later = RequestList("later")

def tell_balance(args, raw_data):
    return later.done(raw_data, FunctionResult("The balance is $42.10."))
```
