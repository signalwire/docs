Read the proposal that the request carries back to the caller again, as a new revision,
so the gates' proposal dialogue starts over with it. The result is the same as
[`propose()`][propose] gives for the same read-back and details, with the revision
number one higher.

## Parameters

<ParamField path="raw_data" type="Mapping[str, Any]" required={true} toc={true}>
  The SWAIG request of the tool asking again. Its `global_data.semantic_state` holds the
  proposal.
</ParamField>

<ParamField path="result" type="FunctionResult | None" default="None" toc={true}>
  A result to add to, in place of a new one.
</ParamField>

## Returns

[`FunctionResult`][functionresult] -- The result that reads the proposal back.

## Raises

`ValueError` when the request carries no proposal.

## Example

```python {6}
from signalwire.patterns import Proposal

order = Proposal("place_order", decline_tool="review_order")

def repeat_order(args, raw_data):
    return order.ask_again(raw_data)
```
