Detect DTMF digits on the call. A typed convenience over [`detect()`][detect]
with the `digit` detector.

## **Parameters**

<ParamField path="options" type="object" toc={true}>
  Detector options.
</ParamField>

<Indent>

<ParamField path="options.digits" type="string" toc={true}>
  The digits to listen for, such as `"0123456789#*"`.
</ParamField>

<ParamField path="options.timeout" type="number" toc={true}>
  Maximum seconds to run the detector before stopping.
</ParamField>

<ParamField path="options.onCompleted" type="(event: RelayEvent) => void | Promise<void>" toc={true}>
  Callback invoked when the operation reaches a terminal state.
</ParamField>

</Indent>

## **Returns**

`Promise<`[`DetectAction`][detectaction]`>` -- An action handle with `stop()` and `wait()` methods. It resolves on the first detection result.

## **Example**

```typescript {11}
import { RelayClient } from '@signalwire/sdk';

const client = new RelayClient({
  project: process.env.SIGNALWIRE_PROJECT_ID!,
  token: process.env.SIGNALWIRE_API_TOKEN!,
  contexts: ['default']
});

client.onCall(async (call) => {
  await call.answer();
  const action = await call.detectDigit({ digits: '0#', timeout: 15 });
  const event = await action.wait();
  console.log(event.params);
});

await client.run();
```
