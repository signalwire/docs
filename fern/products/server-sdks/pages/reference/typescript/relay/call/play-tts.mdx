Play text-to-speech on the call. A typed convenience over [`play()`][play] that
builds the TTS media item for you.

## **Parameters**

<ParamField path="text" type="string" required={true} toc={true}>
  The text to speak.
</ParamField>

<ParamField path="options" type="object" toc={true}>
  Voice and playback options.
</ParamField>

<Indent>

<ParamField path="options.language" type="string" toc={true}>
  Language code for the voice, such as `"en-US"`.
</ParamField>

<ParamField path="options.gender" type="TtsGender" toc={true}>
  `"male"` or `"female"`.
</ParamField>

<ParamField path="options.voice" type="string" toc={true}>
  Voice identifier for the TTS engine.
</ParamField>

<ParamField path="options.volume" type="number" toc={true}>
  Volume adjustment in dB, from `-40` to `40`.
</ParamField>

<ParamField path="options.onCompleted" type="(event: RelayEvent) => void | Promise<void>" toc={true}>
  Callback invoked when the operation reaches a terminal state.
</ParamField>

</Indent>

## **Returns**

`Promise<`[`PlayAction`][playaction]`>` -- An action handle with `stop()`, `pause()`, `resume()`, `volume()`, and `wait()` methods.

## **Example**

```typescript {11}
import { RelayClient } from '@signalwire/sdk';

const client = new RelayClient({
  project: process.env.SIGNALWIRE_PROJECT_ID!,
  token: process.env.SIGNALWIRE_API_TOKEN!,
  contexts: ['default']
});

client.onCall(async (call) => {
  await call.answer();
  const action = await call.playTTS('Welcome to Bayview Taxi.', { language: 'en-US' });
  await action.wait();
});

await client.run();
```
