Start, summarize, or stop live transcription on the call. Unlike
[`transcribe()`][transcribe], which
provides a post-call result, live transcription sends each utterance to your webhook as it is spoken.
The `action` object takes the same shape as the [`live_transcribe`][swml-live-transcribe] SWML method:
a single `start`, `summarize`, or `stop` key. Its keys are sent as written, in snake_case.

<Info>
See also [`liveTranslate()`][live-translate] for real-time translation, and the
[transcribe calls guide][transcribe-calls] for the webhook events.
</Info>

## **Parameters**

<ParamField path="action" type="Record<string, unknown>" required={true} toc={true}>
  The action to perform. Set exactly one of `start`, `summarize`, or `stop`.
</ParamField>

<Indent>

<ParamField path="action.start" type="object" toc={true}>
  Start a live transcription session.
</ParamField>

<Indent>

<ParamField path="action.start.lang" type="string" required={true} toc={true}>
  The language to transcribe, such as `"en-US"`.
</ParamField>

<ParamField path="action.start.direction" type="string[]" required={true} toc={true}>
  The sides of the call to transcribe: `"remote-caller"`, `"local-caller"`, or both.
</ParamField>

<ParamField path="action.start.webhook" type="string" toc={true}>
  The URL that receives transcription events as HTTP `POST` requests.
</ParamField>

<ParamField path="action.start.live_events" type="boolean" default="false" toc={true}>
  Whether to send each utterance to the webhook as it is transcribed.
</ParamField>

<ParamField path="action.start.ai_summary" type="boolean" default="false" toc={true}>
  Whether to send an AI summary of the conversation to the webhook when the session ends.
</ParamField>

<ParamField path="action.start.ai_summary_prompt" type="string" toc={true}>
  The prompt that tells the AI how to summarize the conversation when `ai_summary` is enabled.
</ParamField>

<ParamField path="action.start.speech_engine" type="string" default="deepgram" toc={true}>
  The speech recognition engine: `"deepgram"` or `"google"`.
</ParamField>

<ParamField path="action.start.speech_timeout" type="number" default="60000" toc={true}>
  The timeout for speech recognition, in milliseconds.
</ParamField>

<ParamField path="action.start.vad_silence_ms" type="number" toc={true}>
  Voice activity detection silence time, in milliseconds.
</ParamField>

<ParamField path="action.start.vad_thresh" type="number" default="400" toc={true}>
  Voice activity detection threshold, from `0` to `1800`.
</ParamField>

</Indent>

<ParamField path="action.summarize" type="object" toc={true}>
  Request an AI summary of the conversation so far, while transcription continues. Pass an empty
  object to send the summary to the webhook from `start` with the default summary prompt.
  `ai_summary_prompt` applies only to the summary sent when the session ends.
</ParamField>

<Indent>

<ParamField path="action.summarize.webhook" type="string" toc={true}>
  The URL that receives the summary.
</ParamField>

<ParamField path="action.summarize.prompt" type="string" toc={true}>
  The prompt that tells the AI how to summarize the conversation.
</ParamField>

</Indent>

<ParamField path="action.stop" type="object" toc={true}>
  Stop the live transcription session. Pass an empty object.
</ParamField>

</Indent>

## **Returns**

`Promise<Record<string, unknown>>` -- Server response confirming the operation.

## **Example**

```typescript {13-20}
import { RelayClient } from '@signalwire/sdk';

const client = new RelayClient({
  project: process.env.SIGNALWIRE_PROJECT_ID!,
  token: process.env.SIGNALWIRE_API_TOKEN!,
  contexts: ['default']
});

client.onCall(async (call) => {
  await call.answer();

  // Start live transcription
  const result = await call.liveTranscribe({
    start: {
      lang: 'en-US',
      direction: ['remote-caller', 'local-caller'],
      webhook: 'https://example.com/transcription-events',
      live_events: true,
    },
  });
  console.log('Live transcription started:', result);

  // Let the call proceed...
  await call.waitForEnded();
});

await client.run();
```
