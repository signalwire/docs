Speak a text-to-speech prompt, then collect DTMF or speech input. A typed
convenience over [`playAndCollect()`][play-and-collect].

## **Parameters**

<ParamField path="text" type="string" required={true} toc={true}>
  The prompt to speak.
</ParamField>

<ParamField path="collect" type="CollectConfig" required={true} toc={true}>
  Input collection configuration: `digits`, `speech`, `initialTimeout`, and
  the other fields accepted by [`playAndCollect()`][play-and-collect].
</ParamField>

<ParamField path="options" type="object" toc={true}>
  Voice and playback options.
</ParamField>

<Indent>

<ParamField path="options.language" type="string" toc={true}>
  Language code for the voice, such as `"en-US"`.
</ParamField>

<ParamField path="options.gender" type="TtsGender" toc={true}>
  `"male"` or `"female"`.
</ParamField>

<ParamField path="options.voice" type="string" toc={true}>
  Voice identifier for the TTS engine.
</ParamField>

<ParamField path="options.volume" type="number" toc={true}>
  Volume adjustment in dB, from `-40` to `40`.
</ParamField>

<ParamField path="options.onCompleted" type="(event: RelayEvent) => void | Promise<void>" toc={true}>
  Callback invoked when the operation reaches a terminal state.
</ParamField>

</Indent>

## **Returns**

`Promise<`[`CollectAction`][collectaction]`>` -- An action handle with `stop()`, `pause()`, `resume()`, `volume()`, `startInputTimers()`, and `wait()` methods.

## **Example**

```typescript {11-14}
import { RelayClient } from '@signalwire/sdk';

const client = new RelayClient({
  project: process.env.SIGNALWIRE_PROJECT_ID!,
  token: process.env.SIGNALWIRE_API_TOKEN!,
  contexts: ['default']
});

client.onCall(async (call) => {
  await call.answer();
  const action = await call.promptTTS(
    'Enter your four digit PIN.',
    { digits: { max: 4, terminators: '#' } },
  );
  const event = await action.wait();
  console.log(event.params);
});

await client.run();
```
