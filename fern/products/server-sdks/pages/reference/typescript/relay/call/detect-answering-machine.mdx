Detect whether a human or an answering machine picked up. A typed convenience
over [`detect()`][detect] with the `machine` detector.

## **Parameters**

<ParamField path="options" type="object" toc={true}>
  Detector options. Each maps to the matching snake_case field of the SWML
  `machine` detector.
</ParamField>

<Indent>

<ParamField path="options.initialTimeout" type="number" toc={true}>
  Seconds to wait for initial voice before deciding.
</ParamField>

<ParamField path="options.endSilenceTimeout" type="number" toc={true}>
  Seconds of silence that end the greeting.
</ParamField>

<ParamField path="options.machineVoiceThreshold" type="number" toc={true}>
  Seconds of continuous voice that indicate a machine.
</ParamField>

<ParamField path="options.machineWordsThreshold" type="number" toc={true}>
  Word count that indicates a machine.
</ParamField>

<ParamField path="options.detectInterruptions" type="boolean" toc={true}>
  Report interruptions during the greeting.
</ParamField>

<ParamField path="options.detectMessageEnd" type="boolean" toc={true}>
  Keep detecting until the machine's greeting ends, so you can leave a message.
</ParamField>

<ParamField path="options.timeout" type="number" toc={true}>
  Maximum seconds to run the detector before stopping.
</ParamField>

<ParamField path="options.onCompleted" type="(event: RelayEvent) => void | Promise<void>" toc={true}>
  Callback invoked when the operation reaches a terminal state.
</ParamField>

</Indent>

## **Returns**

`Promise<`[`DetectAction`][detectaction]`>` -- An action handle with `stop()` and `wait()` methods. It resolves on the first detection result.

## **Example**

```typescript {11}
import { RelayClient } from '@signalwire/sdk';

const client = new RelayClient({
  project: process.env.SIGNALWIRE_PROJECT_ID!,
  token: process.env.SIGNALWIRE_API_TOKEN!,
  contexts: ['default']
});

client.onCall(async (call) => {
  await call.answer();
  const action = await call.detectAnsweringMachine({ detectMessageEnd: true, timeout: 30 });
  const event = await action.wait();
  console.log(event.params);
});

await client.run();
```
