Wait for the call to reach the `answered` state. Returns immediately if the call
is already answered or past that state. A typed wait over [`waitFor()`][wait-for].

## **Parameters**

<ParamField path="timeout" type="number | undefined" toc={true}>
  Maximum milliseconds to wait. Throws an `Error` if exceeded. `undefined`
  waits indefinitely.
</ParamField>

## **Returns**

`Promise<`[`RelayEvent`][relayevent]`>` -- The state-change event.

## **Example**

```typescript {12}
import { RelayClient } from '@signalwire/sdk';

const client = new RelayClient({
  project: process.env.SIGNALWIRE_PROJECT_ID!,
  token: process.env.SIGNALWIRE_API_TOKEN!,
  contexts: ['default']
});

client.onCall(async (call) => {
  await call.answer();
  const dialed = await client.dial([[{ type: 'phone', to: '+15559876543', from: '+15551234567' }]]);
  await dialed.waitForAnswered(30000);
  console.log(dialed.state);
});

await client.run();
```
