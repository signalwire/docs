Unwrap a fenced code block such as ```` ```json ... ``` ````. The chat engine hands the model's
answer back verbatim, fence and all, where the voice engine parses it first. Text without a
fence is returned trimmed.

```typescript {1}
stripJsonFence(text: string): string
```

## Parameters

<ParamField path="text" type="string" required={true} toc={true}>
  The text to unwrap.
</ParamField>

## Returns

`string` -- The text without a surrounding code fence, trimmed.

## Examples

```typescript {4}
import { stripJsonFence } from '@signalwire/sdk';

const fenced = '```json\n{"intent":"book_ride"}\n```';
console.log(stripJsonFence(fenced));
// {"intent":"book_ride"}
console.log(stripJsonFence('  {"intent":"book_ride"}  '));
// {"intent":"book_ride"}
console.log(JSON.parse(stripJsonFence(fenced)).intent);
// book_ride
```

Part of the [post-prompt normalization][ref-post-prompt] helpers.
