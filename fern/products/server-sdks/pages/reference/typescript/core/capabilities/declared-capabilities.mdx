Return the names the client declared as truthy under `capabilities`. It accepts either a whole SWML
request body or user variables already extracted with [`userVariables()`][user-variables], so it
works from a dynamic-config callback and from a tool handler alike.

A capability counts only when its value is truthy. `false`, `0`, an empty string, an empty array, and
an empty object all mean "not declared".

```typescript {1}
declaredCapabilities(bodyParams: unknown): ReadonlySet<string>
```

## Parameters

<ParamField path="bodyParams" type="unknown" required={true} toc={true}>
  A SWML request body, or a user variables object.
</ParamField>

## Returns

`ReadonlySet<string>` -- The declared names. Empty when nothing was declared, the payload was
malformed, or the client isn't a browser at all. Never throws.

## Examples

```typescript {11}
import { declaredCapabilities } from '@signalwire/sdk';

const body = {
  vars: {
    userVariables: {
      capabilities: { display_content: true, transcript: 1, chat_handoff: false, tags: [] },
    },
  },
};

console.log([...declaredCapabilities(body)]);
// [ 'display_content', 'transcript' ]

// User variables passed directly give the same result.
console.log([...declaredCapabilities(body.vars.userVariables)]);
// [ 'display_content', 'transcript' ]

console.log(declaredCapabilities(null).size);
// 0
```

Part of the [client capabilities][ref-capabilities] helpers.
