Whether the client declared `name`. A convenience over
[`declaredCapabilities()`][declared-capabilities] for a single check.

```typescript {1}
hasCapability(bodyParams: unknown, name: string): boolean
```

## Parameters

<ParamField path="bodyParams" type="unknown" required={true} toc={true}>
  A SWML request body, or a user variables object.
</ParamField>

<ParamField path="name" type="string" required={true} toc={true}>
  Capability name, such as `'display_content'`.
</ParamField>

## Returns

`boolean` -- `true` only when the capability was explicitly declared truthy.

## Examples

```typescript {7,9,11}
import { hasCapability } from '@signalwire/sdk';

const body = {
  vars: { userVariables: { capabilities: { transcript: true, chat_handoff: false } } },
};

console.log(hasCapability(body, 'transcript'));
// true
console.log(hasCapability(body, 'chat_handoff'));
// false
console.log(hasCapability(body, 'display_content'));
// false
```

Part of the [client capabilities][ref-capabilities] helpers.
