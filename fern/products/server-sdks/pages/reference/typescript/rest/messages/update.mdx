Redact the body of a message you already sent. The only field that can be
changed is `body`, and it must be an empty string; any other value is rejected.

<EndpointSchemaSnippet endpoint="PATCH /api/messaging/messages/{message_id}" />

## **Response Example**

<EndpointResponseSnippet endpoint="PATCH /api/messaging/messages/{message_id}" />

## **Example**

```typescript {9}
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "your-project-id",
  token: "your-api-token",
  host: "your-space.signalwire.com"
});

const redacted = await client.messages.update("message-id", "");
console.log(redacted.body); // ""
```
