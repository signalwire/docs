Keep it to [pause][pause], [resume][resume], or [stop][stop] the recording
later.

## **Request**

<Schema type="Calling.CallRecordRequest" api="signalwire-rest" exclude={["command"]} />

## **Response**

<Schema type="Calling.CallResponse" api="signalwire-rest" />

## **Example**

```typescript {9-13}
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "your-project-id",
  token: "your-api-token",
  host: "your-space.signalwire.com"
});

const controlId = "recording-1";
await client.calling.record("call-id-xxx", {
  control_id: controlId,
  audio: { format: "mp3", stereo: true },
});
```
