Start a detector on an active call. Detectors can identify answering machines,
fax tones, or DTMF digits. Pass a `control_id` of your choosing in the options
and keep it. The ID must be unique per active detector on the call, and
[`detectStop()`][detect-stop] uses it to end the detector.

[detect-stop]: /docs/server-sdks/reference/typescript/rest/calling/detect-stop

## **Examples**

### Answering Machine Detection

```typescript {9-20}
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "your-project-id",
  token: "your-api-token",
  host: "your-space.signalwire.com"
});

// Answering machine detection, correlated by the control ID you choose
const controlId = "amd-1";
const result = await client.calling.detect(
  "call-id-xxx",
  {
    type: "machine",
    params: {
      initial_timeout: 4.5,
      end_silence_timeout: 1.0,
    },
  },
  { control_id: controlId, timeout: 30.0 },
);
```

### Fax Detection

```typescript {9-12}
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "your-project-id",
  token: "your-api-token",
  host: "your-space.signalwire.com"
});

const result = await client.calling.detect("call-id-xxx", {
  type: "fax",
  params: { tone: "CED" },
}, { control_id: "fax-detect-1" });
```

### Digit Detection

```typescript {9-12}
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "your-project-id",
  token: "your-api-token",
  host: "your-space.signalwire.com"
});

const result = await client.calling.detect("call-id-xxx", {
  type: "digit",
  params: { digits: "0123456789#*" },
}, { control_id: "digit-detect-1" });
```
