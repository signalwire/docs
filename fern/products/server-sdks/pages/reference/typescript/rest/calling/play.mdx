Play audio or text-to-speech on an active call. Pass a `control_id` of your
choosing in the options to manage the playback later with
[`playPause()`][play-pause], [`playResume()`][play-resume],
[`playStop()`][play-stop], and [`playVolume()`][play-volume]. The ID must be
unique per active playback on the call. The response confirms that the command
was accepted; playback state arrives asynchronously at `status_url`.

## **Examples**

### Play TTS

```typescript {9-14}
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "your-project-id",
  token: "your-api-token",
  host: "your-space.signalwire.com"
});

// Choose a control ID and keep it for later play commands
const controlId = "greeting-1";
await client.calling.play(
  "call-id-xxx",
  [{ type: "tts", params: { text: "Hello from the REST API!" } }],
  { control_id: controlId },
);
```

### Play Audio File

```typescript {9-11}
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "your-project-id",
  token: "your-api-token",
  host: "your-space.signalwire.com"
});

await client.calling.play("call-id-xxx", [
  { type: "audio", params: { url: "https://example.com/greeting.mp3" } },
], { control_id: "greeting-1" });
```

### Play Multiple Items

```typescript {9}
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "your-project-id",
  token: "your-api-token",
  host: "your-space.signalwire.com"
});

await client.calling.play(
  "call-id-xxx",
  [
    { type: "tts", params: { text: "Please hold while we connect you." } },
    { type: "silence", params: { duration: 1 } },
    { type: "audio", params: { url: "https://example.com/hold-music.mp3" } },
  ],
  { control_id: "hold-sequence-1", loop: 2 },
);
```
