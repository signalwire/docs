Stop an active AI session on a call. The AI agent is disconnected but
the call itself remains active, allowing further call control operations.

## **Request**

<Schema type="Calling.CallAIStopRequest" api="signalwire-rest" exclude={["command"]} />

## **Response**

<Schema type="Calling.CallResponse" api="signalwire-rest" />

## **Example**

```typescript {10-13}
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "your-project-id",
  token: "your-api-token",
  host: "your-space.signalwire.com"
});

// Stop the AI agent by its control ID, then play a goodbye message under a new one
await client.calling.aiStop("call-id-xxx", "agent-1");
await client.calling.play("call-id-xxx", [
  { type: "tts", params: { text: "Thank you for calling. Goodbye!" } },
], { control_id: "goodbye-1" });
await client.calling.end("call-id-xxx", { reason: "hangup" });
```
