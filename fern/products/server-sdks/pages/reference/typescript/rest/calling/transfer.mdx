Transfer an active call to a new destination. Pass a destination string, such
as a SIP address, or an inline SWML document that takes over the call.

## **Request**

<Schema type="Calling.CallTransferRequest" api="signalwire-rest" exclude={["command"]} />

## **Response**

<Schema type="Calling.CallResponse" api="signalwire-rest" />

## **Example**

```typescript {9}
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "your-project-id",
  token: "your-api-token",
  host: "your-space.signalwire.com"
});

await client.calling.transfer("call-id-xxx", {
  version: "1.0.0",
  sections: {
    main: [{ connect: { to: "+15559876543" } }],
  },
});
```
