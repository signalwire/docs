Start, summarize, or stop live translation on an active call. Spoken audio is transcribed and
translated in real time, and each party hears the other in their own language. Pass the action
as `action`: a `start`, `summarize`, or `inject` object, or the string `"stop"`.

## **Request**

<Schema type="Calling.CallLiveTranslateRequest" api="signalwire-rest" exclude={["command"]} />

## **Response**

<Schema type="Calling.CallResponse" api="signalwire-rest" />

## **Example**

```typescript {9-19}
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "your-project-id",
  token: "your-api-token",
  host: "your-space.signalwire.com"
});

await client.calling.liveTranslate("call-id-xxx", {
  action: {
    start: {
      from_lang: "en-US",
      to_lang: "es-ES",
      direction: ["local-caller", "remote-caller"],
      from_voice: "elevenlabs.josh",
      to_voice: "elevenlabs.josh",
    },
  },
});
```
