Start collecting user input on an active call. Supports DTMF digit collection
and speech recognition.

<Markdown src="/snippets/server-sdks/control-id-note.mdx" />

Keep it to manage the collection later.

## **Examples**

### Collect DTMF Digits

```typescript {10-14}
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "your-project-id",
  token: "your-api-token",
  host: "your-space.signalwire.com"
});

// Collect DTMF digits under a control ID you choose
const result = await client.calling.collect("call-id-xxx", {
  control_id: "pin-collect-1",
  digits: { max: 4, terminators: "#", digit_timeout: 5.0 },
  initial_timeout: 10.0,
});
```

### Collect Speech

```typescript {9-15}
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "your-project-id",
  token: "your-api-token",
  host: "your-space.signalwire.com"
});

const result = await client.calling.collect("call-id-xxx", {
  control_id: "speech-collect-1",
  speech: {
    end_silence_timeout: 1.0,
    language: "en-US",
  },
});
```

### Collect Both

```typescript {9-14}
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "your-project-id",
  token: "your-api-token",
  host: "your-space.signalwire.com"
});

const result = await client.calling.collect("call-id-xxx", {
  control_id: "combined-collect-1",
  digits: { max: 1, terminators: "#" },
  speech: { end_silence_timeout: 2.0 },
  initial_timeout: 15.0,
});
```
