Start streaming audio from an active call to a WebSocket endpoint. This is
commonly used for real-time speech processing, analytics, or archival.

<Markdown src="/snippets/server-sdks/control-id-note.mdx" />

Keep it to stop the stream later.

## **Request**

<Schema type="Calling.CallStreamRequest" api="signalwire-rest" exclude={["command"]} />

## **Response**

<Schema type="Calling.CallResponse" api="signalwire-rest" />

## **Example**

```typescript {9-12}
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "your-project-id",
  token: "your-api-token",
  host: "your-space.signalwire.com"
});

const controlId = "audio-stream-1";
await client.calling.stream("call-id-xxx", "wss://example.com/audio-stream", {
  control_id: controlId,
});
```
