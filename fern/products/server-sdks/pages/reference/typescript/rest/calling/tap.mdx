Start tapping audio from an active call and sending it to an external endpoint
(e.g., a WebSocket or RTP destination).

<Markdown src="/snippets/server-sdks/control-id-note.mdx" />

Keep it to stop the tap later.

## **Request**

<Schema type="Calling.CallTapRequest" api="signalwire-rest" exclude={["command"]} />

## **Response**

<Schema type="Calling.CallResponse" api="signalwire-rest" />

## **Example**

```typescript {9-15}
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "your-project-id",
  token: "your-api-token",
  host: "your-space.signalwire.com"
});

const controlId = "tap-1";
await client.calling.tap(
  "call-id-xxx",
  { type: "audio", params: { direction: "both" } },
  { type: "ws", params: { uri: "wss://example.com/tap" } },
  { control_id: controlId },
);
```
