Retrieve a project by ID.

<EndpointSchemaSnippet endpoint="GET /api/projects/{id}" />

## **Response Example**

<EndpointResponseSnippet endpoint="GET /api/projects/{id}" />

## **Example**

```typescript {9}
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "your-project-id",
  token: "your-api-token",
  host: "your-space.signalwire.com"
});

const project = await client.projects.get("project-id");
console.log(project.name, project.region_preference);
```
