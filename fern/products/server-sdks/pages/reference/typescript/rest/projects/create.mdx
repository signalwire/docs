Create a subproject under the authenticated root project. Pass the typed body
first; the optional `extras` argument merges additional fields the body type
does not name yet.

<EndpointSchemaSnippet endpoint="POST /api/projects" />

## **Response Example**

<EndpointResponseSnippet endpoint="POST /api/projects" />

## **Example**

```typescript {9-12}
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "your-project-id",
  token: "your-api-token",
  host: "your-space.signalwire.com"
});

const project = await client.projects.create({
  name: "Bayview Taxi Staging",
  protect_recordings: true,
});
console.log(project.id);
```
