List the authenticated root project and its subprojects. Use `paginate()` to
iterate every project across pages.

<EndpointSchemaSnippet endpoint="GET /api/projects" />

## **Response Example**

<EndpointResponseSnippet endpoint="GET /api/projects" />

## **Example**

```typescript {9}
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "your-project-id",
  token: "your-api-token",
  host: "your-space.signalwire.com"
});

for await (const project of client.projects.paginate()) {
  console.log(project.name, project.subproject ? "(subproject)" : "(root)");
}
```
