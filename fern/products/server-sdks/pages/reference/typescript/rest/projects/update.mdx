Update a project's name or protection settings. Pass the ID, then the typed
body; the optional `extras` argument merges additional fields.

<EndpointSchemaSnippet endpoint="PATCH /api/projects/{id}" />

## **Response Example**

<EndpointResponseSnippet endpoint="PATCH /api/projects/{id}" />

## **Example**

```typescript {9-11}
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "your-project-id",
  token: "your-api-token",
  host: "your-space.signalwire.com"
});

const project = await client.projects.update("project-id", {
  force_https_requests: true,
});
```
