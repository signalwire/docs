[update]: /docs/server-sdks/reference/typescript/rest/phone-numbers/update

Route inbound calls on this phone number to a Relay topic. Relay clients
subscribed to the topic will receive the inbound call event.

This is a typed wrapper over [`update`][update] that sets `call_handler` to
`relay_topic` and populates `call_relay_topic` for you.

## **Parameters**

<ParamField path="resourceId" type="string" required={true} toc={true}>
  ID of the phone number to bind.
</ParamField>

<ParamField path="topic" type="string" required={true} toc={true}>
  Relay topic name. Serialized as `call_relay_topic`.
</ParamField>

<ParamField path="status_callback_url" type="string" toc={true}>
  URL that receives status updates for calls routed via this topic. Serialized as `call_relay_topic_status_callback_url`.
</ParamField>

<ParamField path="extra" type="Record<string, unknown>" toc={true}>
  Additional fields merged into the request body.
</ParamField>

## **Returns**

`Promise<PhoneNumberResponse>` — The updated phone-number resource.

## **Example**

```typescript {9}
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "your-project-id",
  token: "your-api-token",
  host: "your-space.signalwire.com"
});

await client.phoneNumbers.setRelayTopic("phone-number-id", "office", "https://example.com/status");
```
