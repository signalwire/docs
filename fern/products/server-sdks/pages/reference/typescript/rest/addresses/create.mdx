Create a new regulatory address.

<EndpointSchemaSnippet endpoint="POST /api/relay/rest/addresses" />

## **Response Example**

<EndpointResponseSnippet endpoint="POST /api/relay/rest/addresses" />

## **Example**

```typescript {9-19}
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "your-project-id",
  token: "your-api-token",
  host: "your-space.signalwire.com"
});

const addr = await client.addresses.create(
  "HQ Address",
  "US",
  "Jane",
  "Doe",
  "123",
  "Main St",
  "Austin",
  "TX",
  "78701",
);
console.log("Created address:", addr.id);
```
