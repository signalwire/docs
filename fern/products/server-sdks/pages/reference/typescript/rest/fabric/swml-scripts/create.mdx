Create a new SWML script resource.

<EndpointSchemaSnippet endpoint="POST /api/fabric/resources/swml_scripts" />

## **Response Example**

<EndpointResponseSnippet endpoint="POST /api/fabric/resources/swml_scripts" />

## **Example**

```typescript {9-15}
import { RestClient } from "@signalwire/sdk";

const client = new RestClient({
  project: "your-project-id",
  token: "your-api-token",
  host: "your-space.signalwire.com",
});

const result = await client.fabric.swmlScripts.create({
  name: "my-script",
  contents: JSON.stringify({
    version: "1.0.0",
    sections: { main: [{ answer: {} }, { hangup: {} }] },
  }),
});
console.log(`Created: ${result.id}`);
```
