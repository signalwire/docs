Set the default history visibility mode for every step in this context. A
step's own [`setHistory()`][step-set-history] overrides it. See that page for
what each mode does.

## **Parameters**

<ParamField path="history" type={"'keep' | 'default' | 'hide'"} required={true} toc={true}>
  History visibility mode: `"keep"`, `"default"`, or `"hide"`.
</ParamField>

## **Returns**

[`Context`][ref-context] -- Self for method chaining. Throws an `Error` if
`history` is not one of the three modes.

## **Example**

```typescript {5}
import { ContextBuilder } from '@signalwire/sdk';

const builder = new ContextBuilder();
const ctx = builder.addContext('billing');
ctx.setHistory('keep');
ctx.addStep('verify').setText('Verify the account holder.');
ctx.addStep('dispute').setText('Take the details of the disputed charge.');
```
