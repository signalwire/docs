[context-set-history]: /docs/server-sdks/reference/typescript/agents/context-builder/context/set-history

Control how much of the prior conversation the model sees when this step
begins. The setting applies to everything that came before the step; the step's
own turns accumulate normally, and nothing is deleted from the call log.
Overrides the context-level default set with
[`Context.setHistory()`][context-set-history].

## **Parameters**

<ParamField path="history" type={"'keep' | 'default' | 'hide'"} required={true} toc={true}>
  History visibility mode.

  - `"keep"` -- clear nothing. Every prior step's instructions and dialogue stay
    visible to the model.
  - `"default"` -- hide the prior steps' instructions but keep the user and
    assistant dialogue. This is the behavior when unset.
  - `"hide"` -- hide the prior instructions and pull the prior dialogue out of the
    model's context. Reference `${step_history.*}` in this step's text to bring
    back exactly what you need.
</ParamField>

## **Returns**

[`Step`][ref-step] -- Self for method chaining. Throws an `Error` if `history` is
not one of the three modes.

## **Example**

```typescript {8}
import { ContextBuilder } from '@signalwire/sdk';

const builder = new ContextBuilder();
const ctx = builder.addContext('default');

ctx.addStep('collect_pickup').setText('Ask for the pickup address.');
ctx.addStep('confirm_fare')
  .setHistory('hide')
  .setText('Quote the fare for the pickup at ${step_history.collect_pickup} and confirm.');
```
