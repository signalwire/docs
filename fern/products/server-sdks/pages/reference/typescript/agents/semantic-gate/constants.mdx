The SDK checks semantic gates against the platform's limits when a tool is defined
and throws for anything the platform would refuse. These exports hold those limits.

```typescript
import {
  MAX_GATES,
  MAX_QUESTION_BYTES,
  MAX_CRITERIA_BYTES,
  MAX_ON_FAIL_BYTES,
  MAX_VISUAL_INPUT,
  RESERVED_FUNCTION_NAMES,
} from '@signalwire/sdk';
```

## Properties

<ParamField path="MAX_GATES" type="number" toc={true}>
  `8`. The most gates one function can carry.
</ParamField>

<ParamField path="MAX_QUESTION_BYTES" type="number" toc={true}>
  `8192`. The longest gate `question`, in UTF-8 bytes.
</ParamField>

<ParamField path="MAX_CRITERIA_BYTES" type="number" toc={true}>
  `2048`. The longest `criteria.true` or `criteria.false` (`trueMeans` or `falseMeans`), in
  UTF-8 bytes.
</ParamField>

<ParamField path="MAX_ON_FAIL_BYTES" type="number" toc={true}>
  `8192`. The largest `on_fail` output, measured as compact JSON in UTF-8 bytes.
</ParamField>

<ParamField path="MAX_VISUAL_INPUT" type="number" toc={true}>
  `5`. The most caller video frames a gate may ask for with `visualInput`.
</ParamField>

<ParamField path="RESERVED_FUNCTION_NAMES" type="ReadonlySet<string>" toc={true}>
  Hook and built-in function names that can't carry gates: `startup_hook`,
  `hangup_hook`, `check_for_input`, `end_call`, `hangup`, `check_time`,
  `wait_for_user`, `wait_seconds`, `adjust_response_latency`, `next_step`,
  `change_context`, `gather_submit`, `get_visual_input`, `get_ideal_strategy`, and
  `pause_conversation`.
</ParamField>

## Examples

```typescript
import { MAX_GATES, RESERVED_FUNCTION_NAMES } from '@signalwire/sdk';

console.log(MAX_GATES); // 8
console.log(RESERVED_FUNCTION_NAMES.has('end_call')); // true
```
