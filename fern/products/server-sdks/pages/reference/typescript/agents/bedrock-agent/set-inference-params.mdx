Update Bedrock inference parameters. Only the arguments you pass are changed;
an argument left `undefined` keeps its current value.

## **Parameters**

<ParamField path="temperature" type="number | string" toc={true}>
  Generation temperature. Range: 0 to 2. A numeric string is converted, and a SWML
  variable reference such as `'${temperature}'` is kept; anything else throws and
  changes nothing.
</ParamField>

<ParamField path="topP" type="number | string" toc={true}>
  Nucleus sampling parameter. Range: 0 to 1. A numeric string is converted, and a
  SWML variable reference is kept; anything else throws and changes nothing.
</ParamField>

<ParamField path="maxTokens" type="number | string" toc={true}>
  Maximum tokens to generate, an integer or a numeric string. Sent in the prompt as
  `max_tokens`, but the platform's Bedrock session doesn't apply it.
</ParamField>

## **Returns**

[`BedrockAgent`][ref-bedrockagent] -- Returns `this` for method chaining.

## **Example**

```typescript {9}
import { BedrockAgent } from '@signalwire/sdk';

const agent = new BedrockAgent({
  name: 'bedrock-assistant',
  route: '/assistant',
  systemPrompt: 'You are a helpful assistant.',
});

agent.setInferenceParams(0.3, 0.95, 2048);
```
