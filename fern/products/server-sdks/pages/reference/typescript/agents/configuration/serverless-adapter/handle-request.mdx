Convert a serverless event into a standard `Request`, route it through the Hono
app, and return a normalized `ServerlessResponse`.

## **Parameters**

<ParamField path="app" type="{ fetch: (req: Request, env?: Record<string, unknown>) => Response | Promise<Response> }" required={true} toc={true}>
  A Hono-compatible application with a `fetch` method.
</ParamField>

<ParamField path="event" type="ServerlessEvent" required={true} toc={true}>
  The incoming serverless event. Properties include `httpMethod`, `method`,
  `headers`, `body`, `isBase64Encoded`, `path`, `rawPath`, `queryStringParameters`,
  `multiValueQueryStringParameters` and `pathParameters` (API Gateway REST),
  `rawQueryString` (API Gateway v2 and function URLs), and `requestContext`.

  With a signing key set, the signature is checked over the URL SignalWire signed:
  the URL the platform was called on, with its query, and the raw body.
</ParamField>

## **Returns**

`Promise<ServerlessResponse>` -- A normalized response with `statusCode`,
`headers`, and `body`.

## **Example**

```typescript {5}
import { ServerlessAdapter } from '@signalwire/sdk';

const adapter = new ServerlessAdapter('lambda');

const response = await adapter.handleRequest(app, lambdaEvent);
console.log(response.statusCode, response.body);
```
