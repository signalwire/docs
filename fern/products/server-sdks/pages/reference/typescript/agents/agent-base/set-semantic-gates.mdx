Set how the call checks the [semantic gates][semanticgate] on its SWAIG functions.
Each option sets one [AI parameter][ai-params]. An option left out leaves that
setting as it is, and the platform default applies to a setting that was never
set.

## Parameters

<ParamField path="opts" type="object" toc={true}>
  The gate settings.
</ParamField>

<Indent>

<ParamField path="opts.enabled" type="boolean" toc={true}>
  `false` runs gated functions without checking their gates. Sets
  `semantic_gates_enabled`; the platform default is `true`.
</ParamField>

<ParamField path="opts.timeoutMs" type="number" toc={true}>
  How long one gate check may take, an integer from 500 to 10000 milliseconds. A
  check that runs out of time blocks the function. Sets
  `semantic_gate_timeout_ms`; the platform default is 2500.
</ParamField>

<ParamField path="opts.history" type="number" toc={true}>
  How many recent conversation entries the decision model reads, an integer from
  0 to 100. Sets `semantic_gate_history`; the platform default is 20.
</ParamField>

</Indent>

Throws when a value has the wrong type or is out of range, without changing any
setting.

## Returns

[`AgentBase`][ref-agentbase] -- Returns `this` for method chaining.

## Examples

```typescript {5}
import { AgentBase } from '@signalwire/sdk';

const agent = new AgentBase({ name: 'account-agent', route: '/account' });
agent.setPromptText('You help callers manage their account.');
agent.setSemanticGates({ timeoutMs: 4000, history: 40 });
await agent.serve();
```
