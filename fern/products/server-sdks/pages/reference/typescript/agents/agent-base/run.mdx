[serve]: /docs/server-sdks/reference/typescript/agents/agent-base/serve

Start the HTTP server like [`serve()`][serve], or handle a single serverless invocation.
`run()` handles the invocation instead of serving when `opts.event` is given, or when the
environment shows a serverless platform: any of `AWS_LAMBDA_FUNCTION_NAME`, `_HANDLER`,
`FUNCTION_TARGET`, `FUNCTIONS_WORKER_RUNTIME`, or `GATEWAY_INTERFACE` is set. Otherwise it calls
`serve(opts)`.

Returns immediately when `SWAIG_CLI_MODE=true` is set, so the CLI testing tool can load the
agent without opening a port.

## **Parameters**

<ParamField path="opts" type="object" toc={true}>
  Optional server overrides and serverless invocation data.
</ParamField>

<Indent>
<ParamField path="opts.host" type="string" toc={true}>
  Host to bind the server to. Falls back to the constructor's `host` option.
</ParamField>

<ParamField path="opts.port" type="number" toc={true}>
  Port to listen on. Falls back to the constructor's `port` option.
</ParamField>

<ParamField path="opts.event" type="ServerlessEvent" toc={true}>
  The platform's invocation event. When set, `run()` handles this invocation instead of starting
  a server.
</ParamField>

<ParamField path="opts.context" type="unknown" toc={true}>
  The platform's invocation context, passed through with the event.
</ParamField>

<ParamField path="opts.platform" type={"'lambda' | 'gcf' | 'azure' | 'cgi' | 'auto'"} toc={true}>
  Serverless platform. Detected from the environment when omitted.
</ParamField>
</Indent>

## **Returns**

`Promise<void | ServerlessResponse>` -- Resolves once the server is running, or with the
response for a serverless invocation.

## **Example**

```typescript {5}
import { AgentBase } from '@signalwire/sdk';

const agent = new AgentBase({ name: 'my-agent', route: '/agent' });
agent.setPromptText('You are a helpful assistant.');
await agent.run();
```
