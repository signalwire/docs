Replace the entire `global_data` object available to the AI, discarding every
prior key. [`setGlobalData()`][set-global-data] and
[`updateGlobalData()`][update-global-data] merge into the existing object; this
method clears it first. A shallow copy of `data` is stored, so later changes to
your object don't leak into the agent.

## **Parameters**

<ParamField path="data" type={"Record<string, unknown>"} required={true} toc={true}>
  The new global data object.
</ParamField>

## **Returns**

[`AgentBase`][ref-agentbase] -- Returns `this` for method chaining.

## **Example**

```typescript {6}
import { AgentBase } from '@signalwire/sdk';

const agent = new AgentBase({ name: 'dispatch', route: '/dispatch' });

agent.setGlobalData({ region: 'bayview', fleet_size: 12 });
agent.replaceGlobalData({ region: 'mission' }); // fleet_size is gone
```
