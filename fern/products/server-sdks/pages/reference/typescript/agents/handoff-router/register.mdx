Records which conversation and call a nonce belongs to. Call it from the per-call config callback of
the dial that carried the nonce, with `callId` from the request the platform sent, never from
anything the browser supplied.

Registering a nonce that's already in the table changes nothing, because the callback runs on every
config request for the call. The first registration's call, time, and message count stand, and a
nonce [`redeem()`][redeem] has used stays used until it would have expired. An empty or non-string
nonce is ignored.

## Parameters

<ParamField path="nonce" type="string" required={true} toc={true}>
  The nonce put in the dial's user variables.
</ParamField>

<ParamField path="opts" type={"{ conversationId: string; callId?: string | null }"} required={true} toc={true}>
  What the nonce gives access to.
</ParamField>

<Indent>

<ParamField path="opts.conversationId" type="string" required={true} toc={true}>
  The conversation the call belongs to.
</ParamField>

<ParamField path="opts.callId" type="string | null" toc={true}>
  The platform call id. Without one, `/handoff` has no call to end and `/say` has no call to speak
  into.
</ParamField>

</Indent>

## Returns

`void`.

## Examples

```typescript
import { ChatGateway, HandoffRouter } from '@signalwire/sdk';

const gateway = new ChatGateway({ configUrl: 'https://bayview-taxi.example.com/dispatch' });
const handoff = new HandoffRouter({ gateway });

// From the per-call config callback of the dial that carried the nonce.
handoff.register('n_7f3a91c2', {
  conversationId: 'chat-8f21',
  callId: 'b2c0f1e4-5a6d-4f0e-9d1b-3c7e8a9f0b12',
});
```
