Functions exported from `@signalwire/sdk` that act on the singleton
[`SkillRegistry`][skill-registry], so you don't call `SkillRegistry.getInstance()` yourself.

## registerSkill

Register a custom skill class, bypassing the directory scan. Proxies to
[`register()`][register].

<ParamField path="skillClass" type="typeof SkillBase" required={true} toc={true}>
  The skill class to register, a subclass of `SkillBase`.
</ParamField>

Returns `void`.

## listSkills

List metadata for every registered skill. Proxies to [`listSkills()`][list-skills].

Returns `SkillSchemaInfo[]`.

## listSkillsWithParams

Get the full schema of every registered skill, including parameter metadata. Proxies to
[`getAllSkillsSchema()`][get-all-skills-schema].

Returns `Record<string, SkillSchemaInfo>`, keyed by skill name.

## addSkillDirectory

Add a directory to search for skill modules. Proxies to [`addSearchPath()`][add-search-path],
which accepts any path; it does not run the validation of the
[`SkillRegistry.addSkillDirectory()`][add-skill-directory] method of the same name.

<ParamField path="path" type="string" required={true} toc={true}>
  Absolute path to a directory containing skill files.
</ParamField>

Returns `void`.

## Example

```typescript {16-17}
import { FunctionResult, SkillBase, listSkillsWithParams, registerSkill } from '@signalwire/sdk';

class FareSkill extends SkillBase {
  static override SKILL_NAME = 'fare_quote';
  static override SKILL_DESCRIPTION = 'Quote a Bayview Taxi fare';

  override getTools() {
    return [{
      name: 'quote_fare',
      description: 'Quote the fare between two addresses',
      handler: () => new FunctionResult('That trip is about 24 dollars.'),
    }];
  }
}

registerSkill(FareSkill);
console.log(Object.keys(listSkillsWithParams()));
```
