---
title: "discoverAll"
slug: reference/typescript/agents/skill-registry/discover-all
description: "Discover and register skills from all configured directories."
---

Discover and register skills from every configured directory: the search paths
(added via `addSearchPath()` or the `SIGNALWIRE_SKILL_PATHS` environment
variable) and the directories added with `addSkillDirectory()`, each scanned
once. Calls `discoverFromDirectory()` for each.

## **Parameters**

None.

## **Returns**

`Promise<string[]>` -- Array of all newly discovered skill names across all directories.
