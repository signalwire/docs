Remove a skill registration by name. A locked skill isn't removed.

## **Parameters**

<ParamField path="name" type="string" required={true} toc={true}>
  The skill name to unregister.
</ParamField>

## **Returns**

`boolean` -- `true` if the skill was found and removed; `false` if it isn't
registered or is locked.
