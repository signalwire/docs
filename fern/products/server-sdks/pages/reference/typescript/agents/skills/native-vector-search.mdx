Search documents by keyword scoring or through a remote search server. Supports
two modes:

- **In-memory (TF-IDF)** — supply a `documents` array in config; the skill
  tokenizes and indexes at startup (TypeScript-specific fast path).
- **Remote (network)** — point `remote_url` at a search server and optionally
  name the index via `index_name`. Validated by the SSRF guard before each
  request; health check uses a 5-second timeout.

<Note>
The Python SDK's local-index parameters (`index_file`, `build_index`,
`backend`, and the rest) are accepted so a Python configuration still loads,
but this skill doesn't use them; see
[Python compatibility parameters](#python-compatibility-parameters). The `search_stats.backend` value the skill writes to global
data is `remote` with `remote_url` and `memory` otherwise.
</Note>

**Class:** `NativeVectorSearchSkill`

**Tools:** `search_knowledge` (default — `tool_name` override supported)

**Env vars:** None

**Multi-instance:** yes (distinguished by `tool_name` + `index_file`)

## Core Parameters

<ParamField path="tool_name" type="string" default="search_knowledge" toc={true}>
  Custom tool name for this skill instance. Required when registering multiple
  instances on the same agent.
</ParamField>

<ParamField path="remote_url" type="string" toc={true}>
  URL of a remote search server (network mode). Validated by the SSRF guard —
  private, loopback, and cloud-metadata endpoints are rejected. Every request,
  and every redirect it follows, is checked the same way. Credentials in the
  URL (`https://user:password@host`) are sent as basic auth and kept out of
  logs.
</ParamField>

<ParamField path="index_name" type="string" default="default" toc={true}>
  Name of the index on a remote server. Only used with `remote_url`.
</ParamField>

<ParamField path="documents" type="object[]" toc={true}>
  In-memory array of documents to index (TypeScript-specific). Each entry has
  `id` (string), `text` (string), optional `metadata` (object), and optional
  `tags` (string[]).
</ParamField>

## Search Parameters

<ParamField path="count" type="integer" default="5" toc={true}>
  Number of search results to return (range `1-20`).
</ParamField>

<ParamField path="similarity_threshold" type="number" default="0.0" toc={true}>
  Minimum similarity score for results (`0.0` — no limit, `1.0` — exact match).
</ParamField>

<ParamField path="keyword_weight" type="number" toc={true}>
  In-memory mode only: how much keyword overlap counts against TF-IDF in the
  score (range `0.0-1.0`, default `0.3`). Has no effect with `remote_url`,
  where the server ranks results, and logs a warning there.
</ParamField>

## Content Parameters

<ParamField path="tags" type="string[]" default="[]" toc={true}>
  Tag filter applied to search queries. Only documents carrying at least one
  matching tag are returned.
</ParamField>

<ParamField path="global_tags" type="string[]" default="[]" toc={true}>
  Tags added to every entry in `documents` when the skill indexes them at
  startup.
</ParamField>

<ParamField path="max_content_length" type="integer" default="32768" toc={true}>
  Maximum total response size in characters (distributed across all results).
</ParamField>

## Response Parameters

<ParamField path="no_results_message" type="string" default="No information found for '{query}'" toc={true}>
  Message returned when no results match. Supports a `{query}` placeholder
  that is substituted with the user's query text.
</ParamField>

<ParamField path="response_prefix" type="string" default="" toc={true}>
  Text prepended to the search response.
</ParamField>

<ParamField path="response_postfix" type="string" default="" toc={true}>
  Text appended to the search response.
</ParamField>

<ParamField path="response_format_callback" type="function" toc={true}>
  Optional callback to transform the final response. Receives
  `{ response, agent, query, results, args, count, skill }` and must return a
  string.
</ParamField>

<ParamField path="description" type="string" default="Search the knowledge base for information" toc={true}>
  Description of the search tool presented to the AI.
</ParamField>

<ParamField path="hints" type="string[]" default="[]" toc={true}>
  Additional speech recognition hints for the tool.
</ParamField>

## Other Parameters

<ParamField path="verbose" type="boolean" default="false" toc={true}>
  Enable verbose logging during indexing and search.
</ParamField>

## Python compatibility parameters

The skill accepts these parameters so a configuration written for the Python
SDK still loads, but it doesn't use them. The in-memory mode ranks with TF-IDF,
and a remote server uses its own index and model.

| Parameter | Effect in TypeScript |
|---|---|
| `index_file` | Part of the instance key only; no index file is read. |
| `build_index`, `source_dir`, `file_types`, `exclude_patterns` | None. No index is built from files. |
| `backend`, `connection_string`, `collection_name`, `overwrite` | None. The SQLite and pgvector backends aren't available. |
| `model_name` | None. |
| `nlp_backend`, `query_nlp_backend`, `index_nlp_backend` | None. |

## Example — in-memory documents

```typescript {6-16}
import { AgentBase, NativeVectorSearchSkill } from '@signalwire/sdk';

const agent = new AgentBase({ name: 'kb-bot', route: '/kb' });
agent.setPromptText('Answer questions from the knowledge base.');

await agent.addSkill(new NativeVectorSearchSkill({
  tool_name: 'search_kb',
  documents: [
    { id: 'faq-1', text: 'Hours are 9am to 5pm Monday to Friday.', tags: ['hours'] },
    { id: 'faq-2', text: 'Returns are accepted within 30 days.', tags: ['returns'] },
  ],
  count: 3,
  similarity_threshold: 0.1,
  keyword_weight: 0.5,
}));

agent.run();
```

## Example — remote server

```typescript {6-10}
await agent.addSkill(new NativeVectorSearchSkill({
  remote_url: 'https://search.internal.example.com',
  index_name: 'support-kb',
  count: 3,
  similarity_threshold: 0.4,
  tags: ['public'],
}));
```
