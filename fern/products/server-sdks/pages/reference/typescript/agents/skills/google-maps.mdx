Validate and geocode a street address or business name, and compute the
driving distance and travel time between two coordinates, using Google Maps
APIs.

**Class:** `GoogleMapsSkill`

**Tools:** `lookup_address`, `compute_route` (each tool name is configurable).

**Env vars:** `GOOGLE_MAPS_API_KEY` (used when `api_key` is not supplied).

<ParamField path="api_key" type="string" required={true} toc={true}>
  Google Maps API key, with the Geocoding and Routes APIs enabled. Falls back
  to the `GOOGLE_MAPS_API_KEY` environment variable when the config value is
  not supplied. `setup()` fails when neither is set.
</ParamField>

<ParamField path="route_tool_name" type="string" default="compute_route" toc={true}>
  Custom name for the route computation tool.
</ParamField>

<ParamField path="lookup_tool_name" type="string" default="lookup_address" toc={true}>
  Custom name for the address / place lookup tool.
</ParamField>

```typescript {6-8}
import { AgentBase, GoogleMapsSkill } from '@signalwire/sdk';

const agent = new AgentBase({ name: 'assistant', route: '/assistant' });
agent.setPromptText('You are a helpful assistant.');

await agent.addSkill(new GoogleMapsSkill({
  route_tool_name: 'get_driving_time',
}));

agent.run();
```
