Fast web scraping and crawling. Extracts text, markdown, or structured data
from any public URL, optionally following links up to a bounded depth. Uses
`cheerio` for parsing and enforces an SSRF guard: the URL you pass and every
redirect it follows must resolve to a public address.

**Class:** `SpiderSkill`

**Tools:** `scrape_url`, `crawl_site`, `extract_structured_data` (each is
prefixed with `<tool_name>_` when `tool_name` is set).

**Required packages:** `cheerio`

**Env vars:** `SWML_ALLOW_PRIVATE_URLS=true` relaxes the SSRF guard for local
testing.

**Multi-instance:** yes — set a distinct `tool_name` per instance.

<ParamField path="tool_name" type="string" toc={true}>
  Prefix prepended to each emitted tool name (e.g., `tool_name="news"` gives
  `news_scrape_url`, `news_crawl_site`, `news_extract_structured_data`).
  Required when registering multiple instances on the same agent.
</ParamField>

<ParamField path="delay" type="number" default="0.1" toc={true}>
  Delay between requests in seconds (minimum `0`).
</ParamField>

<ParamField path="concurrent_requests" type="integer" default="5" toc={true}>
  Deprecated, and has no effect: the spider fetches one page at a time. Setting
  it logs a warning (range `1-20`).
</ParamField>

<ParamField path="timeout" type="integer" default="5" toc={true}>
  Per-request timeout in seconds (range `1-60`).
</ParamField>

<ParamField path="max_pages" type="integer" default="1" toc={true}>
  Maximum number of pages to scrape (range `1-100`).
</ParamField>

<ParamField path="max_depth" type="integer" default="0" toc={true}>
  Maximum crawl depth. `0` restricts to a single page; range `0-5`.
</ParamField>

<ParamField path="extract_type" type="string" default="fast_text" toc={true}>
  Content extraction method. One of `"fast_text"`, `"markdown"`, or
  `"structured"`. The values `"clean_text"`, `"full_text"`, `"html"`, and
  `"custom"` were never implemented: they still work as `fast_text` and log a
  warning. Any other value makes `setup()` fail.
</ParamField>

<ParamField path="max_text_length" type="integer" default="3000" toc={true}>
  Maximum extracted text length in characters (range `100-100000`).
</ParamField>

<ParamField path="clean_text" type="boolean" default="true" toc={true}>
  Whether to clean extracted text (trim whitespace, collapse runs, etc.).
</ParamField>

<ParamField path="selectors" type={"Record<string, string>"} default="{}" toc={true}>
  Map of name → CSS selector used for structured extraction.
</ParamField>

<ParamField path="follow_patterns" type="string[]" default="[]" toc={true}>
  URL patterns to follow when crawling.
</ParamField>

<ParamField path="user_agent" type="string" default="Spider/1.0 (SignalWire AI Agent)" toc={true}>
  User-Agent header for outbound requests. Also the agent name matched against
  `robots.txt` rules when `follow_robots_txt` is `true`.
</ParamField>

<ParamField path="headers" type={"Record<string, string>"} default="{}" toc={true}>
  Additional HTTP headers sent with each request.
</ParamField>

<ParamField path="follow_robots_txt" type="boolean" default="false" toc={true}>
  Skip pages that the site's `robots.txt` disallows for `user_agent`. This
  covers each page the tools fetch and each redirect they follow. A
  `robots.txt` answered with `401` or `403` disallows every page, and any other
  `4xx` allows every page. A server error or a failed request disallows the
  page and is retried on the next request. Rules are kept for 24 hours.
</ParamField>

<ParamField path="cache_enabled" type="boolean" default="true" toc={true}>
  Whether to cache scraped pages in memory.
</ParamField>

## Example

```typescript {6-11}
import { AgentBase, SpiderSkill } from '@signalwire/sdk';

const agent = new AgentBase({ name: 'assistant', route: '/assistant' });
agent.setPromptText('You are a research assistant.');

await agent.addSkill(new SpiderSkill({
  extract_type: 'markdown',
  max_pages: 5,
  max_depth: 1,
  follow_patterns: ['/docs/'],
}));

agent.run();
```
