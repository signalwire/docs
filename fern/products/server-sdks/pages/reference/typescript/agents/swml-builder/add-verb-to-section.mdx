[add-verb]: /docs/server-sdks/reference/typescript/agents/swml-builder/add-verb

Append a verb to a named section of the SWML document. If the section does not
exist, it is created automatically. The verb config is validated against the
bundled schema when validation is enabled, exactly as in [`addVerb()`][add-verb].

<Warning title="Unknown verbs and keys throw">
Validation is strict. An unknown verb name, an unknown or misspelled key inside
the verb config, or a value of the wrong type throws a `SchemaValidationError`
instead of being dropped silently. Earlier SDK versions appended to non-main
sections without validating. Set `SWML_SKIP_SCHEMA_VALIDATION=true` to disable
validation.
</Warning>

## **Parameters**

<ParamField path="sectionName" type="string" required={true} toc={true}>
  The target section name.
</ParamField>

<ParamField path="verbName" type="string" required={true} toc={true}>
  The SWML verb name (e.g., `"answer"`, `"play"`, `"hangup"`).
</ParamField>

<ParamField path="config" type="unknown" required={true} toc={true}>
  The verb's configuration payload.
</ParamField>

## **Returns**

`void`

## **Example**

```typescript {5}
import { SwmlBuilder } from '@signalwire/sdk';

const builder = new SwmlBuilder();
builder.addVerb('answer', {});
builder.addVerbToSection('goodbye', 'play', {
  url: 'https://example.com/goodbye.mp3',
});
builder.addVerbToSection('goodbye', 'hangup', {});

console.log(builder.render());
```
