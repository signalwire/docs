---

Stop serving a directory. The route stops responding at once, including on a running service.

## Parameters

<ParamField path="route" type="string" required={true} toc={true}>
  The URL route prefix to remove.
</ParamField>

## Returns

`void`

## Example

```typescript
import { WebService } from '@signalwire/sdk';

const web = new WebService({
  directories: { '/audio': './public/audio' },
  basicAuth: ['audio', process.env['AUDIO_PASSWORD'] ?? ''],
});

await web.start();

// Later, stop serving the audio directory.
web.removeDirectory('/audio');
```
