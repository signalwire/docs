Start the HTTP or HTTPS service. The service uses HTTPS when SSL is fully configured, either through the `ssl` constructor option or the `sslCert` and `sslKey` arguments.

<Note>
When `SWAIG_CLI_MODE=true` is set in the environment, the call is a no-op so you can inspect configuration without binding a port.
</Note>

## Parameters

<ParamField path="host" type="string" default="0.0.0.0" toc={true}>
  Bind address.
</ParamField>

<ParamField path="port" type="number" toc={true}>
  Port override. Defaults to the service's `port`.
</ParamField>

<ParamField path="sslCert" type="string" toc={true}>
  Path to the SSL certificate file. Overrides the `ssl` constructor option when passed together with `sslKey`.
</ParamField>

<ParamField path="sslKey" type="string" toc={true}>
  Path to the SSL key file.
</ParamField>

## Returns

`Promise<void>` -- resolves once the server has begun listening.

Throws an `Error` if no basic-auth credentials are configured: the `basicAuth` option, the config file's `security.auth.basic`, or `SWML_BASIC_AUTH_USER` and `SWML_BASIC_AUTH_PASSWORD`.

## Example

```typescript
import { WebService } from '@signalwire/sdk';

const web = new WebService({
  directories: { '/audio': './public/audio' },
  basicAuth: ['audio', process.env['AUDIO_PASSWORD'] ?? ''],
});

await web.start('127.0.0.1', 8080);
```
