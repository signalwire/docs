Add a directory to serve at a URL route prefix. You can call it before or after the service starts; the route serves from the next request.

## Parameters

<ParamField path="route" type="string" required={true} toc={true}>
  URL prefix, for example `'/docs'`. A leading `/` is added if missing.
</ParamField>

<ParamField path="directory" type="string" required={true} toc={true}>
  Local directory path to serve.
</ParamField>

## Returns

`void`

Throws an `Error` if the directory does not exist or the path is not a directory.

## Example

```typescript
import { WebService } from '@signalwire/sdk';

const web = new WebService({
  basicAuth: ['assets', process.env['ASSETS_PASSWORD'] ?? ''],
});

web.addDirectory('/images', './public/images');

await web.start();
```
