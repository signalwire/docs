Get the configured [Hono](https://hono.dev) application, for mounting in another app or for testing.

## Returns

`Hono` -- the configured Hono app.

## Example

```typescript
import { WebService } from '@signalwire/sdk';

const web = new WebService({
  directories: { '/audio': './public/audio' },
  basicAuth: ['audio', process.env['AUDIO_PASSWORD'] ?? ''],
});

const app = web.getApp();
const res = await app.request('/health');
console.log(res.status);
```
