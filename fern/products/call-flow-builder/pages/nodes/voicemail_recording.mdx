This node records a voicemail from the caller. It records only the caller's audio.
The Flow waits on this node while it records and moves to the next node once the recording ends:
when the caller presses a terminator digit, stays silent for the End Silence Timeout, doesn't start speaking within the Initial Timeout, or reaches the Maximum Recording Length.

Reference the recording URL in other nodes in the Flow using the variable `%{record_url}`.
The variable `%{record_result}` is `success` when the recording is saved and `failed` when it isn't.
You can also access the recording URL from the call log details in your [Relay Space](https://my.signalwire.com?page=relay).


## **Node Settings**

<ParamField path="Stereo" type="boolean" toc={true}>
  Record in stereo.<br /><br />**Default Value:** `Toggled Off`
</ParamField>

<ParamField path="Beep" type="boolean" toc={true}>
  Play a beep before recording starts. <br /><br />**Default Value:** `Toggled Off`
</ParamField>

<ParamField path="Terminators" type="string" toc={true}>
  DTMF digits that stop the recording when the caller presses any one of them. Enter up to 12 digits with no separator, for example `#*`.<br /><br />**Default Value:** `#` when left blank<br /><br />**Possible Values:** Digits `0-9`, `*`, `#`
</ParamField>

<ParamField path="Maximum Recording Length" type="integer" toc={true}>
  The maximum length of the recording in seconds. `0` sets no maximum length.<br /><br />**Default Value:** No maximum when left blank<br /><br />**Possible Values:** `0-3600` seconds
</ParamField>

<ParamField path="Initial Timeout" type="integer" toc={true}>
  The time in seconds to wait for the caller to start speaking. If the caller doesn't speak within this time, the recording ends.<br /><br />**Default Value:** `4` seconds when left blank<br /><br />**Possible Values:** `1-99` seconds
</ParamField>

<ParamField path="End Silence Timeout" type="integer" toc={true}>
  The time in seconds of silence after the caller stops speaking that ends the recording.<br /><br />**Default Value:** `5` seconds when left blank<br /><br />**Possible Values:** `1-99` seconds
</ParamField>

<ParamField path="Format" type="string" toc={true}>
  The format of the recording.<br /><br />**Default Value:** `wav`<br /><br />**Possible Values:** `wav`, `mp3`
</ParamField>


## **Examples**


### Simple voicemail with goodbye message

For a traditional voicemail experience, we recommend pairing the Voicemail Recording node with a 
[Play Audio or TTS](/docs/call-flow-builder/reference/play-audio-or-tts) node and including a beep before recording. 
The caller presses `#`, the default terminator, to end the recording, and the Flow continues to the next node.

<llms-ignore>

<Frame caption="Play TTS and record voicemail." ogImage>
![Play TTS and record voicemail.](/assets/images/call-flow/nodes/simple-voicemail.webp)
</Frame>

</llms-ignore>

<llms-only>

Route **Forward to Phone**'s **No Answer**, **Busy**, **Decline**, and **Error** outputs to an unavailable-message **Play Audio or TTS** node → **Voicemail Recording** → a thank-you **Play Audio or TTS** node. Enable the recording beep, use `#` as the terminator, and save WAV format.

</llms-only>

---

### Record voicemail and send recording URL as a POST request

You can pair this node with a [Request](/docs/call-flow-builder/reference/request) node to send the recording URL to the webhook of your choice. 
Any later Voicemail Recording node in the Flow overwrites the `%{record_url}` variable,
so the Request node should immediately follow this Voicemail Recording node or use 
[Set Variables](/docs/call-flow-builder/reference/set-variables) to save this URL for a later request.

<llms-ignore>

<Frame caption="Record voicemail and send URL and call data as a POST request.">
![Record voicemail and send URL and call data as a POST request.](/assets/images/call-flow/nodes/post-voicemail.webp)
</Frame>

</llms-ignore>

<llms-only>

Use the same failed-forward branches for **Play Audio or TTS** → **Voicemail Recording** → **Request**. Configure the Request as POST with a body containing `New voicemail from %{call.from} calling into %{call.to}. Recording URL: %{record_url}`.

</llms-only>

---

### Record voicemail and send recording URL as SMS

You may want to be notified about a new voicemail with an SMS. 
You can follow the Voicemail Recording node with a Send SMS node and again access call data and the recording URL with 
variables such as `%{call.from}`, `%{call.to}`, and `%{record_url}`.

<llms-ignore>

<Frame caption="Record voicemail and send URL and call data as an SMS.">
![Record voicemail and send URL and call data as an SMS.](/assets/images/call-flow/nodes/voicemail-sms.webp)
</Frame>

</llms-ignore>

<llms-only>

Use the same failed-forward branches for **Play Audio or TTS** → **Voicemail Recording** → **Send SMS**. Include `%{call.to}`, `%{call.from}`, and `%{record_url}` in the notification text.

</llms-only>
