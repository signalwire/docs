This page renders every Markdown heading level (H1 through H6) with a short paragraph under each, so you can compare how they look and decide which levels need custom styling. The page title above is the H1 that Fern generates from the `title` frontmatter; body headings normally start at `##`.

The right-hand table of contents picks up headings down to H3 (`max-toc-depth: 3`). H4 through H6 render on the page but don't appear in the table of contents.

# H1 heading (`#`)

This is an explicit H1 written in the page body with a single `#`. It renders at the same level as the page title, which is why body content normally starts at H2.

## H2 heading (`##`)

An H2 marks a major section of the page. This is the highest level you'd normally use in the body and the first level that appears in the table of contents.

### H3 heading (`###`)

An H3 is a subsection of an H2. It's the deepest level that appears in the table of contents.

#### H4 heading (`####`)

An H4 sits under an H3. It renders on the page but is left out of the table of contents.

##### H5 heading (`#####`)

An H5 is rarely used in prose. It's useful mostly for dense reference material.

###### H6 heading (`######`)

An H6 is the smallest heading level Markdown supports. It's often visually close to bold body text, which is a good reason to style it distinctly or avoid it.

## Headings with inline formatting

Headings can carry inline Markdown, which is worth checking when tuning styles.

### Heading with `inline code`

Code in a heading uses the monospace font at the heading's size.

### Heading with **bold** and *italic* text

Bold and italic markers apply on top of the heading weight.

### Heading with a [link](/docs)

Links in headings pick up the link color and hover styles.

### A very long heading that wraps onto a second line when the content column is narrow enough to force it

Long headings show how line height and wrapping behave at each level.

## Adding custom heading styles

Site-wide CSS lives in `fern/styles.css`. The page title uses Fern's `.fern-page-heading` class; body headings render as plain `h2`–`h6` tags inside `.fern-layout-page`, so you can target a level directly, for example:

```css title="fern/styles.css"
.fern-layout-page h2 {
  border-bottom: 1px solid var(--grayscale-5);
  padding-bottom: 0.25rem;
}

.fern-layout-page h4 {
  text-transform: uppercase;
  letter-spacing: 0.05em;
  font-size: 0.875rem;
}
```

Heading font family and color come from the `--typography-heading-font-family` and `--fg-headings` tokens in `fern/brand-tokens.css`. After changing styles, reload this page to compare every level side by side.
