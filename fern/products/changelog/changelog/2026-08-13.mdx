## Default TTS engine changed to ElevenLabs

<Warning title="Check any agent that does not name a TTS engine">
An `ai` verb with no `voice` set now speaks with ElevenLabs `mark`. It previously used Google `en-US-Neural2-J`. Name the engine and the voice explicitly to pin what your agent sounds like.
</Warning>

The implicit engine — the one applied when a voice string names none — moved from `gcloud` to `elevenlabs` on 13 August. Since 17 August, a bare Google-shaped ID such as `en-US-Neural2-C` is routed back to `gcloud`, so those configurations work as before.

Bare names for other engines are not. An Azure name like `en-US-JennyNeural` has the same shape and also resolves to `gcloud`. A bare name matching no ElevenLabs voice gets the default ElevenLabs voice substituted, so you hear the wrong voice rather than silence. Name the engine every time: `gcloud.en-US-Neural2-A`, `elevenlabs.Rachel`, `azure.en-US-AvaNeural`.

This reaches into [`ai.languages`](/docs/swml/reference/calling/ai/languages) too — an entry naming no engine of its own inherits the top-level one.

## Post-prompt and debug webhook payloads

Already available — these callbacks have fired since 2023. The AI post-prompt callback, the AI debug webhook, and the Bedrock post-prompt callback are specified field by field in the REST API reference: around 20 post-prompt fields, and the 47 event types the debug stream can carry. Build against the payload instead of reading it off a live call.

The [`ai.params`](/docs/swml/reference/calling/ai/params) and [`amazon_bedrock`](/docs/swml/reference/calling/amazon-bedrock) references carry the same definitions.
