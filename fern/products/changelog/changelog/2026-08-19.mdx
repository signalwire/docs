## One AI agent, many languages

Give an agent a voice per language and it detects what the caller speaks, answers in it, and switches whenever the caller does. `multilingual` and `languages` are mutually exclusive: set both and SignalWire uses `multilingual`, ignoring `languages` entirely.

See [`ai.multilingual`](/docs/swml/reference/calling/ai/multilingual).

## Conversation analytics

Analyze finished conversations with post-prompt reports, and troubleshoot live calls with debug webhooks. See [Conversation analytics](/docs/platform/ai/analytics), or start from the [AI quickstart](/docs/platform/ai/quickstart).

## Verify SWML request signatures

Already available — SignalWire signs every request for a SWML document with an HMAC in the `X-Signalwire-Signature` header. Verify it in Node, Python, or Ruby so your endpoint can reject forged requests.

Signing has been in place on the voice path since 2023; on the messaging path it started in June 2026. See [Verify SWML request signatures](/docs/swml/guides/webhook-security).
