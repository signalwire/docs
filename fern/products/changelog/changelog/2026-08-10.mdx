## Tool calling

The AI agent runs the conversation; your code owns the business logic. A SWAIG function is where the two meet — the agent decides when to call it, you decide what it does. The [tool calling guide](/docs/platform/ai/tool-calling) builds a complete order-status agent in both SWML and the Python Server SDK.

## Prompting for realtime voice

What changes when a prompt is spoken rather than read: sentence length, speech-recognition hints for names and product terms, and checking results with post-prompt reports. See [best practices](/docs/platform/ai/best-practices).
